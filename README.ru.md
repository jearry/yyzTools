## Введение

Поиск, перевод, распознавание, предпросмотр, пакетная обработка, скриншоты, обои — все частые и мелкие задачи повседневной работы, и больше не нужно для каждой из них отдельно искать, устанавливать и оплачивать программу. Установите yyzTools один раз — и всё нужное окажется под рукой.

## Ключевые особенности

- **Бесплатно навсегда** — Все функции открыты: без платной разблокировки, без уровней подписки и без урезания ключевых возможностей ради скрытой оплаты.
- **Сначала локально** — Буфер обмена, поиск файлов, статистика использования и OCR обрабатываются и хранятся на вашем компьютере и никуда не отправляются сами.
- **Одна установка** — Более 40 модулей готовы к работе сразу — без круга поисков, сравнений, загрузок, пробных версий и удалений.
- **387 командных модулей** — Команды пяти категорий: ИИ, приложения, игры, система и веб-сайты. Чтобы добавить свою, достаточно одного файла JSON.

## Архитектура

Гибридная: **хост на C++ (Win32 + WebView2)**, несущий **фронтенд (Alpine.js + чистый JS + Vite)**, с изоляцией функциональных областей в отдельные процессы.

| Процесс | Назначение |
|---------|------------|
| `yyzTools.exe` | Основной процесс — содержит командную панель, перевод, OCR и большинство других функций |
| `yyzWallpaper.exe` | Динамические обои — компонует веб/видео под слоем значков рабочего стола через Windows Composition API |
| `yyzBrowser.exe` | Встроенный браузер без рамки, через который командные модули открывают URL |
| `yyzCmd.exe` | Исполнитель системных команд на чистом Win32 (выключение / перезагрузка / громкость / монитор / корзина и т. д.) |
| `yyzInputHint.exe` | Индикация нажатий клавиш клавиатуры / мыши в реальном времени (RawInput) |
| `yyzMouseFinder.exe` | Быстрый поиск курсора мыши |
| `yyzScreenCap.exe`   | Снимок экрана — область, прокрутка и закрепление |
| `yyzScreenRec.exe`   | Запись экрана — камера следует за курсором, показ кликов и клавиш |
| `yyzFileClean.exe`   | Молниеносное сканирование и очистка файлов (ImGui) |
| `yyzDiskSpace.exe`   | Молниеносный анализ дискового пространства (ImGui) |
| `yyzMemClean.exe`    | Молниеносная очистка памяти (ImGui) |
| `yyzWinOpt.exe`      | Молниеносный оптимизатор системы (ImGui) |
| `yyzUpdater.exe` | Инкрементный автообновлятор (см. `src/updater/`) |
| `yyzFileSearch.exe` | Собственный движок поиска файлов по всем томам — прямое чтение MFT + инкрементальный индекс USN |

Фронтенд вызывает менеджеры C++ через мост `window.Zen`; все они возвращают результат по единому контракту `{ error, ... }`.

## Загрузка

- **Установщик** (рекомендуется): `yyzTools-setup-1.1.1.2110.exe` —— [GitHub Releases](https://github.com/jearry/yyzTools/releases)
- **winget**: установка в терминале командой `winget install yyztools`
- Медленно из Китая? Добавьте префикс зеркала к URL установщика: [ghfast.top](https://ghfast.top/) · [ghproxy.com](https://ghproxy.com/) · [gh-proxy.com](https://gh-proxy.com/)
- Или скачайте с [официальной страницы загрузки](https://yyztools.com/ru/download.html).

Мастер установки поддерживает 12 языков: упрощённый и традиционный китайский, английский, японский, корейский, французский, немецкий, испанский, русский, арабский, португальский и итальянский.

## Системные требования

- Windows 10 / 11 (x64)
- WebView2 Runtime (предустановлен в новых системах; при отсутствии установщик предложит его установить)

## Языки интерфейса

Интерфейс и тексты командных модулей поддерживают все перечисленные 12 языков. При первом запуске язык системы определяется автоматически; переключить его можно в любой момент в настройках.

## Об этом репозитории

Этот репозиторий (`jearry/yyzTools`) — **репозиторий публикаций и хостинга официального сайта** yyzTools:

- [`releases/`](releases/) —— версионированные установщики и томные архивы (`.7z`), а также манифест автообновления `update.json`
- [`docs/`](docs/) —— статический сайт <https://yyztools.com> (хостинг через GitHub Pages)
- Компоненты с открытым кодом (лицензии — см. [LICENSE](LICENSE)):
  - [`src/library/`](src/library/) —— общая библиотека утилит (yyzlib)
  - [`src/updater/`](src/updater/) —— автообновлятор
  - [`src/yyzcmd/`](src/yyzcmd/) —— исполнитель системных команд
  - [`src/inputhint/`](src/inputhint/) —— подсказки клавиш
  - [`src/mousefinder/`](src/mousefinder/) —— поиск курсора

О проблемах с функциональностью сообщайте через [Issues](https://github.com/jearry/yyzTools/issues).
