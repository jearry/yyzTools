常见问题

真的永久免费吗？会不会以后收费？

真的免费。不设付费解锁、不设会员体系，也不会把核心能力阉割成付费项。我们希望 yyzTools 是你愿意长期留在桌面上的工具，而不是又一笔订阅。

我的数据会被上传吗？

不会。剪贴板历史、文件搜索、应用统计、OCR 等都在本机处理与存储。只有你主动使用翻译这类联网功能时，才会把你输入的内容按你选择的服务发给对应第三方。另外软件会定期检查更新，那个请求只传版本号。

需要注册账号吗？

不需要。软件不要求注册，也不主动收集你的身份信息。

支持哪些系统？

Windows 10 与 Windows 11 的 64 位版本。需要 Microsoft Edge WebView2 运行时，Win11 已内置，Win10 若缺失安装程序会引导你装上。

会占用很多资源吗？

主进程常驻很轻，壁纸、截图、按键提示等做成了独立进程，用不到就不启动。开游戏时可以一键进入游戏模式，暂停壁纸与特效。

怎么自己加功能？

往安装目录的 Modules 文件夹里放一个 .zenmod JSON 文件，写上名称、图标、要执行的命令，重启后命令面板里就能搜到，不需要编译任何代码。
