Frequently asked

Is it really free forever? Will you start charging?

Genuinely free. No paid unlocks, no membership tiers, and no holding core features back behind a paywall. We want yyzTools to be a tool you are happy to keep on your desktop long-term, not another subscription.

Is my data uploaded anywhere?

No. Clipboard history, file search, app usage, and OCR are processed and stored locally. Only when you actively use an online feature such as translation does your input go to the third-party service you selected.

Do I need an account?

No. There is no sign-up, and the software does not collect identifying information.

Which systems are supported?

64-bit Windows 10 and Windows 11. The Microsoft Edge WebView2 runtime is required; Windows 11 ships with it, and on Windows 10 the installer will guide you through adding it.

Is it heavy on resources?

The resident main process is light, and wallpaper, capture, and input hints run as separate processes that only start when used. Game mode pauses wallpaper and effects in a single click.

How does yyzTools differ from PowerToys?

PowerToys is Microsoft’s modular utility set for power users - you enable the pieces you want. yyzTools is an integrated suite: command palette, translation, OCR, clipboard history, and batch file / image / video / PDF tools come preconfigured in one installer, with a 12-language interface. Both are free, so many people simply keep both.

How does it compare with Flow Launcher or Raycast?

Flow Launcher is an excellent open-source launcher that shines at search and plugins. Raycast comes from macOS; its Windows version is still in beta and the full experience needs a Pro subscription. yyzTools is complete out of the box: translation, OCR, clipboard history, batch processing, and live wallpaper are all built in — no plugin hunting, no subscription.

How does it compare with Everything or Listary?

Everything is an excellent dedicated filename-search tool; Listary adds a launcher and Explorer integration. Since v1.0.5, yyzTools runs its own in-house engine: direct $MFT reads with USN journal updates, Everything-style syntax (path: / ext: / size:), and a resident index of around 5–30 MB. The difference: one Alt+Space box searches files alongside apps, processes, windows, bookmarks, and clipboard, with preview, reveal, and recycle-bin actions built in. If all you want is the fastest filename search, Everything remains a great pick.

I already use PowerToys — can I still install yyzTools?

Yes, they coexist fine. The resident yyzTools process is light, wallpaper and capture start on demand, and every hotkey is customisable. A common setup: PowerToys for window snapping and key remapping, yyzTools for launching, translation, OCR, and batch processing.

What about uTools, Wox, or ZTools?

uTools is a plugin platform - the shell is free, but popular plugins sit behind a paid membership. Wox is an open-source launcher focused on search. ZTools is an open-source uTools alternative assembled from a plugin market. yyzTools bundles 388 modules into one installer with no membership and no paid unlocks, and keeps clipboard, search, and OCR data on your machine.
