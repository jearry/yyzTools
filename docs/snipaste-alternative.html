Step numbers Snipaste doesn't have

Writing a how-to? Pick the number tool on the capture toolbar and click where each step goes: a bold badge drops in, the count increments itself, and undo rewinds the counter with it. Pair it with rectangles and text and the "click here, then here" explains itself. Snipaste's annotation set is excellent — it simply has no numbered-step tool.

When Snipaste is still the right pick

If pinning is the point, Snipaste's pinning is unmatched: zoom, rotate, flip, per-pin transparency, mouse click-through, thumbnail mode, a color picker, grouping and auto backup. If you also work on macOS or Linux, or you want the lightest dedicated tool, Snipaste remains the specialist — and its personal edition is free forever.

When yyzTools is the better fit

If your screenshot is usually the start of something — text to extract, a phrase to translate, a long page to capture whole, a tutorial to number — yyzTools finishes the job inside the capture window, and the same install already carries the launcher, file search and clipboard history, 387 modules in total.

Common questions

Does yyzTools replace Snipaste's pinning?

Partially. Pinning from the capture toolbar and pinning clipboard images are built in, but Snipaste's pin goes much deeper — rotation, grouping, per-pin transparency, a color picker, backup and restore. Heavy pin users should keep Snipaste; it also runs on macOS and Linux.

How does the step-number tool work?

Press Ctrl+` to capture, pick the number tool on the toolbar and click where the step belongs: a bold badge is placed and the count auto-increments for the next click. Badges are objects like any other shape — select, drag, resize or delete them afterwards, and undo restores the counter too.

Can both stay installed together?

Yes, they don’t conflict. yyzTools’ capture defaults to Ctrl+` and Snipaste to F1 / F3, so the keys rarely collide; anything that does can be remapped on either side.
