剪贴板能读你复制的图

复制一张含文字的图片（截图或图片文件），yyzTools 会在后台自动 OCR，把文字连同图片一起存进历史；之后你能用只存在于图里的文字把它搜出来，也能一键只把识别出的文本复制回去。Win+V 只存图不识别，Text Extractor 读一次就走，二者都不会沉淀成可搜索的文字历史。

什么时候 PowerToys 仍是好选择

如果你想改造的是 Windows 本身——FancyZones 窗口分屏、Keyboard Manager 键位重映射，或一大套深度系统工具，且全程开源、由微软背书——那 PowerToys 更专更强，还能只启用你要的模块。yyzTools 目前不提供窗口分屏和键位重映射。

什么时候选 yyzTools

如果你想用一个应用替代「PowerToys Run + 文件搜索 + 剪贴板管理 + 截图 OCR + 翻译」这一摞，还要复制的图片能变可搜文字，外加图片/视频/PDF 批量、动态壁纸与下载管理——yyzTools 一次轻量安装全包，键盘优先，12 语可用。

常见疑问

yyzTools 能完全替代 PowerToys 吗？

在「启动器 + 工具箱」的交集上大体可以。PowerToys 有 yyzTools 还没有的系统工具，主要是 FancyZones 与 Keyboard Manager；反过来 yyzTools 有 PowerToys 缺的内置项，如真正的翻译、自研全盘搜索、可搜 OCR 剪贴板、视频与 PDF 批量、动态壁纸。看你实际要用哪一块交集。

两个能同时装吗？

能，互不冲突。只需注意全局热键——两者默认都用 Alt+空格——把其中一个的启动热键改掉即可。

可 OCR 的剪贴板具体能做什么？

复制一张含文字的图片（截图或图片文件）时，yyzTools 会跑 OCR 并把文字存进剪贴板历史。之后你能用只出现在那张图里的文字搜到它，也能只复制识别出的文本。Win+V 存图却不识别，Text Extractor 是一次性提取、不留历史。
