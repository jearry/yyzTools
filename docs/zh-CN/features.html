按使用场景分成六类。所有功能都包含在同一个安装包里，没有额外购买项。

按 Alt+空格 唤起的统一入口，一个搜索框贯穿整台电脑。

应用搜索 默认

搜索并启动 Win32 / UWP 应用、系统命令、系统设置，支持管理员身份运行与定位文件位置。

基于 Everything 的秒级全盘检索，可直接打开、预览、定位或删除到回收站。

进程管理 p␣

搜索进程并运行 / 挂起、终止、重启，无需再开任务管理器。

窗口管理 w␣

搜索窗口并显示 / 隐藏、置顶 / 取消置顶、关闭。

书签搜索 b␣

检索浏览器书签，普通或隐私模式打开。

剪贴板历史 c␣

回溯文本与图片历史记录，点选即回填。

命令行 >␣

直接执行命令，支持以管理员身份运行。

即时计算 =␣

边输入边出结果，公式与结果图形化呈现，回车复制。

启动与效率

把重复动作压缩成一次快捷键。

程序坞

常用应用与网址的悬浮启动条，分组管理，随手可及。

后台记录文本与图片，支持钉住图片悬浮于桌面之上。

记录各应用的使用时长与激活次数，用图表看清时间去了哪里。

屏幕截图

区域截图、长截图（滚动拼接）、贴图钉屏，独立进程互不拖累。

提醒助手

单次 / 每日 / 每周 / 每月提醒，到点桌面通知。

公历农历对照、节气节假日、干支纪年与择日信息。

按键提示

基于 RawInput 实时显示键盘鼠标按键，录屏演示时观众看得清。

鼠标定位

一键高亮当前光标位置，多显示器下再也不用找鼠标。

文本与语言

文本处理链路上的常用工序，一次装齐。

超级翻译

多引擎划词与整段翻译，可自选服务与目标语言。

文字识别 OCR

截图即识别，本地 RapidOCR 引擎离线运行，中英混排准确。

正则表达式

实时匹配高亮、分组查看、常用表达式速查。

编码解码

Base64 / URL / HTML / Unicode / 进制等常见编码互转。

哈希计算

MD5 / SHA 系列摘要，支持文本与文件校验。

加密解密

基于 OpenSSL 的对称与非对称加解密、密钥生成。

数据转换

JSON / YAML / XML / TOML / CSV 结构化数据互转与格式化。

数据生成

UUID / GUID、ULID、随机字符串与测试数据批量生成。

文件与媒体

批量处理交给工具，你只管选文件。

文件预览

免装 Office 直接预览 Word / Excel / PPT / PDF / 图片 / 视频 / 代码 / 压缩包等格式。

批量重命名

序号、替换、正则、大小写、EXIF 时间等规则组合，改前先预览。

图片批量处理

基于 ImageMagick 的缩放、裁剪、格式转换、水印、压缩。

视频批量处理

基于 FFmpeg 的转码、截取、抽帧、压缩、音频提取。

PDF 批量处理

基于 pdfcpu 与 Ghostscript 的合并、拆分、加水印、压缩、加解密。

文件下载

基于 Aria2 的多线程下载，断点续传与队列管理。

计算与拓展

开放的命令模块体系，加个 JSON 就多一条命令。

计算稿纸

多行连续计算，支持变量、单位换算与函数，公式排版化显示。

二维码

文本与网址生成二维码，也可从截图或图片中识别。

命令模块

内置 379 个 .zenmod 命令模块，涵盖 AI、应用、游戏、系统、网站五大类，命令面板中直接唤起。

内置浏览器

无边框轻量浏览器，命令模块打开网址时使用，不惊动主浏览器。

自定义扩展

往 Modules 目录放一个 .zenmod JSON 即新增一条命令，无需编译。

个性化

动态壁纸

用 Windows Composition API 把网页与视频贴到桌面图标层下方，不遮挡操作。

桌面特效

雪花飘落等氛围特效，鼠标穿透不干扰点击。

游戏模式

一键暂停壁纸与特效，把资源全让给游戏。

导航页

可自定义分组的标签导航，替代浏览器新标签页。

地球保卫战

内置的小游戏，摸鱼三分钟。
