隐私政策

生效日期：2026 年 8 月 8 日　·　版本：v1.0

本政策说明 yyzTools（以下简称“本软件”）如何处理你的数据。核心原则一句话：本地优先（local-first）——能在你电脑上做完的事，绝不送到别处。本政策是用户协议第三节的展开说明，两者不一致时以本政策为准。

一、我们不收集什么

本软件不要求注册账户，不收集你的姓名、手机号、邮箱等身份识别信息，也没有任何形式的用户画像或行为埋点上报。

我们没有服务器保存你的使用数据——因为本软件根本不向我们发送使用数据。

二、本地处理与存储的数据

以下数据均在你的设备上采集、处理与存储，保存在本机的配置文件与数据库中，不会由本软件主动上传：

  • 剪贴板历史：你复制过的文本与图片记录。
  • 应用使用统计：各应用的前台时长与激活次数。
  • 文件搜索与预览：本机文件索引与你打开过的文件路径。
  • 文字识别（OCR）：识别在本地 RapidOCR 引擎中完成，图像不出本机。
  • 配置与偏好：快捷键、程序坞条目、壁纸设置、界面语言等。
  • 命令面板记录：你的搜索词与启动过的项目。

三、需要联网的功能

只有以下情形会产生网络请求，且都由你的操作触发：

  • 超级翻译：你提交的文本或图像会按你在设置中选择的服务，发送至相应的第三方在线翻译服务。这部分数据由该第三方按其自有隐私政策处理，不在我们控制范围内。
  • 文件下载：由你输入的链接直接连接目标服务器。
  • 命令模块与导航页：打开网址时由内置浏览器直接访问该网站。
  • 动态壁纸：若你使用在线网页作为壁纸源，则会访问该网页。

如不希望任何数据外发，你可以不使用上述联网功能，其余功能完全离线可用。

四、更新检查

本软件会定期向官方镜像（GitHub、jsDelivr 等）请求版本清单，以判断是否有新版本。该请求仅传输版本号等必要信息，不包含你的任何个人数据或使用数据。

你可以在设置中关闭自动检查，改为手动通过托盘菜单检查更新。

五、你对数据的控制权

  • 所有本地数据都在你的用户目录下，你可随时直接查阅、备份、导出或删除。
  • 剪贴板历史可在命令面板中删除单条或一键清空。
  • 卸载时可选择一并删除数据目录，删除后不可恢复。

六、第三方组件

本软件内置以下开源或免费组件，各自按其原有许可证条款分发：Microsoft Edge WebView2、FFmpeg、ImageMagick、Ghostscript、pdfcpu、RapidOCR、Everything、Aria2、7-Zip、OpenSSL 等。它们均以本地进程方式被调用，不承担数据上传职责。

七、儿童隐私

本软件是通用桌面工具，不针对儿童设计，也不会主动收集任何年龄相关信息。

八、网站访问统计

当你访问本站官网（yyztools.com）时，我们会借助 Cloudflare Web Analytics 收集匿名的聚合访问统计（如页面浏览量、访问来源、大致地域与设备类型），用于了解内容受欢迎程度并优化站点体验。该服务不使用 Cookie，也不收集可用于识别你个人身份的信息；相关数据由 Cloudflare 依据其隐私政策聚合处理。

九、政策变更与联系

本政策如有修订，将在本页面注明新的生效日期。若涉及数据处理方式的实质性变化，我们会在更新说明中一并提示。有任何疑问可通过下方邮箱或 GitHub Issues 与我们联系。
