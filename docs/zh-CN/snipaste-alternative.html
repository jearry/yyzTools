Snipaste 没有的序号标注

写操作教程时，在截图工具条上选序号工具，点到哪一步就在哪里落一个加粗圆形编号，计数自动递增，撤销时计数器同步回退。配上矩形和文本，「先点这里、再点那里」自己就长在图上。Snipaste 的标注集很出色——唯独没有步骤序号工具。

什么时候 Snipaste 仍是好选择

如果贴图才是重点，Snipaste 的贴图无可匹敌：缩放、旋转、翻转、单独调透明度、鼠标穿透、缩略图模式、取色器、分组、自动备份恢复。如果你还要在 macOS / Linux 上使用，或者想要最轻量的专用工具，Snipaste 仍是专家之选——个人版永久免费。

如果你的截图往往只是起点——要提取文字、翻译一句、把长页面整页截下、给操作步骤标上序号——yyzTools 在截图窗口里就把后半程做完，而同一个安装包里本就带着启动器、文件搜索、剪贴板历史，共 387 个模块。

常见疑问

yyzTools 能替代 Snipaste 的贴图吗？

只能部分替代。截图工具条的一键钉图、剪贴板图片钉屏都内置，但 Snipaste 的贴图深得多——旋转、分组、单独调透明度、取色器、备份恢复。重度贴图用户建议留着 Snipaste，它也支持 macOS 和 Linux。

序号标注怎么用？

Ctrl+` 唤出截图，工具条选序号工具，点到步骤所在处：落下一个加粗圆形编号，计数自动递增。序号与其他图形一样是对象，画完还能选中、拖动、缩放、删除，撤销时计数器一并回退。

两个能共存吗？

可以，互不冲突。yyzTools 截图默认 Ctrl+`，Snipaste 默认 F1 / F3，几乎不撞键；真撞了，两边都能改键。
