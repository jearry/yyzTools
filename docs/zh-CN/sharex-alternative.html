装好就有的 OCR——旁边就是翻译

ShareX 的 OCR 依托 Windows 内置引擎，加新语言要先装系统语言包。yyzTools 把 RapidOCR 引擎和模型打进安装包：装好即用、混排文字友好，截图工具条上的 OCR 与翻译按钮（或独立的快速 OCR，Alt+T）把一张截图直接变成翻译好的文字，全程不用离开截图流程。

什么时候 ShareX 仍是好选择

如果你的截图是要「发出去」的——大量上传目标、自定义上传器、截图后任务链、自动捕获——或者你要的是每个旋钮都露在外面的开源免费无账号工具，ShareX 仍是重度用户之选，它的社区也是 Windows 免费软件里最大的之一。

什么时候选 yyzTools

如果你的截图是用来读和回的——提取文字、翻译段落、整页截存——yyzTools 在截图窗口里就把事办完，同一个安装包里还有启动器、文件搜索、剪贴板历史、批量处理，共 387 个模块。

常见疑问

yyzTools 能替代 ShareX 吗？

日常截图——区域、滚动、标注、贴图——基本能，还多了翻译和内置 OCR 引擎。但 ShareX 的主场——上传目标、自定义上传器、截图后自动化——这里没有对应物。重度分享流用户请留着 ShareX。

两边 OCR 引擎有什么差别？

yyzTools 把 RapidOCR 引擎和模型随安装包交付，装好即用、对混排文字优化。ShareX 调用 Windows 内置 OCR，语言跟随系统语言包——加一种语言要先去 Windows 语言设置里装。

两个能共存吗？

可以。若有热键相撞，在任一侧改键即可（yyzTools：托盘图标 → 设置 → 快捷键）。
