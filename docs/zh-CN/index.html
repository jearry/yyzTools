常见问题

真的永久免费吗？会不会以后收费？

真的免费。不设付费解锁、不设会员体系，也不会把核心能力阉割成付费项。我们希望 yyzTools 是你愿意长期留在桌面上的工具，而不是又一笔订阅。

我的数据会被上传吗？

不会。剪贴板历史、文件搜索、应用统计、OCR 等都在本机处理与存储。只有你主动使用翻译这类联网功能时，才会把你输入的内容按你选择的服务发给对应第三方。

需要注册账号吗？

不需要。软件不要求注册，也不主动收集你的身份信息。

支持哪些系统？

Windows 10 与 Windows 11 的 64 位版本。需要 Microsoft Edge WebView2 运行时，Win11 已内置，Win10 若缺失安装程序会引导你装上。

会占用很多资源吗？

主进程常驻很轻，壁纸、截图、按键提示等做成了独立进程，用不到就不启动。开游戏时可以一键进入游戏模式，暂停壁纸与特效。

yyzTools 和 PowerToys 有什么区别？

PowerToys 是微软的模块化工具集，面向进阶用户，需要自行启用各个组件。yyzTools 是一体化套件：命令面板、翻译、OCR、剪贴板历史、文件/图片/视频/PDF 批量处理在同一个安装包里开箱即用，界面支持 12 种语言。两者都免费，很多人会同时保留。

和 Flow Launcher、Raycast 比呢？

Flow Launcher 是优秀的开源启动器，强在搜索和插件；Raycast 来自 macOS，Windows 版仍在公测，完整体验要 Pro 订阅。yyzTools 的差异是「装完即全」：翻译、OCR、剪贴板历史、批量处理、动态壁纸全部内置，不用装插件，也不用订阅。

和 Everything、Listary 比呢？

Everything 是出色的专用文件名搜索工具，Listary 则兼有启动器和资源管理器增强。yyzTools 的文件搜索从 1.0.5 起换成自研引擎：同样是 NTFS MFT 直读加 USN 实时增量，支持 path: / ext: / size: 等兼容语法，全盘索引常驻内存约 5~30 MB。区别在于 Alt+空格 一个输入框里，文件与应用、进程、窗口、书签、剪贴板一起搜，搜到即可预览、定位或删除。如果只追求极致的文件名搜索，Everything 依然是好选择。

已经在用 PowerToys，还能装 yyzTools 吗？

可以，互不冲突。yyzTools 主进程常驻很轻，壁纸、截图等按需启动，快捷键也都能自定义。常见组合：PowerToys 管窗口分屏和键盘重映射，yyzTools 管启动、翻译、OCR 与批量处理。

和 uTools、Wox、ZTools 比呢？

uTools 是插件平台，主体免费但不少热门插件要开会员；Wox 是专注搜索的开源启动器。ZTools 是开源的 uTools 平替，功能靠插件市场拼装。yyzTools 把 40+ 模块直接打包进安装包，没有会员也没有付费解锁，剪贴板、搜索、OCR 数据都留在本机。
