什么时候选 Wallpaper Engine

如果你的目标就是桌面本身，Wallpaper Engine 无可匹敌：创意工坊数以万计的现成壁纸、带关键帧与粒子的场景编辑器、音频响应壁纸，都远在 yyzTools 的壁纸模块之外。若你看重的正是这套工艺，一次性的小额付费很值。另外 Lively 也是一款只做壁纸、免费开源的选项。

什么时候选 yyzTools

如果你不想「为了换桌面」单独装一个软件，或干脆不想为桌面花一分钱——yyzTools 把动态壁纸做进了那个本就免费的效率工具箱，同一个安装里已有启动器、文件搜索、OCR、翻译、剪贴板与清理。它不是最深的壁纸工具，只是你反正都要装的那套工具箱里的一项。

常见疑问

yyzTools 的动态壁纸和 Wallpaper Engine 一样强吗？

论纯壁纸工艺，不如。Wallpaper Engine 有完整的场景编辑器、音频响应壁纸和庞大的创意工坊生态；yyzTools 覆盖日常场景——把视频或网页设成桌面、全屏时自动暂停——但不会去和创意工坊量级的内容与编辑器比拼。

和 Lively 比怎么样？

Lively 是免费开源、只做壁纸渲染的独立软件，技术路线（网页 + 视频）相似。差别在于 yyzTools 身在效率工具箱里：如果你同时要用启动器、文件搜索、OCR，一次安装就都齐了；只想装一个专职壁纸软件的话，Lively 或 Wallpaper Engine 更合身。

会不会拖慢游戏帧率？

不会。和 Wallpaper Engine、Lively 一样，游戏或其他应用全屏时壁纸会自动暂停，把 GPU 与 CPU 让给你真正在用的程序。
