常见疑问

yyzTools 像 uTools 那样支持插件吗？

它的扩展单元是 .zenmod 命令模块——一个在命令面板注册命令的 JSON 文件，背后可挂一个网页。387 个随安装包交付，SDK 文档和样例工程免费下载。它刻意比插件市场轻：没有插件运行时，没有发布流程。

两边默认都是 Alt+Space，会冲突吗？

会，两者的默认全局快捷键都是 Alt+Space，第一次同时使用时在任意一侧改键即可（yyzTools：托盘图标 → 设置 → 快捷键）。之后互不干扰。
