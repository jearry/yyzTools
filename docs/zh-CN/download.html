下载与安装常见问题

yyzTools 完全免费吗？

是。所有功能永久免费——没有付费解锁、没有会员体系、也没有试用倒计时。

会收集我的数据吗？

不会。yyzTools 无需账号，剪贴板历史、文件搜索、OCR 都在本机处理。只有你主动使用翻译等联网功能时，输入内容才会发送给你选择的第三方服务。

需要联网吗？

只有下载、检查更新和翻译等联网功能需要网络。命令面板、文件搜索、OCR、剪贴板历史、批量处理等全部可以完全离线使用。

系统要求是什么？

64 位 Windows 10（1809 及以上）或 Windows 11，约 600 MB 磁盘空间，需要 Microsoft Edge WebView2 运行时——Win11 已预装，Win10 缺失时安装程序会引导安装。
