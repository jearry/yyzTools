下载与安装常见问题

Q01 yyzTools 完全免费吗？

是。所有功能永久免费——没有付费解锁、没有会员体系、也没有试用倒计时。

Q02 会收集我的数据吗？

不会。yyzTools 无需账号，剪贴板历史、文件搜索、OCR 都在本机处理。只有你主动使用翻译等联网功能时，输入内容才会发送给你选择的第三方服务。

Q03 需要联网吗？

只有下载、检查更新和翻译等联网功能需要网络。命令面板、文件搜索、OCR、剪贴板历史、批量处理等全部可以完全离线使用。

Q04 系统要求是什么？

64 位 Windows 10（1809 及以上）或 Windows 11，约 600 MB 磁盘空间，需要 Microsoft Edge WebView2 运行时——Win11 已预装，Win10 缺失时安装程序会引导安装。

Q05 运行安装包时 Windows 提示「Windows 已保护你的电脑」怎么办？

这是 Microsoft Defender SmartScreen 对未经代码签名程序的通用提醒，首次运行时可能出现。点击「更多信息」→「仍要运行」即可继续安装；你也可以先用页面上的 SHA-256 校验值核对文件完整性。

Q06 安装包会捆绑其他软件或修改浏览器设置吗？

不会。安装包只包含 yyzTools 本体与其运行所需的内置组件（FFmpeg、OCR 模型等，均为本地功能的依赖），不捆绑任何第三方软件、不设浏览器主页劫持、无开机自启之外的驻留进程。用页面上的 SHA-256 校验值可核对文件完整性。

Q07 如何彻底卸载 yyzTools？

在系统「设置 → 应用」或安装目录中运行卸载程序即可。卸载时可选择是否一并删除用户数据（配置、剪贴板历史、使用统计等都在你的用户目录下，不进注册表深处的散落项）；默认安装到用户目录，卸载后无残留服务与开机自启项。
