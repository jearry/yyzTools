开发 yyzTools 模块

一个模块就是普通的 HTML/JS 页面加一份 .zenmod 描述文件，无需框架、无需构建。选择你的起点。

快速入门指南

从零创建一个运行在 yyzTools 内的 Web 应用：页面目录、窗口宿主、多语言、异步 Native API、配置持久化。纯原生 JS，免构建。

接口参考手册

yyzTools Native API 完整接口定义：窗口控制、应用管理、进程、文件操作、媒体处理、截图 OCR、加密、剪贴板、书签、命令执行与更新。

下载样例工程

开箱即用的完整模块。把其中的 Web 与 Modules 两个目录复制到 yyzTools.exe 所在目录（与同名目录合并），重启后命令面板即可搜到它。随包附两份英文文档。
