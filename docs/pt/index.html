Perguntas frequentes

É realmente gratuito para sempre? Vocês vão começar a cobrar?

É realmente gratuito. Sem desbloqueios pagos, sem planos de assinatura e sem deixar os recursos essenciais atrás de um paywall. Queremos que o yyzTools seja uma ferramenta que você goste de manter na sua área de trabalho por muito tempo, e não mais uma assinatura.

Meus dados são enviados para algum lugar?

Não. Histórico da área de transferência, busca de arquivos, estatísticas de uso e OCR são processados e guardados localmente. Somente quando você usa ativamente um recurso online, como a tradução, o conteúdo que você digita é enviado ao serviço de terceiros que você escolheu. Além disso, o programa verifica periodicamente se há atualizações: essa requisição transmite apenas números de versão.

É preciso criar uma conta?

Não. O programa não exige cadastro e não coleta informações que o identifiquem.

Quais sistemas são compatíveis?

Windows 10 e Windows 11 em suas versões de 64 bits. É necessário o runtime Microsoft Edge WebView2: o Windows 11 já o inclui e, no Windows 10, o instalador orienta você a adicioná-lo caso esteja ausente.

Consome muitos recursos?

O processo principal residente é bem leve, e o papel de parede, as capturas e as dicas de teclado rodam como processos separados que só iniciam quando usados. O modo jogo pausa o papel de parede e os efeitos com um único clique.

Como adiciono meus próprios recursos?

Coloque um arquivo JSON .zenmod na pasta Modules do diretório de instalação com o nome, o ícone e o comando a executar. Após reiniciar, ele já aparece nas buscas do CmdPlate, sem compilar nenhum código.
