Crie módulos para o yyzTools

Um módulo é uma página HTML/JS comum mais um arquivo .zenmod — sem frameworks e sem etapa de build. Escolha por onde começar.

Introdução

Crie do zero uma aplicação web que corre dentro do yyzTools: estrutura da página, host de janela, i18n, APIs nativas assíncronas e persistência de configuração. Sem compilação.

Referência da API

Referência completa da API nativa do yyzTools: janelas, aplicações, processos, ficheiros, multimédia, OCR, cifragem, área de transferência, marcadores, comandos e atualizações.

Baixar projeto de exemplo

Um módulo completo e executável. Copie as pastas Web e Modules para a pasta do yyzTools.exe — elas se mesclam às que já estão lá — e reinicie: o painel de comandos o encontrará. Inclui os dois documentos em inglês.
