Privacy policy

Effective date: August 8, 2026 ·Version: v1.0

This policy explains how yyzTools (the "Software") handles your data. The core principle in one phrase: local-first — anything that can be done on your machine never leaves it. This policy expands on section 3 of the User Agreement; where the two differ, this policy governs.

1. What we do not collect

The Software requires no account. It does not collect your name, phone number, email address, or other identifying information, and there is no profiling or analytics telemetry of any kind.

We hold no server-side record of your usage — because the Software never sends usage data to us in the first place.

2. Data processed and stored locally

The following is collected, processed, and stored on your own device, in local configuration files and databases, and is never uploaded by the Software on its own:

  • Clipboard history: the text and images you have copied.
  • App usage statistics: foreground time and launch counts per application.
  • File search and preview: the local file index and paths you have opened.
  • OCR: recognition runs in the local RapidOCR engine; images never leave the machine.
  • Configuration and preferences: shortcuts, dock entries, wallpaper settings, interface language.
  • CmdPlate history: your search terms and the items you have launched.

3. Features that require a network

Only the following produce network requests, and each is triggered by your own action:

  • Super translate: the text or image you submit is sent to the third-party translation service you selected in settings. That data is handled by the third party under its own privacy policy and is outside our control.
  • Downloader: connects directly to the target server for the URL you entered.
  • Command modules and navigation page: the built-in browser visits the site directly when opening a URL.
  • Live wallpaper: if you use an online page as a wallpaper source, that page is fetched.

If you would rather nothing left your machine, simply do not use the features above — everything else works fully offline.

4. Update checks

The Software periodically requests a version manifest from official mirrors (GitHub, jsDelivr, and similar) to determine whether a newer release exists. That request carries only what is necessary, such as version numbers, and contains none of your personal or usage data.

You can disable automatic checks in settings and check manually from the tray menu instead.

5. Your control over your data

  • All local data lives under your user directory, where you can inspect, back up, export, or delete it at any time.
  • Clipboard history entries can be removed individually or cleared in bulk from CmdPlate.
  • Uninstalling offers to delete the data directory as well; that deletion is irreversible.

6. Third-party components

The Software bundles the following open-source or free components, each distributed under its own licence: Microsoft Edge WebView2, FFmpeg, ImageMagick, Ghostscript, pdfcpu, RapidOCR, Aria2, 7-Zip, and OpenSSL. All are invoked as local processes and play no part in uploading data.

7. Children’s privacy

The Software is a general-purpose desktop utility. It is not designed for children and does not collect age-related information.

8. Website analytics

When you visit this website (yyztools.com), we use Cloudflare Web Analytics to collect anonymous, aggregated traffic statistics — such as page views, referral sources, approximate region, and device type — to understand which content is popular and to improve the site. The service uses no cookies and gathers no personally identifiable information; the data is aggregated and processed by Cloudflare under its own privacy policy.

9. Changes and contact

If this policy is revised, the new effective date will be shown on this page. Where a change materially affects how data is handled, we will call it out in the release notes as well. For any questions, reach us by email or via GitHub Issues below.
