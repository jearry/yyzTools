1. About the Software

yyzTools (Yes Your Zen Tools) is a desktop productivity toolkit for Windows. We aim to bring the frequent, trivial needs of everyday work and creation together into a ready-to-use toolbox—so you no longer have to wander through uneven plugin markets, filtering, installing, and paying for each small feature individually. Install once, and the tools you need are ready at hand.

The main capabilities currently provided include (continuously updated):

  • Command Panel: a unified entry point for searching apps, files, bookmarks, clipboard, windows, and processes, with a built-in command line and calculator;
  • Launch & Productivity: dock, clipboard history, app usage statistics, screen capture & pin-to-desktop, reminder assistant, perpetual calendar;
  • Text & Language: super translation, OCR (text recognition), regular expressions, encode / decode, hash calculation, encryption / decryption;
  • Files & Media: file preview, batch file rename, batch image processing, batch video processing, batch PDF processing, file download;
  • Calculation & Extensions: calculation scratchpad, QR code generation & recognition, AI quick entry;
  • Personalization: dynamic wallpaper, desktop effects, game mode.

3. Privacy &amp; Data Handling (Important)

We take your privacy seriously. The Software follows a "local-first" principle:

  1. Local processing first: Data involved in features such as clipboard history, app usage statistics, file search and preview, desktop effects, and the command panel is collected, processed, and stored locally on your device, in local configuration files and databases, and is never actively uploaded to our servers by the Software.
  2. Online features: When you use features that require a network connection, such as "Super Translation", the text or image data you input will be sent to the corresponding third-party online service according to your chosen configuration to complete processing. Such data is handled by the third party under its own privacy policy and is outside our control. To prevent any data from being sent out, you may disable the relevant feature or avoid using online capabilities.
  3. Automatic update check: The Software periodically requests a version manifest from official mirrors (such as GitHub, jsDelivr) to determine whether an update is needed. This process transmits only necessary information such as version numbers and does not involve any of your personal data.
