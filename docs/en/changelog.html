v1.0.0.1000

2026-08-08
  • Every feature page is now localised, with Simplified Chinese and English.
  • New data generator module: UUID / GUID, ULID, random strings, and test data.
  • New batch PDF module: merge, split, watermark, compress, encrypt, and decrypt.
  • New batch image and video modules, built on ImageMagick and FFmpeg.
  • Command modules expanded to 379, adding AI and popular-website entries.
  • Replaced NirCmd.exe with our own yyzCmd.exe — system commands are now pure Win32.
  • Scrolling capture now stitches automatically; clipboard images can be pinned to the desktop.
  • Switched to per-package updates, so a check downloads only what changed.
