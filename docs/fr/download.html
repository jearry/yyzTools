Étapes d’installation

  1. 01 Téléchargez l’installateur ci-dessus et lancez-le.
  2. 02 Choisissez la langue de l’interface quand elle vous est demandée ; les autres valeurs par défaut conviennent.

À propos des mises à jour

yyzTools se met à jour par paquets : programme principal, pages de l’interface, modules de commandes, FFmpeg, modèles OCR, etc. sont empaquetés séparément. Une vérification ne télécharge donc que ce qui a réellement changé, sans réinstaller tout le logiciel.

FAQ téléchargement et installation

Q01 yyzTools est-il vraiment gratuit ?

Oui. Toutes les fonctions sont gratuites à vie : aucun déblocage payant, aucun abonnement, aucun compte à rebours d’essai.

Q02 Collecte-t-il mes données ?

Non. yyzTools ne demande aucun compte et traite l’historique du presse-papiers, la recherche de fichiers et l’OCR localement sur votre machine. Seules les fonctions en ligne que vous utilisez activement, comme la traduction, envoient votre saisie au service tiers de votre choix.

Q03 Faut-il une connexion Internet ?

Uniquement pour le téléchargement, la vérification des mises à jour et les fonctions en ligne comme la traduction. Tout le reste - palette de commandes, recherche de fichiers, OCR, historique du presse-papiers, traitements par lots - fonctionne entièrement hors ligne.

Q04 Quelle est la configuration requise ?

Windows 10 64 bits (1809 ou ultérieur) ou Windows 11, environ 600 Mo d’espace disque et le runtime Microsoft Edge WebView2 - préinstallé sur Windows 11 ; sur Windows 10, l’installateur vous guide s’il est absent.

Q05 Windows affiche « Windows a protégé votre PC » quand je lance l'installateur. Que faire ?

Il s'agit de Microsoft Defender SmartScreen, un avertissement standard pour les programmes sans certificat de signature de code, qui peut apparaître au premier lancement. Cliquez sur « Informations complémentaires » → « Exécuter quand même » pour continuer l'installation. Vous pouvez aussi vérifier le fichier avec les sommes de contrôle SHA-256 affichées sur cette page.

Q06 L'installateur intègre-t-il d'autres logiciels ou modifie-t-il les paramètres du navigateur ?

Non. L'installateur ne contient que yyzTools et les composants intégrés nécessaires à son fonctionnement (FFmpeg, modèles OCR et autres dépendances des fonctions locales). Aucun logiciel tiers n'est ajouté, la page d'accueil du navigateur n'est pas détournée, et aucun processus ne réside au-delà de l'entrée facultative de démarrage automatique. Vous pouvez vérifier le fichier avec les sommes de contrôle SHA-256 affichées sur cette page.

Q07 Comment désinstaller complètement yyzTools ?

Lancez le programme de désinstallation depuis « Paramètres → Applications » ou depuis le dossier d'installation. Vous pouvez choisir de supprimer également les données utilisateur (configuration, historique du presse-papiers, statistiques d'utilisation — tout est conservé dans votre profil utilisateur, sans se disperser dans le registre). L'application s'installe par défaut dans votre répertoire utilisateur ; après désinstallation, aucun service ni élément de démarrage ne subsiste.
