Vous cherchez une alternative à uTools ?

uTools est un lanceur axé plugins : un cœur ultra-léger plus un marché de 3 000+ plugins, avec un plafond d’installation en offre gratuite que l’abonnement lève. yyzTools mise sur l’inverse — 387 modules déjà dans une seule installation, tous opérationnels dès la première seconde, sans plafond, sans abonnement ni compte.

Ni plafond, ni abonnement, ni montage

L’offre gratuite de uTools plafonne le nombre de plugins installables — et lever ce plafond est précisément la valeur de l’abonnement. yyzTools n’a pas d’équivalent : l’installateur embarque déjà 387 modules fonctionnels, il n’y a rien à plafonner ni à déverrouiller — lanceur, recherche de fichiers, OCR, traduction, historique du presse-papiers et traitements par lots y sont dès le premier jour.

Quand uTools reste le bon choix

Si vous voulez une plateforme plus qu’un produit — 3 000+ plugins communautaires, un usage croisé Windows, macOS et Linux, des besoins de niche qu’aucune suite finie n’a prévus — l’écosystème de uTools dépasse largement ce qu’un installateur peut embarquer. Pour les amoureux des plugins, il reste la maison naturelle.

Quand yyzTools est le meilleur choix

Si vous préférez ne pas monter votre boîte à outils à la main — sans parcourir un marché, sans plafond d’installation, sans abonnement pour le lever, sans compte — yyzTools vous remet 387 modules fonctionnels dès le premier jour : lanceur, recherche sur tout le disque, OCR, traduction, historique du presse-papiers, traitements par lots et plus, gratuit aussi en entreprise.

Questions fréquentes

yyzTools prend-il en charge les plugins comme uTools ?

Son unité d’extension est le module de commande .zenmod — un fichier JSON qui enregistre des commandes dans la palette, avec une page web optionnelle derrière. 387 sont livrés dans la boîte, et un SDK avec documentation et projet d’exemple se télécharge gratuitement. C’est volontairement plus léger qu’un marché de plugins : ni runtime dédié, ni processus de publication.

Les deux se lancent sur Alt+Space — est-ce que ça se marche dessus ?

Oui, la touche globale par défaut est Alt+Space des deux côtés : changez-la d’un côté ou de l’autre à la première utilisation simultanée (yyzTools : icône de la zone de notification → Paramètres → Raccourcis). Ensuite, aucune interférence.

Qu’est-ce qui est exactement limité dans l’offre gratuite de uTools ?

La ligne officielle de uTools est « cœur gratuit pour toujours, services premium payants » : l’offre gratuite plafonne les installations de plugins, l’illimité exige un abonnement qui regroupe aussi la synchronisation multi-appareils. yyzTools n’a pas de tel concept — chaque module est livré dans l’installateur.
