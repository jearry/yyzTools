WinDirStat 2.x is a revived, well-built classic: multithreaded NTFS scanning, treemap, duplicate finder, dark mode. yyzTools' analyzer takes a different architecture — it reads from a resident indexing service (MFT snapshot + USN increments), so drilling into any folder answers instantly — and it doesn't stop at the picture: reveal, recycle, search the same files, and run a 152-rule cleanup, all in one install.

The treemap that doesn't rescan

yyzTools' analyzer doesn't scan at all in the classic sense: a resident Windows service holds each volume's MFT snapshot and applies USN journal increments as the disk changes. Drilling from C: into a deep folder is one query against live index data — the picture is already there. That same service powers instant file search, so the folder you just analyzed is searchable by name in the next keystroke.

When WinDirStat is still the right pick

WinDirStat is free, open source (GPLv2), actively maintained again, and its 2.x line is genuinely good: fast direct NTFS scanning, duplicate detection by content, extension statistics, report export and Explorer integration. If you want a pure standalone analyzer — or the duplicate finder is the mission — it remains an excellent specialist.

When yyzTools is the better fit

If your real question is "what's hogging the disk, and how do I clean it without installing another program," yyzTools answers both: a treemap that answers instantly from the resident index, then recycle, search and a 152-rule cleanup on the same files — inside the free toolbox that also carries the launcher, OCR and translation.

Common questions

Is yyzTools' analyzer faster than WinDirStat?

Not comparable as-is: WinDirStat 2.x scans with multithreaded direct NTFS reads and is fast for a one-shot scan. yyzTools doesn't scan on demand — a resident service maintains an MFT snapshot with USN increments, so browsing the treemap and drilling into folders reads prebuilt data. First answer is instant; the trade-off is a resident background service.

I already use WinDirStat — why switch?

Keep it if it serves you well. yyzTools earns its place when analysis is step one: from the same window you can recycle the hogs, jump into full-disk file search, and run a 152-rule cleanup — and the analyzer ships inside the free toolbox with launcher, OCR and translation.

Does the resident service slow my PC down?

It's the same indexing service that powers yyzTools' file search (f␣ in the launcher). The MFT snapshot is built once and maintained with low-cost USN journal increments; after that, analysis and search add no disk-wide rescans.
