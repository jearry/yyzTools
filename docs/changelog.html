Changelog

Versions follow major.minor.patch.build.

v1.0.2.1200

Latest 2026-08-14
  • The command-palette file module now supports batch copy, cut, and delete (Shift/Ctrl multi-select, Ctrl+A to select all).
  • Fixed garbled DXF previews in the command-palette file module.
  • Faster PDF loading in the command-palette file module.
  • Fixed an intermittent error in Data conversion / Structured text.
  • The Earth Defender game adds more languages and sound effects.
  • Settings now supports import and export.
  • Screenshot now exits after a successful save.
  • Added sample buttons to Encode/Decode and Regex tester.
  • The dock now supports URLs.

v1.0.0.1000

2026-08-08
  • Every feature page is now localised, in 10 languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, French, German, Spanish, Russian, and Arabic.
  • New data generator module: UUID / GUID, ULID, random strings, and test data.
  • New batch PDF module: merge, split, watermark, compress, encrypt, and decrypt.
  • New batch image and video modules, built on ImageMagick and FFmpeg.
  • Command modules expanded to 379, adding AI and popular-website entries.
  • Replaced NirCmd.exe with our own yyzCmd.exe — system commands are now pure Win32.
  • Scrolling capture now stitches automatically; clipboard images can be pinned to the desktop.
  • Switched to per-package updates, so a check downloads only what changed.
