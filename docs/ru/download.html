yyzTools обновляется по пакетам: основная программа, страницы интерфейса, командные модули, FFmpeg, модели OCR и прочее упакованы отдельно, поэтому при проверке обновлений загружается только то, что действительно изменилось, — переустанавливать всю программу не требуется.

Частые вопросы о загрузке и установке

Q01 yyzTools действительно полностью бесплатен?

Да. Все функции бесплатны навсегда: ни платной разблокировки, ни подписки, ни отсчёта пробного периода.

Q02 Программа собирает мои данные?

Нет. yyzTools не требует учётной записи и обрабатывает историю буфера обмена, поиск файлов и OCR локально на вашем компьютере. Только сетевые функции, которые вы сами используете, например перевод, отправляют введённый текст выбранному вами стороннему сервису.

Q03 Нужно ли подключение к интернету?

Только для загрузки, проверки обновлений и сетевых функций вроде перевода. Всё остальное - командная панель, поиск файлов, OCR, история буфера обмена, пакетная обработка - полностью работает офлайн.

Q04 Каковы системные требования?

64-битные Windows 10 (1809 или новее) или Windows 11, около 600 МБ на диске и среда выполнения Microsoft Edge WebView2 - она встроена в Windows 11, а в Windows 10 установщик поможет её установить при отсутствии.

Q05 При запуске установщика Windows показывает «Система Windows защитила ваш компьютер». Что делать?

Это Microsoft Defender SmartScreen — стандартное предупреждение для программ без сертификата подписи кода, которое может появиться при первом запуске. Нажмите «Подробнее» → «Выполнить в любом случае», чтобы продолжить установку. Подлинность файла также можно проверить по контрольным суммам SHA-256, указанным на этой странице.

Q06 Устанавливает ли инсталлятор сторонний софт или меняет настройки браузера?

Нет. В инсталлятор входят только сам yyzTools и встроенные компоненты, необходимые для работы (FFmpeg, модели OCR и другие зависимости локальных функций). Никакого стороннего ПО, никакого захвата домашней страницы браузера и никаких резидентных процессов, кроме необязательной записи автозапуска. Подлинность файла можно проверить по контрольным суммам SHA-256 на этой странице.

Q07 Как полностью удалить yyzTools?

Запустите деинсталлятор из «Параметры → Приложения» или из папки установки. При удалении можно выбрать, удалять ли заодно пользовательские данные (настройки, историю буфера обмена, статистику использования — всё хранится в вашем профиле, а не рассыпано по реестру). Приложение по умолчанию ставится в пользовательский каталог; после удаления не остаётся ни служб, ни записей автозапуска.
