Системные требования

Операционная система
Windows 10 1809 или новее / Windows 11 (64 бита)
Среда выполнения
Microsoft Edge WebView2 (встроена в Windows 11; в Windows 10 установщик поможет её установить, если она отсутствует)
Место на диске
Около 600 МБ, включая встроенные FFmpeg, ImageMagick и модели OCR
Права
По умолчанию установка в пользовательский каталог — права администратора не нужны

Порядок установки

  1. Скачайте установщик выше и запустите его.
  2. Выберите язык интерфейса, остальные параметры можно оставить по умолчанию.
  3. После установки нажмите Alt+Space, чтобы открыть командную панель, и начинайте работу.
  4. Через значок в области уведомлений доступны настройки, переключение обоев и эффектов, проверка обновлений.

Об обновлениях

yyzTools обновляется по пакетам: основная программа, страницы интерфейса, командные модули, FFmpeg, модели OCR и прочее упакованы отдельно, поэтому при проверке обновлений загружается только то, что действительно изменилось, — переустанавливать всю программу не требуется.

Частые вопросы о загрузке и установке

yyzTools действительно полностью бесплатен?

Да. Все функции бесплатны навсегда: ни платной разблокировки, ни подписки, ни отсчёта пробного периода.

Программа собирает мои данные?

Нет. yyzTools не требует учётной записи и обрабатывает историю буфера обмена, поиск файлов и OCR локально на вашем компьютере. Только сетевые функции, которые вы сами используете, например перевод, отправляют введённый текст выбранному вами стороннему сервису.

Нужно ли подключение к интернету?

Только для загрузки, проверки обновлений и сетевых функций вроде перевода. Всё остальное - командная панель, поиск файлов, OCR, история буфера обмена, пакетная обработка - полностью работает офлайн.

Каковы системные требования?

64-битные Windows 10 (1809 или новее) или Windows 11, около 600 МБ на диске и среда выполнения Microsoft Edge WebView2 - она встроена в Windows 11, а в Windows 10 установщик поможет её установить при отсутствии.
