Частые вопросы

yyzTools поддерживает плагины, как uTools?

Его единица расширения — командный модуль .zenmod: JSON-файл, регистрирующий команды в палитре, с опциональной веб-страницей за ними. 387 идут в комплекте, SDK с документацией и образцом скачивается бесплатно. Это нарочно легче плагин-магазина: ни плагин-рантайма, ни процесса публикации.

Оба запускаются по Alt+Space — конфликтуют?

Да, глобальная клавиша по умолчанию — Alt+Space у обоих: поменяйте её на любой из сторон при первом совместном использовании (yyzTools: значок в трее → Настройки → Горячие клавиши). Дальше они не мешают друг другу.

Что именно ограничено в бесплатном тарифе uTools?

Официальная формула uTools — «ядро бесплатно навсегда, премиум-сервисы платные»: бесплатный тариф ограничивает число устанавливаемых плагинов, безлимит требует подписки, куда входит и синхронизация между устройствами. В yyzTools такого понятия нет — каждый модуль приходит в установщике.
