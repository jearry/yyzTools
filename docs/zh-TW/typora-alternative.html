常見疑問

yyzTools 能替代 Typora 嗎？

核心寫作可以：所見即所得、GFM、KaTeX 公式、Mermaid、圖片自動落盤與自動儲存都有。但 Typora 的匯出格式、主題生態、大綱與檔案樹、拼字檢查以及 macOS / Linux 支援，這裡沒有對應物。重度寫作或需要匯出交付的使用者建議保留 Typora——它是買斷制，一次付費長期可用。

圖片是怎麼存放的？

貼上、複製或拖入的圖片會自動儲存到文件所在目錄的 assets/ 子目錄，文件裡寫入相對路徑引用——整個文件目錄可以整體移動、打包或放進 Git，圖片不會丟。尚未另存為的文件插入圖片時會先提示另存為。

支援數學公式和 Mermaid 圖表嗎？

支援。行內公式用 $..$，區塊公式用 $$..$$（KaTeX 渲染）；Mermaid 程式碼區塊可點預覽為 SVG，兩者都是動態載入，不拖慢首屏。

需要匯出 PDF 或 Word 嗎？

可以匯出 PDF 和 HTML——匯出選單裡兩項都有，所見即所得（PDF 經系統列印引擎產生）。Word / EPUB 等格式沒有內建，需要的話，Typora 仍是更順手的選擇。
