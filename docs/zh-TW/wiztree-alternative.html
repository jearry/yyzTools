什麼時候 WizTree / TreeSize 仍是好選擇

如果你要的是純粹專業的磁碟分析——極限掃描與重掃更快、報告列印匯出、掃網路共用碟與非 NTFS / 可移動卷——WizTree、TreeSize 在這一件專門的事上更成熟更全面。yyzTools 不追求做最深的獨立分析器。

什麼時候選 yyzTools

如果你的真實問題是「我的 C 碟怎麼滿了、不想再裝一個軟體怎麼解決」，yyzTools 一次答兩件事：掃成 treemap，再就地處理那些檔案——定位、回收、搜尋、跑檔案清理——都在這套本就帶啟動器、OCR、翻譯的免費工具箱裡。

常見疑問

yyzTools 的分析器比 WizTree 快嗎？

兩者都直讀 NTFS $MFT，掃大容量磁碟都是幾秒而非幾分鐘。WizTree 專做此事，在極限掃描、重掃上可能更快更成熟；yyzTools 的長處在掃描「之後」能做什麼，而不是把那零點幾秒摳下來。

我已經有 WizTree / WinDirStat 了，還需要嗎？

如果只想看佔用，留著它們即可，它們很強。等你厭倦了「一個看佔用、一個清垃圾、一個找檔案」要裝好幾個時，再把它們併成一個才輪到 yyzTools。

能掃網路碟 / 隨身碟嗎？

目前以本機固定 NTFS 卷為主，網路共用與非 NTFS / 可移動碟支援有限——這是與 WizTree、TreeSize 的真實差距之一。
