什麼時候 Everything 仍是好選擇

如果你只需要極致的檔名搜尋——比如正則表示式查詢、HTTP 伺服器分享、透過 SDK 做二次整合，或者要索引非 NTFS 與可攜式磁碟——Everything 依然是成熟可靠的專業工具。yyzTools 的自研引擎目前只索引固定 NTFS 磁碟，也不支援 regex:，不打算在每個細分場景都取代它。

什麼時候選 yyzTools

如果你想用一個工具取代「啟動器 + 檔案搜尋」的組合——比如 PowerToys Run 管啟動、Everything 管檔案的雙工具搭配——yyzTools 一次裝齊：Alt+空白鍵 同一個輸入框裡搜應用程式、檔案、處理程序、視窗、書籤、剪貼簿，搜到即可預覽、定位、刪除，背後還有翻譯、OCR、剪貼簿歷史、批次處理等 387 個模組隨取隨用。

常見疑問

yyzTools 的檔案搜尋是套殼 Everything 嗎？

不是。從 1.0.5 起，檔案搜尋改為完全自研的引擎（直讀 NTFS $MFT + USN Journal 即時增量），Everything 依賴已從安裝檔中移除，索引記憶體占用從數百 MB 降到 5~30 MB 左右。

查詢語法和 Everything 相容嗎？

常用語法相容：path:、ext:、size:、datemodified:、萬用字元以及 AND / OR / NOT 組合都可以直接用。暫不支援 regex: 正則，這是與 Everything 的主要語法差距。

可以和 Everything 同時安裝嗎？

可以，兩者互不衝突。不過如果 yyzTools 的檔案搜尋已經滿足需要，只保留一個會更省資源。
