yyzTools vs PowerToys

兩者都是「全家桶」，但押的注不同。PowerToys 深挖 Windows 系統本身——視窗佈局、鍵位重映射、系統微調；yyzTools 把你每天要用的工具——搜尋、OCR、翻譯、剪貼簿、批次、桌布——打包進一次輕量安裝。

剪貼簿能讀你複製的圖

複製一張含文字的圖片（截圖或圖片檔），yyzTools 會在背景自動 OCR，把文字連同圖片一起存進歷史；之後你能用只存在於圖裡的文字把它搜出來，也能一鍵只把辨識出的文字複製回去。Win+V 只存圖不辨識，Text Extractor 讀一次就走，兩者都不會沉澱成可搜尋的文字歷史。

什麼時候 PowerToys 仍是好選擇

如果你想改造的是 Windows 本身——FancyZones 視窗分屏、Keyboard Manager 鍵位重映射，或一大套深度系統工具，且全程開源、由微軟背書——那 PowerToys 更專更強，還能只啟用你要的模組。yyzTools 目前不提供視窗分屏和鍵位重映射。

什麼時候選 yyzTools

如果你想用一個應用替代「PowerToys Run + 檔案搜尋 + 剪貼簿管理 + 截圖 OCR + 翻譯」這一摞，還要複製的圖片能變可搜文字，外加圖片/影片/PDF 批次、動態桌布與下載管理——yyzTools 一次輕量安裝全包，鍵盤優先，12 語可用。

常見疑問

yyzTools 能完全替代 PowerToys 嗎？

在「啟動器 + 工具箱」的交集上大體可以。PowerToys 有 yyzTools 還沒有的系統工具，主要是 FancyZones 與 Keyboard Manager；反之 yyzTools 有 PowerToys 缺的內建項，如真正的翻譯、自研全碟搜尋、可搜 OCR 剪貼簿、影片與 PDF 批次、動態桌布。看你實際要用哪一塊交集。

兩個能同時裝嗎？

能，互不衝突。只需注意全域熱鍵——兩者預設都用 Alt+空格——把其中一個的啟動熱鍵改掉即可。

可 OCR 的剪貼簿具體能做什麼？

複製一張含文字的圖片（截圖或圖片檔）時，yyzTools 會跑 OCR 並把文字存進剪貼簿歷史。之後你能用只出現在那張圖裡的文字搜到它，也能只複製辨識出的文字。Win+V 存圖卻不辨識，Text Extractor 是一次性擷取、不留歷史。
