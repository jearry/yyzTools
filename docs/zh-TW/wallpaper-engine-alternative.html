什麼時候選 Wallpaper Engine

如果你的目標就是桌面本身，Wallpaper Engine 無可匹敵：創意工坊數以萬計的現成桌布、帶關鍵影格與粒子的場景編輯器、音訊響應桌布，都遠在 yyzTools 的桌布模組之外。若你看重的正是這套工藝，一次性的小額付費很值。另外 Lively 也是一款只做桌布、免費開源的選項。

什麼時候選 yyzTools

如果你不想「為了換桌面」單獨裝一個軟體，或乾脆不想為桌面花一分錢——yyzTools 把動態桌布做進了那個本就免費的效率工具箱，同一個安裝裡已有啟動器、檔案搜尋、OCR、翻譯、剪貼簿與清理。它不是最深的桌布工具，只是你反正都要裝的那套工具箱裡的一項。

常見疑問

yyzTools 的動態桌布和 Wallpaper Engine 一樣強嗎？

論純桌布工藝，不如。Wallpaper Engine 有完整的場景編輯器、音訊響應桌布和龐大的創意工坊生態；yyzTools 覆蓋日常場景——把影片或網頁設成桌面、全螢幕時自動暫停——但不會去和創意工坊量級的內容與編輯器比拼。

和 Lively 比怎麼樣？

Lively 是免費開源、只做桌布渲染的獨立軟體，技術路線（網頁 + 影片）相似。差別在於 yyzTools 身在效率工具箱裡：如果你同時要用啟動器、檔案搜尋、OCR，一次安裝就都齊了；只想裝一個專職桌布軟體的話，Lively 或 Wallpaper Engine 更合身。

會不會拖慢遊戲影格率？

不會。和 Wallpaper Engine、Lively 一樣，遊戲或其他應用全螢幕時桌布會自動暫停，把 GPU 與 CPU 讓給你真正在用的程式。
