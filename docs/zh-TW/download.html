下載與安裝常見問題

Q01 yyzTools 完全免費嗎？

是。所有功能永久免費--沒有付費解鎖、沒有會員制、也沒有試用倒數。

Q02 會蒐集我的資料嗎？

不會。yyzTools 無需帳號，剪貼簿歷史、檔案搜尋、OCR 都在本機處理。只有你主動使用翻譯等連網功能時，輸入內容才會傳給你選擇的第三方服務。

Q03 需要連網嗎？

只有下載、檢查更新和翻譯等連網功能需要網路。命令面板、檔案搜尋、OCR、剪貼簿歷史、批次處理等全部可以完全離線使用。

Q04 系統需求是什麼？

64 位元 Windows 10（1809 及以上）或 Windows 11，約 600 MB 磁碟空間，需要 Microsoft Edge WebView2 執行階段--Win11 已預裝，Win10 缺少時安裝程式會引導安裝。

Q05 執行安裝包時 Windows 提示「Windows 已保護您的電腦」怎麼辦？

這是 Microsoft Defender SmartScreen 對未經程式碼簽署程式的通用提醒，首次執行時可能出現。點擊「更多資訊」→「仍要執行」即可繼續安裝；您也可以先用頁面上的 SHA-256 校驗值核對檔案完整性。

Q06 安裝包會捆綁其他軟體或修改瀏覽器設定嗎？

不會。安裝包只包含 yyzTools 本體與其執行所需的內建元件（FFmpeg、OCR 模型等，皆為本機功能的相依元件），不捆綁任何第三方軟體、不設瀏覽器首頁劫持、無開機自啟之外的常駐程序。可用頁面上的 SHA-256 校驗值核對檔案完整性。

Q07 如何徹底解除安裝 yyzTools？

在系統「設定 → 應用程式」或安裝目錄中執行解除安裝程式即可。解除安裝時可選擇是否一併刪除使用者資料（設定、剪貼簿歷史、使用統計等都在您的使用者目錄下，不散落登錄檔深處）；預設安裝到使用者目錄，解除安裝後無殘留服務與開機自啟項。
