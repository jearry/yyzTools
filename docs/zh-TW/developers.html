開發 yyzTools 模組

一個模組就是一般的 HTML/JS 頁面加一份 .zenmod 描述檔，無需框架、無需建置。選擇你的起點。

快速入門指南

從零建立一個執行在 yyzTools 內的 Web 應用：頁面目錄、視窗宿主、多語言、非同步 Native API、設定持久化。純原生 JS，免建置。

介面參考手冊

yyzTools Native API 完整介面定義：視窗控制、應用管理、行程、檔案操作、媒體處理、螢幕擷取 OCR、加密、剪貼簿、書籤、命令執行與更新。
