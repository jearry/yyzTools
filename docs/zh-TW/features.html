功能清單

依使用情境分成六類。所有功能都包含在同一個安裝檔裡，沒有額外購買項目。

yyzTools（全稱 Yes Your Zen Tools）是一款免費、本機優先的 Windows 桌面效率工具集，內建 40+ 模組：命令面板、程式啟動列、剪貼簿歷史、超級翻譯、OCR、檔案預覽、批次重新命名與圖片/影片/PDF 批次處理、動態桌布、桌面特效。一個安裝檔，12 種語言，無需帳號，永久免費。

命令面板 啟動與效率 文字與語言 檔案與媒體 計算與擴充 個人化 對比

命令面板

按 Alt+空白鍵 喚出的統一入口，一個搜尋框貫穿整台電腦。

應用程式搜尋 預設

搜尋並啟動 Win32 / UWP 應用程式、系統命令、系統設定，支援以管理員身分執行與開啟檔案位置。

檔案搜尋 f␣

自研索引引擎秒級全磁碟檢索，記憶體佔用極低，可直接開啟、預覽、定位或刪除到資源回收筒。

處理程序管理 p␣

搜尋處理程序並執行 / 暫停、結束、重新啟動，無需再開工作管理員。

視窗管理 w␣

搜尋視窗並顯示 / 隱藏、置頂 / 取消置頂、關閉。

書籤搜尋 b␣

檢索瀏覽器書籤，以一般或隱私模式開啟。

剪貼簿歷史 c␣

回溯文字與圖片歷史記錄，點選即回填。

命令列 >␣

直接執行命令，支援以管理員身分執行。

即時計算 =␣

邊輸入邊出結果，算式與結果圖形化呈現，按 Enter 複製。

啟動與效率

把重複動作壓縮成一次快速鍵。

程式啟動列

常用應用程式與網址的浮動啟動列，分組管理，隨手可及。

剪貼簿歷史

在背景記錄文字與圖片，支援把圖片釘在桌面之上。

應用程式統計

記錄各應用程式的使用時長與啟動次數，用圖表看清時間去了哪裡。

螢幕截圖

區域截圖、滾動截圖（自動拼接）、貼圖釘在畫面上，獨立處理程序互不拖累。

螢幕錄製

錄製螢幕與音訊、自選網路攝影機區域，鏡頭自動跟隨滑鼠並縮放，帶點擊與按鍵提示，一鍵匯出成片。

提醒助理

單次 / 每日 / 每週 / 每月提醒，到點桌面通知。

萬年曆

國曆農曆對照、節氣節假日、干支紀年與擇日資訊。

按鍵提示

基於 RawInput 即時顯示鍵盤滑鼠按鍵，錄影示範時觀眾看得清楚。

滑鼠定位

一鍵標亮目前游標位置，多螢幕下再也不用找滑鼠。

文字與語言

文字處理流程上的常用工序，一次裝齊。

超級翻譯

多引擎劃詞與整段翻譯，可自選服務與目標語言。

文字辨識 OCR

截圖即辨識，本機 RapidOCR 引擎離線執行，中英混排準確，並支援快捷 OCR 翻譯。

正規表示式

即時比對標示、群組檢視、常用表示式速查。

編碼解碼

Base64 / URL / HTML / Unicode / 進位等常見編碼互轉。

雜湊計算

MD5 / SHA 系列摘要，支援文字與檔案校驗。

加密解密

基於 OpenSSL 的對稱與非對稱加解密、金鑰產生。

資料轉換

JSON / YAML / XML / TOML / CSV 結構化資料互轉與格式化。

資料產生

UUID / GUID、ULID、隨機字串與測試資料批次產生。

檔案與媒體

批次處理交給工具，你只管選檔案。

檔案預覽

免裝 Office 直接預覽 Word / Excel / PPT / PDF / 圖片 / 影片 / 程式碼 / 壓縮檔等格式。

批次重新命名

序號、取代、正規表示式、大小寫、EXIF 時間等規則組合，改前先預覽。

圖片批次處理

基於 ImageMagick 的縮放、裁切、格式轉換、浮水印、壓縮。

影片批次處理

基於 FFmpeg 的轉檔、擷取片段、擷取影格、壓縮、音訊擷取。

PDF 批次處理

基於 pdfcpu 與 Ghostscript 的合併、分割、加浮水印、壓縮、加解密。

檔案下載

基於 Aria2 的多執行緒下載，續傳與佇列管理。

計算與擴充

開放的命令模組體系，加個 JSON 就多一條命令。

計算稿紙

多行連續計算，支援變數、單位換算與函式，算式排版化顯示。

QR Code

文字與網址產生 QR Code，也可從截圖或圖片中辨識。

命令模組

內建 379 個 .zenmod 命令模組，涵蓋 AI、應用程式、遊戲、系統、網站五大類，命令面板中直接喚起。

內建瀏覽器

無邊框輕量瀏覽器，命令模組開啟網址時使用，不驚動主要瀏覽器。

自訂擴充

往 Modules 目錄放一個 .zenmod JSON 即新增一條命令，無需編譯。

個人化

桌面是你每天看最久的介面，值得好看一點。

動態桌布

用 Windows Composition API 把網頁與影片貼到桌面圖示層下方，不遮擋操作。

桌面特效

雪花飄落等氛圍特效，滑鼠穿透不干擾點擊。

遊戲模式

一鍵暫停桌布與特效，把資源全讓給遊戲。

導覽頁

可自訂分組的標籤導覽，取代瀏覽器新標籤頁。

地球保衛戰

內建的小遊戲，偷閒三分鐘。
