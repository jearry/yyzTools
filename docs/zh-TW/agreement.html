一、關於本軟體

yyzTools（Yes Your Zen Tools）是一款執行於 Windows 平台的桌面效率工具集。我們致力於把日常辦公與創作中高頻、瑣碎的需求，整合進一個開箱即用的工具箱——無需你再奔波於參差不齊的外掛市場，為每一個小功能去單獨篩選、安裝與付費；一次安裝，所需工具即取即用。

本軟體目前提供的主要能力包括（持續更新中）：

  • 命令面板：集中入口，可搜尋應用、檔案、書籤、剪貼簿、視窗、程序，並內建命令列與計算機；
  • 啟動與效率：程式塢、剪貼簿歷史、應用使用統計、螢幕截圖與釘選、提醒助手、萬年曆；
  • 文字與語言：超級翻譯、文字辨識（OCR）、正規表示式、編碼 / 解碼、雜湊計算、加密 / 解密；
  • 檔案與媒體：檔案預覽、檔案批次重新命名、圖片批次處理、影片批次處理、PDF 批次處理、檔案下載；
  • 計算與延伸：計算稿紙、QR Code 產生與辨識、AI 快捷入口；
  • 個人化：動態桌布、桌面特效、遊戲模式。
