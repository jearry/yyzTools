Snipaste 沒有的序號標註

寫操作教學時，在截圖工具列上選序號工具，點到哪一步就在哪裡落一個粗體圓形編號，計數自動遞增，復原時計數器同步回退。配上矩形和文字，「先點這裡、再點那裡」自己就長在圖上。Snipaste 的標註集很出色——唯獨沒有步驟序號工具。

什麼時候 Snipaste 仍是好選擇

如果貼圖才是重點，Snipaste 的貼圖無可匹敵：縮放、旋轉、翻轉、單獨調透明度、滑鼠穿透、縮圖模式、取色器、分組、自動備份還原。如果你還要在 macOS / Linux 上使用，或者想要最輕量的專用工具，Snipaste 仍是專家之選——個人版永久免費。

什麼時候選 yyzTools

如果你的截圖往往只是起點——要擷取文字、翻譯一句、把長頁面整頁截下、給操作步驟標上序號——yyzTools 在截圖視窗裡就把後半段做完，而同一個安裝包裡本就帶著啟動器、檔案搜尋、剪貼簿歷史，共 387 個模組。

常見疑問

yyzTools 能取代 Snipaste 的貼圖嗎？

只能部分取代。截圖工具列的一鍵釘圖、剪貼簿圖片釘選都內建，但 Snipaste 的貼圖深得多——旋轉、分組、單獨調透明度、取色器、備份還原。重度貼圖使用者建議留著 Snipaste，它也支援 macOS 和 Linux。

序號標註怎麼用？

Ctrl+` 喚出截圖，工具列選序號工具，點到步驟所在處：落下一個粗體圓形編號，計數自動遞增。序號與其他圖形一樣是物件，畫完還能選取、拖曳、縮放、刪除，復原時計數器一併回退。

兩個能共存嗎？

可以，互不衝突。yyzTools 截圖預設 Ctrl+`，Snipaste 預設 F1 / F3，幾乎不撞鍵；真撞了，兩邊都能改鍵。
