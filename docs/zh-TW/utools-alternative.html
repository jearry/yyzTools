常見疑問

yyzTools 像 uTools 那樣支援外掛嗎？

它的擴充單元是 .zenmod 命令模組——一個在命令面板註冊命令的 JSON 檔案，背後可掛一個網頁。387 個隨安裝包交付，SDK 文件和範例工程免費下載。它刻意比外掛市場輕：沒有外掛執行時，沒有發佈流程。

兩邊預設都是 Alt+Space，會衝突嗎？

會，兩者的預設全域快捷鍵都是 Alt+Space，第一次同時使用時在任意一側改鍵即可（yyzTools：系統匣圖示 → 設定 → 快捷鍵）。之後互不干擾。

uTools 免費版到底限制了什麼？

uTools 官方口徑是「基礎功能永久免費，加值服務收費」：免費版有外掛安裝數量上限，無限安裝需會員，會員還捆綁多裝置同步等權益。yyzTools 沒有這個概念——全部模組隨安裝包交付。
