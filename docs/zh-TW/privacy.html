隱私權政策

生效日期：2026 年 8 月 8 日　·　版本：v1.0

本政策說明 yyzTools（以下簡稱「本軟體」）如何處理你的資料。核心原則一句話：本機優先（local-first）——能在你電腦上做完的事，絕不送到別處。本政策是使用者協議第三節的展開說明，兩者不一致時以本政策為準。

一、我們不蒐集什麼

本軟體不要求註冊帳戶，不蒐集你的姓名、手機號碼、電子郵件等身分識別資訊，也沒有任何形式的使用者輪廓分析或行為追蹤回報。

我們沒有伺服器保存你的使用資料——因為本軟體根本不向我們傳送使用資料。

二、在本機處理與儲存的資料

以下資料均在你的裝置上蒐集、處理與儲存，保存在本機的設定檔與資料庫中，不會由本軟體主動上傳：

  • 剪貼簿歷史：你複製過的文字與圖片記錄。
  • 應用程式使用統計：各應用程式的前景時長與啟動次數。
  • 檔案搜尋與預覽：本機檔案索引與你開啟過的檔案路徑。
  • 文字辨識（OCR）：辨識在本機 RapidOCR 引擎中完成，影像不離開本機。
  • 設定與偏好：快速鍵、程式啟動列項目、桌布設定、介面語言等。
  • 命令面板記錄：你的搜尋字詞與啟動過的項目。

三、需要連網的功能

只有以下情形會產生網路請求，且都由你的操作觸發：

  • 超級翻譯：你提交的文字或影像會依你在設定中選擇的服務，傳送至相應的第三方線上翻譯服務。這部分資料由該第三方依其自有隱私權政策處理，不在我們控制範圍內。
  • 檔案下載：由你輸入的連結直接連線目標伺服器。
  • 命令模組與導覽頁：開啟網址時由內建瀏覽器直接造訪該網站。
  • 動態桌布：若你使用線上網頁作為桌布來源，則會造訪該網頁。

如不希望任何資料外傳，你可以不使用上述連網功能，其餘功能完全可離線使用。

四、更新檢查

本軟體會定期向官方鏡像（GitHub、jsDelivr 等）請求版本清單，以判斷是否有新版本。該請求僅傳輸版本號等必要資訊，不包含你的任何個人資料或使用資料。

你可以在設定中關閉自動檢查，改為手動透過系統匣選單檢查更新。

五、你對資料的控制權

  • 所有本機資料都在你的使用者目錄下，你可隨時直接查閱、備份、匯出或刪除。
  • 剪貼簿歷史可在命令面板中刪除單筆或一鍵清空。
  • 移除軟體時可選擇一併刪除資料目錄，刪除後無法復原。

六、第三方元件

本軟體內建以下開源或免費元件，各自依其原有授權條款散布：Microsoft Edge WebView2、FFmpeg、ImageMagick、Ghostscript、pdfcpu、RapidOCR、Everything、Aria2、7-Zip、OpenSSL 等。它們均以本機處理程序方式被呼叫，不承擔資料上傳職責。

七、兒童隱私

本軟體是通用桌面工具，並非針對兒童設計，也不會主動蒐集任何年齡相關資訊。

八、網站訪問統計

當你造訪本站官網（yyztools.com）時，我們會藉助 Cloudflare Web Analytics 收集匿名的聚合造訪統計（如頁面瀏覽量、造訪來源、大致地區與裝置類型），用於了解內容受歡迎程度並優化站點體驗。該服務不使用 Cookie，也不收集可用於識別你個人身分的資訊；相關資料由 Cloudflare 依據其隱私政策聚合處理。

九、政策變更與聯絡

本政策如有修訂，將在本頁面註明新的生效日期。若涉及資料處理方式的實質變更，我們會在更新說明中一併提示。有任何疑問可透過下方電子郵件或 GitHub Issues 與我們聯絡。
