快速入門指南

從零寫出你的第一個模組，無需任何建置工具

介面參考手冊 下載範例專案

本文面向模組開發者，示範如何從零建立一個執行在 yyzTools 主程序內的 Web 應用（以 SDK 範例工程 SDK_Sample——一個急速檔案查詢器——為例），涵蓋：頁面目錄、視窗宿主、i18n、非同步 Native API（全盤檔案搜尋）、檔案開啟、設定持久化，以及需要擴充 C++ 能力時的 native 方法新增模板。

範例是純原生 JS、零第三方依賴、免建置的：不需要 Vite / Alpine / FontAwesome，複製 Web 與 Modules 兩個目錄到 yyzTools.exe 所在目錄即可執行。

一、範例目錄與部署方式 #

sdk/sample/
  Web/                        ← 复制到 <yyzTools.exe 所在目录>\Web\        （与现有 Web 目录合并）
    SDK_Sample/               ← 样例自包含目录，整个文件夹即一个完整模块
      index.html              # 页面结构（原生 DOM，data-i18n 标注文案位）
      filefinder.js           # 全部逻辑：搜索 / 打开 / 历史 / Esc
      filefinder.css          # 页面样式（全部用 --zen-* 变量，自动适配深浅色）
      i18n.js                 # 文案字典（zh_cn / en）
      lib/
        zen_api.js            # ZenAPI 封装类（Native API 的 JS 包装，唯一 lib 依赖）
        window_controls.css   # 主题变量（--zen-*）+ 窗口控制栏样式
  Modules/                   ← 复制到 <yyzTools.exe 所在目录>\Modules\    （与现有 Modules 目录合并）
    SDK_Sample.zenmod         # type:"web" 模块声明，ModuleManager 自动创建宿主窗口

部署：

把 sdk/sample/Web     复制/合并到  bin64\Web\
把 sdk/sample/Modules 复制/合并到  bin64\Modules\
重启 yyzTools.exe，命令面板搜"SDK样例工程"即可启动

主程式讀取位置的約定：

資源 位置
頁面 <exe目录>\Web\{page}\index.html
模組 <exe目录>\Modules\<分类>\*.zenmod（只掃一層子目錄）

二、架構總覽：一個 Web 應用是如何跑起來的 #

Modules/SDK_Sample.zenmod   ← 声明 type:"web" 的模块文件（数据驱动，无需写 C++）
        │  主程序启动时扫描 .zenmod
        ▼
WebModule 宿主窗口（原生窗口 + WebView2）
        │  加载 Web\SDK_Sample\index.html
        ▼
Web/SDK_Sample/             ← 你的全部前端代码（原生 JS，零依赖）
        │  window.Zen.xxx(...)  ←→  主程序注册的原生接口
        ▼
C++ 各 Manager（文件/进程/窗口/剪贴板/OCR...）

關鍵結論：

  • 不需要寫任何 C++ 程式碼。type: "web" 的 .zenmod 會被主程式自動建立為 WebModule 宿主視窗，視窗尺寸、圖示、多語言名稱都由模組檔案宣告。

  • 模組自動獲得：命令面板搜尋（含拼音索引）、全域快捷鍵綁定、程序塢掛載、windowControl 名稱表註冊。

  • 前端與 C++ 的唯一通道是 window.Zen，請統一透過 ZenAPI 封裝類別呼叫（範例已附帶 lib/zen_api.js）。

  • 免建置頁面直接是靜態檔案，改完重新整理視窗即生效（windowControl('sdk_sample','hide') 再 show，或重啟 exe），無需任何編譯步驟。

三、頁面結構（原生 JS，四個檔案） #

index.html #

不引任何第三方庫；視窗控制列的三個按鈕用 Unicode 字元當圖示（− / □ / ×），樣式由 lib/window_controls.css 提供。文案位用 data-i18n / data-i18n-ph 標註，JS 初始化時統一填充。結構分四塊：搜尋列、搜尋歷史 chips、狀態列（結果數 + 語法提示）、結果清單：

<div class="search-bar">
    <input type="text" id="searchInput" class="search-input" data-i18n-ph="inputPlaceholder"
           spellcheck="false" autocomplete="off">
    <button class="search-btn" id="btnSearch" data-i18n="search"></button>
</div>
<div class="history-chips" id="historyChips"> ... </div>
<div class="status-bar">
    <span id="statusText" data-i18n="empty"></span>
    <span class="syntax-hint" data-i18n="syntaxHint"></span>
</div>
<div class="result-list" id="resultList"></div>

filefinder.js（核心邏輯） #

五個職責，全部照抄範例即可：

  1. 視窗控制：ZenAPI.windowControl('sdk_sample', 'min'|'max'|'close'|'drag')；標題列拖動判定位移超過 5px 才觸發；Esc 鍵——輸入框有焦點先 blur，否則關窗。
  2. 主題：註冊 window.__applyTheme 接收 C++ 回推（首屏 data-theme 由 C++ 注入，無需 JS 處理）。
  3. i18n：讀 getConfig().language，從字典取文案，遍歷 data-i18n 元素填充；帶 {{count}} 佔位的句子用插值函數展開。
  4. 搜尋：searchFile(keyword, maxResults) 是非同步綁定介面（背景執行緒執行，不阻塞 UI）；按 Enter 立即搜、輸入防抖 300ms 自動搜；用遞增序號丟棄亂序回包——native 側有搜尋槽機制（新請求直接頂掉未完成的舊請求，舊 Promise 拿到的是空結果），前端序號防止這個「空結果晚到」覆蓋掉新結果的渲染，二者配合。
  5. 結果操作：openFile(fullPath, false) 開啟檔案（雙擊同，第二參數是「是否管理員權限」）；openFileLocation(fullPath) 開啟所在目錄；完整路徑由 path + '\\' + name 拼出；圖示直接用結果裡現成的 icon 欄位（base64）；檔案大小用 size 數字欄位格式化展示。

searchFile 回傳結構（{ error, files[] }） #

files[] 每項的欄位：

欄位 類型 說明
name / path 字串 檔名 / 所在目錄。完整路徑 = path + '\\' + name
dateModified 字串 修改時間（在地化格式文字）
size 數字 檔案位元組數，原生數字直接用
icon 字串 base64 圖示，<img src> 直飲，無需再調 getFileIcon
score 數字 相關度打分（native 已按分排序）
isDir 數字 1/0 數字而非原生布林（手拼 JSON 路徑），判斷用 truthy 或 === 1，不要 === true

本範例呼叫的介面一覽 #

介面 綁定 用途
searchFile(keyword, maxResults) 非同步 全盤 MFT 索引搜尋，支援 Everything 語法（size:>100MB、ext:mp4、!ext:tmp）
openFile(path, admin) 同步 開啟檔案/目錄（shell 預設行為），admin=true 時以管理員權限
openFileLocation(path) 同步 在檔案總管中定位到該檔案
getConfig(key?) 同步 讀設定：缺省全量、傳 key 只取該鍵（支援 a.b 點路徑）
setConfig(patch, replace?) 同步 窄粒度寫搜尋歷史：setConfig({ sdk_sample: { history } })；replace=true 整體替換（僅匯入備份用）
log(message) 同步 前端日誌，寫入主程序日誌，便於排查
windowControl(name, action) 同步 視窗最小化/最大化/關閉/拖動

呼叫規範（四條鐵律） #

import ZenAPI from './lib/zen_api.js';

// 1. 判错用 isOk()（error 恒为数字：0 成功，-1 表示调用异常）
const res = await ZenAPI.searchFile('yyztools', 200);
if (!ZenAPI.isOk(res)) { ... }

// 2. 接口返回的布尔字段是原生布尔，直接判断
//    （例外一：config 的值由前端写入决定类型，通常是字符串，比较时注意归一）
//    （例外二：searchFile 结果的 isDir 是 1/0 数字——手拼 JSON 路径，用 truthy 或 === 1）
const ex = await ZenAPI.exists(path);
if (ex.exists === true) { ... }

// 3. 配置写入必须窄粒度，禁止全量回写
await ZenAPI.setConfig({ sdk_sample: { history } });   // 只写自己的键

// 4. 按 id 批量取应用信息用 getAppInfo，禁止循环 searchApp
const infos = await ZenAPI.getAppInfo(['calculator', 'ocr']);

非同步介面（getAppInfo / searchFile / 媒體五件套 / ocrRecognition）在背景執行緒執行，注意同一時刻僅有一個媒體子處理程序在跑，長時間任務要提供 cancelRun() 取消入口。

常用介面速查（範例之外的更多能力） #

場景 介面
讀/寫自己的設定 getConfig / setConfig（窄粒度 patch）/ addConfig（追加清單項）
開啟/另存檔案 browseFile / browseDir / writeFile / readFile（>50MB 用 readFileChunk）
取得系統目錄 getKnownDir('download') 等
開啟網頁/外部程式 runAny('https://...', '')
複製到剪貼簿 前端 navigator.clipboard（文字場景無需 native）
螢幕擷取/OCR screenCap('fast', ...) → ocrRecognition(base64)（均非同步）
呼起其他模組視窗 windowControl('translate', 'show')

四、建立 .zenmod 模組檔案（視窗宿主） #

在 Modules/<分類>/ 下新建 .zenmod（範例檔案：sdk/sample/Modules/SDK_Sample.zenmod）：

{
    "id": "sdk_sample",
    "type": "web",
    "name": { "zh_cn": "SDK样例工程", "en": "SDK Sample Project", "...": "共 12 门语言" },
    "desc": { "zh_cn": "基于 MFT 索引的全盘急速文件搜索，支持 Everything 语法", "en": "..." },
    "icon": "fas fa-search",
    "winClassName": "yyzTools::SdkSampleWindowClass",
    "width": 760,
    "height": 540,
    "layoutType": 34,
    "url": "SDK_Sample/index.html",
    "preCreate": 0
}

欄位說明（type:"web" 時主程式讀取的全部欄位）：

欄位 必填 說明
id 是 全域唯一。同時是 windowControl/windowState 的視窗名、快捷鍵 appId、dock 掛載 id
type 是 固定 web
name 是 12 語言物件；也允許純字串寫法（僅建議內部測試用），取值回落：當前語言 → en → 純字串
desc 否 同上
icon 否 FontAwesome class（如上）或 base64 圖片
winClassName 否 Win32 視窗類別名，全域唯一即可
width / height 否 初始視窗尺寸，預設 800x600
layoutType 否 初始位置布局位元遮罩，34 = 水平置中 + 垂直置中
url 是 相對 Web 根目錄的頁面路徑（SDK_Sample/index.html）；也支援 http(s) 開頭的線上位址
preCreate 否 1 = 啟動時預先建立視窗（加快首次開啟），預設 0 按需建立
canSuspend 否 1 = 允許視窗隱藏時掛起 WebView 省資源（預設 1）

改完自查：JSON 可解析、UTF-8 無 BOM、id 全域唯一、12 門語言均非空。

至此應用已完成——按第一節複製兩個目錄，命令面板搜尋「SDK範例工程」或「sdk」即可啟動（拼音索引自動生成），windowControl('sdk_sample', 'show') 也能喚起它。

五、多語言文案（字典方式） #

免建置方案用普通 ES module 字典即可（i18n.js）：

const messages = {
    zh_cn: { title: 'SDK样例工程', results: '{{count}} 个结果，耗时 {{ms}} ms', ... },
    en:    { title: 'SDK Sample Project', results: '{{count}} results in {{ms}} ms', ... }
};
export function getMessages(lang) { return messages[lang] || messages.en; }
export function interpolate(dict) {
    return (key, params) => { /* {{count}} → params.count */ };
}

初始化時讀 getConfig().language 選語言，查不到回落 en；帶佔位符的句子用 tf('results', { count, ms }) 展開。

注意：

  • 語言碼用底線小寫風格（zh_cn），與 .zenmod 一致，不是 BCP47。

  • .zenmod 的 name/desc 必須 12 門語言齊全；頁面內文案沒有強制要求，範例只給 zh_cn/en，按需擴充。

  • 需要跟隨介面語言即時切換的模組，可把字典改為按需 import() 懶載入多語言檔案，機制與本文相同。

六、除錯與整合 #

1. 免构建直接跑（推荐起步）：
   复制 sdk/sample/Web、sdk/sample/Modules 到 bin64\（Release exe 所在目录），重启 exe。
   改前端后 windowControl('sdk_sample','close') 再打开，或重启 exe 生效。

2. 浏览器看结构：
   直接双击 Web/SDK_Sample/index.html 用浏览器打开。
   浏览器里没有 window.Zen，ZenAPI.call 会走异常路径返回 error: -1，
   页面结构 / 样式 / 输入防抖 / 渲染逻辑均可正常调试（原生接口除外）。

搜尋效能提示：searchFile 走 C++ 側 MFT 全盤索引，通常毫秒級返回；native 有搜尋槽機制——新請求會頂掉未完成的舊請求（舊的返回空結果），前端配 300ms 防抖 + 遞增序號丟棄亂序回包，連續擊鍵也不會打爆背景執行緒或閃爍舊結果。結果圖示（base64）由 searchFile 順手帶回，無需額外調 getFileIcon。

介面能力不夠用時（例如需要新的 C++ 能力），可透過官網回饋管道提出需求，由主程式在後續版本擴充介面。

八、安全須知 #

Native API 面向模組開發者完整開放宿主處理程序的系統能力，其中包含檔案讀寫與刪除、處理程序建立與終止、視窗控制、剪貼簿讀寫、系統設定修改、命令列執行等高危操作，且不設權限彈窗、不做沙箱隔離、不提供復原機制。

呼叫前請自行評估每一次操作的安全性：校驗一切外部輸入，涉及不可逆操作前先備份或請使用者確認，並只使用功能真正需要的能力。由此造成的一切後果由開發者自行承擔。
