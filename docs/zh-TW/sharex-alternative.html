在找 ShareX 的替代品？

ShareX 是重度使用者的截圖瑞士軍刀——可設定極深、開源、上傳工作流程無可匹敵。yyzTools 的截圖模組涵蓋同樣的日常主幹——區域、捲動長截圖、標註、貼圖釘選——並在 ShareX 不去的地方繼續：安裝包自帶的本機 OCR 引擎，和截圖工具列上一步直達的翻譯。

裝好就有的 OCR——旁邊就是翻譯

ShareX 的 OCR 依託 Windows 內建引擎，加新語言要先裝系統語言包。yyzTools 把 RapidOCR 引擎和模型打進安裝包：裝好即用、混排文字友善，截圖工具列上的 OCR 與翻譯按鈕（或獨立的快速 OCR，Alt+T）把一張截圖直接變成翻譯好的文字，全程不用離開截圖流程。

什麼時候 ShareX 仍是好選擇

如果你的截圖是要「發出去」的——大量上傳目標、自訂上傳器、截圖後任務鏈、自動擷取——或者你要的是每個旋鈕都露在外面的開源免費無帳號工具，ShareX 仍是重度使用者之選，它的社群也是 Windows 免費軟體裡最大的之一。

什麼時候選 yyzTools

如果你的截圖是用來讀和回的——擷取文字、翻譯段落、整頁截存——yyzTools 在截圖視窗裡就把事辦完，同一個安裝包裡還有啟動器、檔案搜尋、剪貼簿歷史、批次處理，共 387 個模組。

常見疑問

yyzTools 能取代 ShareX 嗎？

日常截圖——區域、捲動、標註、貼圖——基本能，還多了翻譯和內建 OCR 引擎。但 ShareX 的主場——上傳目標、自訂上傳器、截圖後自動化——這裡沒有對應物。重度分享流使用者請留著 ShareX。

兩邊 OCR 引擎有什麼差別？

yyzTools 把 RapidOCR 引擎和模型隨安裝包交付，裝好即用、對混排文字最佳化。ShareX 呼叫 Windows 內建 OCR，語言跟隨系統語言包——加一種語言要先去 Windows 語言設定裡裝。

兩個能共存嗎？

可以。若有熱鍵相撞，在任一側改鍵即可（yyzTools：系統匣圖示 → 設定 → 快捷鍵）。
