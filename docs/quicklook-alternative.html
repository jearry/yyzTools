A QuickLook alternative — Space-to-preview without needing MS Office

QuickLook brings macOS-style Space-to-preview to Windows and covers a very wide list of file types. One catch on Office: QuickLook's Word/Excel/PowerPoint preview hosts Windows' built-in preview handler, so it needs Microsoft Office installed — without it, .doc/.ppt won't preview either. yyzTools parses modern Office (docx/xlsx/pptx) itself in a WebView2 front end — no Office required — and adds interactive 3D models (glTF/OBJ/FBX/STL…) and CAD DXF that QuickLook has no answer to, folded into one free Alt+Space toolbox.

When QuickLook is the better pick

If you want the widest raw format list — every code language, RAW/PSD images, archives, fonts, email and more — and you already have MS Office installed so QuickLook's Word/Excel/PowerPoint preview works, QuickLook is the more complete dedicated previewer, and it's open source. For pure format-type coverage it's the stronger choice.

When yyzTools is the better fit

If you want Space-to-preview without installing another app — Office documents rendered even on machines with no MS Office, interactive 3D models and CAD that QuickLook can't preview, and a binary view as a fallback so nothing opens blank — yyzTools folds all of that into the free Alt+Space toolbox you already use.

Common questions

Does QuickLook preview Office files without Microsoft Office?

No. QuickLook's Word/Excel/PowerPoint support hosts Windows' built-in preview handler (the same mechanism Explorer's preview pane uses), so a compatible MS Office install is required — without it, .doc and .ppt won't render. yyzTools parses modern Office (docx/xlsx/pptx) itself, so it previews those without MS Office installed (legacy .doc/.ppt fall back to a binary view).

What does yyzTools preview that QuickLook can't?

Interactive 3D models — glTF, GLB, OBJ, FBX, STL, PLY, DAE — and CAD DXF. QuickLook has no 3D/CAD preview at all. yyzTools also shows a hex view for unrecognized files instead of a blank pane.

Then where is QuickLook stronger?

Raw format count: 200+ code and text types, 100+ image formats including RAW/PSD/HEIC, plus archives, fonts and email — far more categories than yyzTools covers. If your goal is the broadest possible previewer and you already have Office installed, QuickLook wins that axis.
