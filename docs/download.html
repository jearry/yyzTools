Installation

  1. 01 Download the installer above and run it.
  2. 02 Pick your interface language when prompted; the defaults are fine for everything else.
  3. 03 Once installed, press Alt+Space to open CmdPlate and get started.
  4. 04 The tray icon gives you settings, wallpaper and effect toggles, and update checks.

About updates

yyzTools updates per package: the main framework, front-end pages, command modules, FFmpeg, OCR models, and so on are packaged separately, so an update downloads only what actually changed instead of reinstalling everything.

Download & install FAQ

Q01 Is yyzTools completely free?

Yes. Every feature is free permanently - no paid unlocks, no membership tiers, no trial countdowns.

Q02 Does it collect my data?

No. yyzTools needs no account and processes clipboard history, file search, and OCR locally on your machine. Only online features you actively use, such as translation, send your input to the third-party service you choose.

Q03 Does it need an internet connection?

Only for downloading, update checks, and online features like translation. Everything else - command palette, file search, OCR, clipboard history, batch processing - works fully offline.

Q04 What are the system requirements?

64-bit Windows 10 (1809 or later) or Windows 11, about 600 MB of disk space, and the Microsoft Edge WebView2 runtime - preinstalled on Windows 11; the installer guides you on Windows 10 if it is missing.
