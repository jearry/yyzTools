Common questions

Can yyzTools replace Typora?

For core writing, yes: WYSIWYG, GFM, KaTeX math, Mermaid, paste-to-save images and autosave are all there. But Typora's export formats, theme ecosystem, outline and file tree, spell check and macOS / Linux support have no equivalent here. Heavy writers or anyone exporting for delivery should keep Typora — it is a one-time purchase that keeps working.

How are images stored?

Images you paste, copy or drop are auto-saved to an assets/ subfolder next to the document, and referenced by relative path — the whole document folder can be moved, zipped or put into Git without losing them. Inserting an image into an unsaved document prompts you to save it somewhere first.

Does it support math and Mermaid diagrams?

Yes. Inline math uses $..$, block math $$..$$ (rendered with KaTeX), and Mermaid code blocks preview to SVG on demand. Both load on demand, so they don't slow down the first screen.

What about exporting to PDF or Word?

Both PDF and HTML export are built in — two items in the export menu, WYSIWYG (PDF is produced through the system print engine). Word / EPUB and other formats aren't included; for those, Typora remains the smoother choice.
