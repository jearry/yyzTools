Häufige Fragen

Ist es wirklich dauerhaft kostenlos? Wird später abgerechnet?

Wirklich kostenlos. Keine kostenpflichtige Freischaltung, keine Mitgliedschaft und keine Kernfunktionen hinter einer Bezahlschranke. yyzTools soll ein Werkzeug sein, das Sie langfristig gern auf Ihrem Desktop behalten — und kein weiteres Abo.

Werden meine Daten hochgeladen?

Nein. Zwischenablage-Verlauf, Dateisuche, App-Statistiken und OCR werden lokal verarbeitet und gespeichert. Nur wenn Sie aktiv eine Online-Funktion wie die Übersetzung nutzen, gehen Ihre Eingaben an den von Ihnen gewählten Drittanbieter. Zusätzlich prüft die Software regelmäßig auf Updates — diese Anfrage überträgt lediglich Versionsnummern.

Brauche ich ein Konto?

Nein. Es gibt keine Registrierung, und die Software erhebt keine Identitätsdaten.

Welche Systeme werden unterstützt?

Windows 10 und Windows 11 in der 64-Bit-Version. Die Laufzeitumgebung Microsoft Edge WebView2 ist erforderlich; Windows 11 bringt sie mit, unter Windows 10 führt Sie das Installationsprogramm bei Bedarf durch die Installation.

Braucht es viele Ressourcen?

Der dauerhaft laufende Hauptprozess ist sehr leicht; Hintergrund, Aufnahme und Tastenhinweise laufen als eigene Prozesse und starten nur bei Bedarf. Der Spielmodus pausiert Hintergrund und Effekte mit einem Klick.

Wie ergänze ich eigene Funktionen?

Legen Sie eine .zenmod-JSON-Datei mit Namen, Icon und dem auszuführenden Befehl in den Ordner Modules des Installationsverzeichnisses. Nach einem Neustart ist sie in der Kommandoleiste auffindbar — ohne eine Zeile Code zu kompilieren.
