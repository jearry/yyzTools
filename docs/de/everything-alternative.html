Suchen Sie eine Everything-Alternative?

yyzTools bringt eine eigene Suchengine für die ganze Festplatte mit, gebaut wie Everything — Index über direkte NTFS-$MFT-Lesezugriffe, Live-Updates über das USN-Journal, kompatible Abfragesyntax. Der Unterschied: Dasselbe Installationspaket enthält auch einen Launcher, Übersetzung, OCR, Stapelwerkzeuge und über 40 weitere Module.

yyzTools vs Everything

Beide gehen denselben technischen Weg; der Unterschied liegt in der Ausrichtung. Everything ist ein eigenständiges Werkzeug, das sich ganz auf die Dateinamensuche konzentriert. yyzTools baut die Dateisuche in eine integrierte Produktivitätswerkzeugkiste ein.

Wann Everything weiterhin die richtige Wahl ist

Wenn Sie nur die ultimative Dateinamensuche brauchen — Regex-Abfragen, einen HTTP-Server zum Teilen der Ergebnisse, Anbindung über das SDK oder die Indizierung von Nicht-NTFS- und Wechsellaufwerken —, bleibt Everything ein ausgereifter, verlässlicher Spezialist. Die Engine von yyzTools indiziert derzeit nur feste NTFS-Laufwerke und unterstützt regex: noch nicht; sie will Everything nicht in jeder Nische ersetzen.

Wann yyzTools besser passt

Wenn Sie eine Zwei-Tool-Kombination — etwa PowerToys Run zum Starten plus Everything für Dateien — durch eine einzige App ersetzen möchten, erledigt das yyzTools mit einer einzigen Installation: Ein Alt+Space-Feld durchsucht Apps, Dateien, Prozesse, Fenster, Lesezeichen und Zwischenablage gemeinsam, mit Vorschau, Speicherort-Anzeige und Papierkorb-Aktionen für die Treffer, und dahinter stehen über 40 weitere Module wie Übersetzung, OCR, Zwischenablage-Verlauf und Stapelverarbeitung.

Häufige Fragen

Ist die Dateisuche von yyzTools nur eine Hülle um Everything?

Nein. Seit v1.0.5 läuft die Dateisuche auf einer vollständig eigenentwickelten Engine (direkte NTFS-$MFT-Lesezugriffe + USN-Journal-Updates). Die Everything-Abhängigkeit wurde aus dem Installationspaket entfernt, und der Speicherverbrauch des Index sank von mehreren hundert MB auf wenige MB.

Ist die Abfragesyntax mit Everything kompatibel?

Die gängige Syntax ist kompatibel: path:, ext:, size:, datemodified:, Platzhalter und AND / OR / NOT-Kombinationen funktionieren direkt. Regex (regex:) wird noch nicht unterstützt — die größte Syntaxlücke gegenüber Everything.

Kann Everything parallel zu yyzTools installiert bleiben?

Ja, beide stören sich nicht. Wenn die Dateisuche von yyzTools Ihre Anforderungen aber bereits abdeckt, spart ein einzelnes Tool Ressourcen.
