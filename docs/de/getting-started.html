yyzTools in 5 Minuten einrichten

Sie müssen nicht jede Funktionsseite einzeln öffnen — gehen Sie die folgenden Schritte durch, und Sie kennen yyzTools genau so, wie Sie es täglich nutzen werden.

01

Die Befehlspalette aufrufen

30 Sek.

Drücken Sie Alt+Leertaste, und mitten auf dem Bildschirm erscheint ein Suchfeld. Das ist das Zentrum von yyzTools: Apps, Dateien, Prozesse, Fenster, Lesezeichen und Zwischenablage werden alle in diesem einen Feld gesucht — Ergebnisse erscheinen beim Tippen, Enter öffnet sie.

Alt+LeertastePalette ein-/ausblenden

Mit Umschalt+Enter wird das ausgewählte Ergebnis als Administrator ausgeführt.

02

Ein paar Präfixe merken

2 Min.

Tippen Sie am Anfang des Feldes einen Präfix plus Leerzeichen, um den Suchbereich zu wechseln: f durchsucht alle Laufwerke, p Prozesse, w Fenster, b Browser-Lesezeichen, c den Zwischenablage-Verlauf, > führt Befehle aus, = rechnet sofort. Funktionsnamen müssen Sie nicht behalten — nur die Buchstaben.

f␣alle Dateien p␣Prozesse w␣Fenster b␣Lesezeichen c␣Zwischenablage =␣Rechnen
03

Favoriten ins Dock ziehen

1 Min.

Bewegen Sie die Maus an den oberen Bildschirmrand, und das Dock fährt heraus. Ziehen Sie häufig genutzte Apps, Dateien und Ordner einfach hinein — hinausziehen entfernt sie. Für Ihre Dauereinträge ist der Weg über das Startmenü damit Geschichte.

Rechtsklick auf das Dock erstellt Gruppen; URLs lassen sich ebenfalls ablegen.

04

Tastenkürzel an die eigenen Gewohnheiten anpassen

1 Min.

Rechtsklick auf das Tray-Symbol → Einstellungen → Tastenkürzel. Palette, Screenshot, OCR, Übersetzung und Rechner lassen sich auf Ihre Wunschkombinationen legen; auch Submodule der Palette unterstützen eigene Kürzel.

Über das Tray-Menü wechseln Sie außerdem Hintergründe und Effekte und prüfen Updates.

05

Öffnen, was gebraucht wird — wann es gebraucht wird

30 Sek.

Übersetzung, OCR, Stapelverarbeitung: Sie müssen nie danach suchen — den Namen in die Palette tippen genügt. Name vergessen? Werfen Sie einen Blick in die Funktionsliste — alle 388 Module sind bereits an Bord, jederzeit einsatzbereit.
