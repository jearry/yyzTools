Häufige Fragen zu Download und Installation

Q01 Ist yyzTools wirklich kostenlos?

Ja. Alle Funktionen sind dauerhaft kostenlos - keine kostenpflichtige Freischaltung, keine Mitgliedschaft, keinen Testzeitraum-Countdown.

Q02 Werden meine Daten gesammelt?

Nein. yyzTools benötigt kein Konto und verarbeitet Zwischenablage-Verlauf, Dateisuche und OCR lokal auf Ihrem Rechner. Nur wenn Sie aktiv eine Online-Funktion wie die Übersetzung nutzen, gehen Ihre Eingaben an den von Ihnen gewählten Drittanbieter.

Q03 Ist eine Internetverbindung nötig?

Nur für den Download, die Update-Prüfung und Online-Funktionen wie die Übersetzung. Alles Übrige - Kommandoleiste, Dateisuche, OCR, Zwischenablage-Verlauf, Stapelverarbeitung - funktioniert vollständig offline.

Q04 Welche Systemanforderungen gelten?

Windows 10 (ab 1809) oder Windows 11 in 64 Bit, rund 600 MB Speicherplatz sowie die Laufzeitumgebung Microsoft Edge WebView2 - in Windows 11 enthalten; unter Windows 10 führt Sie das Installationsprogramm bei Bedarf durch die Installation.

Q05 Windows zeigt beim Start des Installationsprogramms „Windows hat Ihren PC geschützt". Was tun?

Dies ist Microsoft Defender SmartScreen, eine Standardwarnung für Programme ohne Code-Signaturzertifikat, die beim ersten Start erscheinen kann. Klicken Sie auf „Weitere Informationen" → „Trotzdem ausführen", um fortzufahren. Sie können die Datei zusätzlich mit den auf dieser Seite angezeigten SHA-256-Prüfsummen verifizieren.

Q06 Bündelt das Installationsprogramm andere Software oder ändert es Browsereinstellungen?

Nein. Das Installationsprogramm enthält nur yyzTools selbst und die integrierten Komponenten, die es zum Laufen braucht (FFmpeg, OCR-Modelle und weitere Abhängigkeiten lokaler Funktionen). Es wird keine Drittanbieter-Software mitinstalliert, keine Browser-Startseite umgebogen und außer dem optionalen Autostart-Eintrag läuft kein Prozess im Hintergrund. Die Datei lässt sich über die SHA-256-Prüfsummen auf dieser Seite verifizieren.

Q07 Wie deinstalliere ich yyzTools vollständig?

Führen Sie das Deinstallationsprogramm über „Einstellungen → Apps" oder direkt aus dem Installationsordner aus. Sie können dabei wählen, ob die Benutzerdaten (Konfiguration, Zwischenablage-Verlauf, Nutzungsstatistiken — alles im Benutzerprofil, nicht im Registrierungsdatenbank-DSchungel verstreut) mitgelöscht werden. Die App installiert standardmäßig ins Benutzerverzeichnis; nach der Deinstallation bleiben keine Dienste oder Autostart-Einträge zurück.
