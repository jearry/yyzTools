Systemanforderungen

Betriebssystem
Windows 10 1809 oder neuer / Windows 11 (64 Bit)
Laufzeitumgebung
Microsoft Edge WebView2 (in Windows 11 enthalten; unter Windows 10 führt das Installationsprogramm bei Bedarf durch die Installation)
Speicherplatz
Etwa 600 MB, inklusive mitgelieferter Komponenten wie FFmpeg, ImageMagick und OCR-Modelle
Berechtigungen
Installiert standardmäßig in Ihr Benutzerverzeichnis — keine Administratorrechte nötig

Installationsschritte

  1. Laden Sie das Installationspaket oben herunter und starten Sie es.
  2. Wählen Sie im Assistenten die Sprache der Oberfläche; alles Übrige können Sie auf den Standardwerten lassen.
  3. Drücken Sie nach der Installation zweimal Ctrl, um die Kommandoleiste zu öffnen, und legen Sie los.
  4. Über das Symbol im Infobereich erreichen Sie Einstellungen, Hintergrund und Effekte sowie die Update-Prüfung.

Über Updates

yyzTools aktualisiert paketweise: Hauptprogramm, Frontend-Seiten, Kommandomodule, FFmpeg, OCR-Modelle und weitere Bestandteile sind getrennt gepackt. Eine Update-Prüfung lädt daher nur das, was sich wirklich geändert hat, statt die ganze Software neu zu installieren.
