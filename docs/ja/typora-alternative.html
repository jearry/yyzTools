よくある質問

yyzTools は Typora の代わりになりますか？

コアな執筆ならなります：WYSIWYG、GFM、KaTeX 数式、Mermaid、画像の自動保存、自動保存をすべて備えています。ただし Typora の書き出し形式、テーマのエコシステム、アウトラインとファイルツリー、スペルチェック、macOS / Linux 対応に相当するものはありません。長文を書く方や書き出して納品する方は Typora を残しておくのがおすすめです——買い切りなので長く使えます。

画像はどこに保存されますか？

貼り付け・コピー・ドラッグした画像は、文書と同じ場所の assets/ サブフォルダに自動保存され、相対パスで参照されます。文書フォルダごと移動・圧縮・Git 管理しても画像は失われません。未保存の文書に画像を挿入するときは、先に保存するよう案内されます。

数式と Mermaid 図に対応していますか？

対応しています。インライン数式は $..$、ブロック数式は $$..$$（KaTeX で描画）、Mermaid コードブロックはワンクリックで SVG プレビューできます。どちらもオンデマンド読み込みなので初回表示は遅くなりません。

PDF や Word への書き出しはできますか？

PDF と HTML への書き出しはどちらも対応しています——書き出しメニューに 2 項目あり、WYSIWYG です（PDF はシステムの印刷エンジン経由で生成）。Word / EPUB などは内蔵されていません。それらが必要なら Typora のほうが手軽です。
