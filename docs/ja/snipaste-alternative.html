Snipaste の代替をお探しですか？

Snipaste は「キャプチャ＋ピン留め」を極めた道具です。yyzTools のキャプチャモジュールは同じ日常をカバーしつつ——領域キャプチャ、その場での注釈、ピン留め——Snipaste が止まるところから先へ進みます：操作ガイド向けの自動連番ツール、キャプチャツールバー上の OCR と翻訳、ずれなくつなぐスクロールキャプチャ、そして隣には画面収録モジュール。

Snipaste にない連番注釈

操作ガイドを書くとき、ツールバーの番号ツールで手順の場所をクリックするだけ：太字のバッジが置かれ、番号は自動で増え、元に戻すとカウンターも一緒に戻ります。矩形やテキストと組み合わせれば「ここをクリック、次にここ」が図だけで伝わります。Snipaste の注釈セットは優秀ですが、連番ツールだけはありません。

Snipaste が引き続き最適なとき

ピン留めこそ目的なら、Snipaste のそれは無敵です：拡大・回転・反転、個別の透過設定、クリックスルー、サムネイルモード、カラーピッカー、グループ化、自動バックアップ。macOS や Linux でも使う、あるいは最軽量の専用ツールが欲しいなら、Snipaste は依然として専門家の選択です——個人版は永久無料。

yyzTools がより合うとき

スクリーンショットがたいてい「始まり」なら——文字を起こす、一文を翻訳する、長いページをまるごと撮る、手順に番号を振る——yyzTools はキャプチャウィンドウの中で後半まで済ませます。しかも同じインストーラにランチャー、ファイル検索、クリップボード履歴など計 387 モジュールが最初から入っています。

よくある質問

yyzTools は Snipaste のピン留めを置き換えられますか？

部分的にです。キャプチャツールバーからのピン留めとクリップボード画像のピン留めは内蔵していますが、Snipaste のピン留めははるかに深い——回転、グループ化、個別透過、カラーピッカー、バックアップと復元。ピン留めを重く使う方は Snipaste を残すことをおすすめします。macOS と Linux でも動きます。

連番ツールの使い方は？

Ctrl+` でキャプチャし、ツールバーの番号ツールを選んで手順の場所をクリック：太字のバッジが置かれ、次のクリックに向けて番号が自動で増えます。バッジも他の図形と同じオブジェクトで、後から選択・移動・拡大縮小・削除でき、元に戻すとカウンターも戻ります。

両方入れたままでも大丈夫？

はい、競合しません。yyzTools のキャプチャは Ctrl+` が既定で、Snipaste は F1 / F3——ほぼぶつかりません。ぶつけてもどちら側でも変更できます。
