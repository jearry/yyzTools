機能一覧

利用シーンごとに 6 つに分類しています。すべての機能が同じインストーラーに含まれており、追加購入は一切ありません。

yyzTools（正式名称は Yes Your Zen Tools）は無料・ローカル優先の Windows デスクトップ効率化ツールセットです。コマンドパレット、ドック、クリップボード履歴、スーパー翻訳、OCR、ファイルプレビュー、一括リネーム、画像・動画・PDF の一括処理、ライブ壁紙、デスクトップエフェクトなど 40 以上のモジュールを内蔵。インストーラー 1 つ、UI は 12 言語、アカウント不要、永久無料です。

コマンドパレット ランチャーと効率化 テキストと言語 ファイルとメディア 計算と拡張 パーソナライズ 比較

コマンドパレット

Alt+Space で呼び出す統合入口。ひとつの検索欄がパソコン全体を貫きます。

01

アプリ検索 default

Win32 / UWP アプリ、システムコマンド、システム設定を検索して起動します。管理者として実行やファイルの場所を開くことにも対応します。

02

ファイル検索 f␣

独自開発のインデックスエンジンによる全ドライブの高速検索（メモリ使用量はわずか）。そのまま開く、プレビュー、場所を表示、ごみ箱へ削除ができます。

03

プロセス管理 p␣

プロセスを検索して実行 / 一時停止、終了、再起動。タスクマネージャーを開く必要はありません。

04

ウィンドウ管理 w␣

ウィンドウを検索して表示 / 非表示、最前面に固定 / 解除、閉じる操作ができます。

05

ブックマーク検索 b␣

ブラウザーのブックマークを検索し、通常またはプライベートモードで開きます。

06

クリップボード履歴 c␣

テキストと画像の履歴をさかのぼり、選ぶだけでそのまま貼り戻せます。

07

コマンドライン >␣

コマンドを直接実行できます。管理者としての実行にも対応します。

08

即時計算 =␣

入力しながら結果を表示。数式と結果を図として整えて表示し、Enter でコピーします。

ランチャーと効率化

繰り返しの操作を、ひとつのショートカットに凝縮します。

01

ドック

画面上端に常駐するフローティングランチャー。マウスを上部に動かすと自動でスライド表示され、グループ分けしたアプリと URL にいつでも素早くアクセスできます。

02

クリップボード履歴

テキストと画像をバックグラウンドで記録。画像をピン留めしてデスクトップの上に浮かべられます。

03

アプリ使用統計

各アプリの使用時間とアクティブ化回数を記録し、グラフで時間の使い道を可視化します。

04

スクリーンショット

範囲キャプチャー、長尺キャプチャー（スクロール結合）、画面へのピン留め。独立プロセスなので互いに足を引っ張りません。

05

画面録画

画面と音声の録画、カメラ領域の自由な選択に対応。カメラはカーソルを自動追従してズームし、クリック・キー入力のヒントを表示、ワンクリックで仕上げ映像を出力します。

06

リマインダー

1 回 / 毎日 / 毎週 / 毎月のリマインダー。時刻になるとデスクトップに通知します。

07

万年暦

新暦と旧暦の対照、二十四節気と祝日、干支や吉日の情報。

08

システムクイック操作

音量調整・シャットダウン・再起動・ロック・USB取り出し・ごみ箱を空にするなど、よく使うシステム操作をコマンド一つで実行。

テキストと言語

テキスト処理でよく使う工程を、まとめて導入。

01

スーパー翻訳

複数エンジンによる選択範囲翻訳と全文翻訳。サービスと翻訳先の言語を自分で選べます。

02

文字認識 OCR

スクリーンショットからそのまま認識。ローカルの RapidOCR エンジンでオフライン動作し、日本語と英語が混在した文章も正確。クイック OCR 翻訳にも対応します。

03

クイック OCR

メインウィンドウを開かず、ホットキー一つでスクリーンショットの認識と翻訳まで完了。

04

正規表現

リアルタイムのマッチ強調表示、キャプチャグループの確認、よく使う表現の早見表。

05

エンコード・デコード

Base64 / URL / HTML / Unicode / 進数など、一般的なエンコード方式を相互変換します。

06

ハッシュ計算

MD5 / SHA 系のダイジェスト。テキストとファイルの検証に対応します。

07

暗号化・復号

OpenSSL を基盤とした共通鍵・公開鍵方式の暗号化と復号、鍵の生成。

08

データ変換

JSON / YAML / XML / TOML / CSV の構造化データの相互変換と整形。

09

データ生成

UUID / GUID、ULID、ランダム文字列、テストデータの一括生成。

ファイルとメディア

一括処理はツールに任せて、あなたはファイルを選ぶだけ。

01

ファイルプレビュー

Office を入れなくても Word / Excel / PPT / PDF / 画像 / 動画 / コード / 圧縮ファイルなどをそのままプレビューできます。

02

一括リネーム

連番、置換、正規表現、大文字小文字、EXIF の撮影日時などのルールを組み合わせられます。実行前にプレビューできます。

03

画像の一括処理

ImageMagick を基盤とした拡大縮小、切り抜き、形式変換、透かし、圧縮。

04

動画の一括処理

FFmpeg を基盤とした変換、切り出し、フレーム抽出、圧縮、音声抽出。

05

PDF の一括処理

pdfcpu と Ghostscript を基盤とした結合、分割、透かし追加、圧縮、暗号化と復号。

06

ファイルダウンロード

Aria2 を基盤としたマルチスレッドダウンロード。レジューム再開とキュー管理に対応します。

計算と拡張

JSON をひとつ足せばコマンドが増える、開かれたコマンドモジュール方式。

01

計算用紙

複数行の連続計算に対応し、変数、単位換算、関数も利用できます。数式は組版のように整えて表示します。

02

QR コード

テキストや URL から QR コードを生成し、スクリーンショットや画像から読み取ることもできます。

03

オープンSDK

379 個の .zenmod コマンドモジュールを内蔵（AI・アプリ・ゲーム・システム・Web の5分類）。Modules フォルダに JSON を置くだけでビルドなしでコマンドを追加でき、SDK ドキュメントとサンプルプロジェクトも公開中。

04

内蔵ブラウザー

枠なしの軽量ブラウザー。コマンドモジュールが URL を開くときに使われるため、普段のブラウザーを邪魔しません。

パーソナライズ

デスクトップは毎日いちばん長く見る画面。少しきれいにする価値があります。

01

ライブ壁紙

Windows Composition API を使って Web ページや動画をデスクトップアイコンの下の層に描画します。操作の妨げになりません。

02

デスクトップエフェクト

雪が舞うといった雰囲気づくりの演出。マウス操作を透過するのでクリックを妨げません。

03

ナビゲーションページ

グループをカスタマイズできるタブ型ナビゲーション。ブラウザーの新しいタブページを置き換えます。

各製品の公開情報に基づき、2026 年 8 月時点で整理しています。「プラグイン」は機能が内蔵ではなくサードパーティ製プラグインで提供されることを意味します。「⚠️」は部分的なサポートまたは特定プラットフォーム限定を意味します。

どのツールにも得意分野があります：PowerToys はシステムレベルの調整に強く、uTools と Raycast は拡張性の高いプラットフォーム、Flow Launcher と Wox は検索起点のランチャー、Launchy は軽量な古典、Everything と Listary はファイル検索の専門家です。yyzTools はよく使う機能を最初から 1 つのネイティブアプリに統合する道を選びました——プラグイン探しも、ウェブランタイムのオーバーヘッドもありません。ご自身のワークフローに合うものをお選びください。
