ディスクを食い尽くしているのは誰か — そしてどう片付けるか

yyzTools のディスク領域アナライザーはドライブを走査し、サイズ順にフォルダを色付きツリーマップで描画します。WizTree や WinDirStat と同じ手法で、100 万ファイル超でも高速。違うのは単独のユーティリティではない点 — 領域を食うファイルから直接、表示・プレビュー・ゴミ箱へ移動でき、そのままファイル検索やクリーンアップへ飛び込めます。

それでも WizTree / TreeSize が適する場面

ディスク解析の専業ツールとして最高水準を望むなら——極限の再走査速度、レポート印刷と出力、ネットワーク共有や非 NTFS / リムーバブルボリュームの走査——WizTree や TreeSize の方が成熟し充実しています。yyzTools は最深の単体アナライザーを目指しません。

yyzTools が適する場面

本当の関心が「C ドライブが満タンになった理由を、アプリを増やさずに解決したい」なら、yyzTools は一度に両方答えます。ツリーマップへ走査し、それらのファイルをその場で処理——表示・ゴミ箱・検索・ファイルクリーナー——ランチャーや OCR・翻訳を既に備えた同じ無料ツールボックスで。

よくある質問

yyzTools の分析は WizTree より速いですか？

どちらも NTFS $MFT を直読みするので、大容量ドライブも数秒で完走します。WizTree はこれ専用に作られており、極限走査や再走査ではより速く成熟し得ます。yyzTools の強みは走査「後」に何ができるかで、数百分の一秒を縮めることにはありません。

既に WizTree / WinDirStat がありますが、必要ですか？

見るだけならそれで十分、優れたツールです。占用を見るアプリ、掃除するアプリ、探すアプリと幾つも入れるのに飽きたら、一つにまとめる手段として yyzTools をどうぞ。

ネットワークドライブや USB も走査できますか？

ローカルの固定 NTFS ボリューム中心で、ネットワーク共有や非 NTFS / リムーバブルは現状サポートが限定的です——WizTree / TreeSize との現実的な差の一つです。
