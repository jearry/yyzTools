更新について

yyzTools は分割パッケージ方式で更新します。本体、フロントエンドのページ、コマンドモジュール、FFmpeg、OCR モデルなどをそれぞれ独立して配布しているため、更新確認時には実際に変更のあった部分だけをダウンロードし、毎回ソフトウェア全体を再インストールする必要はありません。

ダウンロードとインストールのよくあるご質問

Q01 yyzTools は完全に無料ですか。

はい。すべての機能が永久無料です。有料アンロックも会員制度も試用期間のカウントダウンもありません。

Q02 データを収集されますか。

いいえ。yyzTools はアカウント不要で、クリップボード履歴、ファイル検索、OCR はすべて端末内で処理されます。翻訳などオンライン機能をご自身で利用したときにのみ、入力内容が選択したサードパーティサービスへ送信されます。

Q03 インターネット接続は必要ですか。

ダウンロード、更新確認、翻訳などのオンライン機能のみネット接続が必要です。コマンドパレット、ファイル検索、OCR、クリップボード履歴、一括処理などは完全オフラインで動作します。

Q04 動作環境を教えてください。

64 ビット版の Windows 10（1809 以降）または Windows 11、ディスク容量は約 600 MB、そして Microsoft Edge WebView2 ランタイムが必要です。Windows 11 には標準搭載されており、Windows 10 で不足している場合はインストーラーが導入を案内します。

Q05 インストーラーを実行すると「Windows によって PC が保護されました」と表示される場合は？

これは、コード署名がないプログラムに対する Microsoft Defender SmartScreen の標準的な警告で、初回実行時に表示されることがあります。「詳細情報」→「実行」をクリックすればインストールを続行できます。ページに表示されている SHA-256 チェックサムでファイルの整合性を確認することもできます。

Q06 インストーラーに他ソフトのバンドルやブラウザー設定の変更はありますか？

ありません。インストーラーに含まれるのは yyzTools 本体と、動作に必要な内蔵コンポーネント（FFmpeg、OCR モデルなど、いずれもローカル機能のための依存物）だけです。サードパーティ製ソフトのバンドル、ブラウザのホームページ乗っ取り、自動起動以外の常駐プロセスは一切ありません。このページの SHA-256 チェックサムでファイルの整合性を確認できます。

Q07 yyzTools を完全にアンインストールするには？

システムの「設定 → アプリ」またはインストールフォルダーのアンインストーラーから実行してください。アンインストール時にユーザーデータ（設定、クリップボード履歴、使用統計など。いずれもユーザープロファイル内に保存され、レジストリの深部には散らばりません）を一緒に削除するか選べます。既定でユーザーディレクトリにインストールされるため、アンインストール後にサービスや自動起動項目は残りません。
