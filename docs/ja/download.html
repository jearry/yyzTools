インストール手順

  1. 上のインストーラーをダウンロードして実行します。
  2. 案内に従って表示言語を選びます。それ以外は既定のままで問題ありません。
  3. インストールが完了したら、Alt+Space でコマンドパレットを呼び出し、使い始めます。
  4. タスクトレイのアイコンから設定を開き、壁紙やエフェクトの切り替え、更新の確認ができます。

更新について

yyzTools は分割パッケージ方式で更新します。本体、フロントエンドのページ、コマンドモジュール、FFmpeg、OCR モデルなどをそれぞれ独立して配布しているため、更新確認時には実際に変更のあった部分だけをダウンロードし、毎回ソフトウェア全体を再インストールする必要はありません。

ダウンロードとインストールのよくあるご質問

yyzTools は完全に無料ですか。

はい。すべての機能が永久無料です。有料アンロックも会員制度も試用期間のカウントダウンもありません。

データを収集されますか。

いいえ。yyzTools はアカウント不要で、クリップボード履歴、ファイル検索、OCR はすべて端末内で処理されます。翻訳などオンライン機能をご自身で利用したときにのみ、入力内容が選択したサードパーティサービスへ送信されます。

インターネット接続は必要ですか。

ダウンロード、更新確認、翻訳などのオンライン機能のみネット接続が必要です。コマンドパレット、ファイル検索、OCR、クリップボード履歴、一括処理などは完全オフラインで動作します。

動作環境を教えてください。

64 ビット版の Windows 10（1809 以降）または Windows 11、ディスク容量は約 600 MB、そして Microsoft Edge WebView2 ランタイムが必要です。Windows 11 には標準搭載されており、Windows 10 で不足している場合はインストーラーが導入を案内します。
