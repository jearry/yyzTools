ShareX の代替をお探しですか？

ShareX はパワーユーザーのスイスアーミーナイフです——設定は深く、オープンソース、アップロードワークフローは右に出る者がいない。yyzTools のキャプチャモジュールは同じ日常をカバーしつつ——領域、スクロールキャプチャ、注釈、ピン留め——ShareX が行かない場所へ進みます：インストーラ同梱のローカル OCR エンジンと、ツールバーから一步の翻訳。

箱に入ったまま使える OCR——となりに翻訳

ShareX の OCR は Windows 内蔵エンジンを利用するため、新しい言語にはまずシステム言語パックのインストールが要ります。yyzTools は RapidOCR エンジンとモデルをインストーラに入れています：インストールした瞬間から動き、混在文字を扱い、ツールバーの OCR・翻訳ボタン（または独立のクイック OCR、Alt+T）が一枚のキャプチャを翻訳済みテキストに変えます。キャプチャの流れから出る必要はありません。

ShareX が引き続き最適なとき

キャプチャが「どこかへ送られる」ためのものなら——多数のアップロード先、カスタムアップローダー、キャプチャ後タスクチェーン、自動キャプチャ——あるいはあらゆるノブが外に見えたオープンソースの無料・アカウント不要ツールが欲しいなら、ShareX は今もパワーユーザーの選択で、そのコミュニティは Windows フリーウェア最大級のひとつです。

yyzTools がより合うとき

キャプチャが読んで返すためのものなら——文字を起こす、段落を翻訳する、長いページを丸ごと撮る——yyzTools はキャプチャウィンドウの中で完結させ、同じインストーラにランチャー、ファイル検索、クリップボード履歴、バッチ処理など計 387 モジュールが入っています。

よくある質問

yyzTools は ShareX の代替になりますか？

日常のキャプチャ——領域、スクロール、注釈、ピン留め——はほぼ対応し、翻訳と同梱 OCR エンジンが加わります。ただし ShareX の本領——アップロード先、カスタムアップローダー、キャプチャ後の自動化——に相当するものはありません。共有ヘビーユーザーは ShareX を残してください。

OCR エンジンの違いは？

yyzTools は RapidOCR エンジンとモデルをインストーラ内に納め、インストール直後から使え、混在文字向きです。ShareX は Windows 内蔵 OCR を呼び出し、その言語はインストール済みシステム言語パックに依存します——追加には Windows の言語設定への手続きが要ります。

両方入れたままでも大丈夫？

はい。ホットキーが衝突する場合はどちらかで変更してください（yyzTools：トレイアイコン → 設定 → ショートカット）。
