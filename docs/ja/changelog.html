v1.0.2.1200

最新バージョン 2026-08-14
  • コマンドパレットのファイルモジュールで一括コピー・切り取り・削除に対応（Shift・Ctrl で複数選択、Ctrl+A で全選択）。
  • コマンドパレットのファイルモジュールにおける DXF ファイルのプレビュー文字化けを修正。
  • コマンドパレットのファイルモジュールの PDF 読み込み速度を改善。
  • データ変換 / 構造化テキストの偶発的なエラーを修正。
  • ゲーム「地球を救え」で多言語と効果音に対応。
  • 設定にインポート・エクスポートを追加。
  • スクリーンショットは保存成功後に終了するよう変更。
  • エンコード/デコードと正規表現にサンプルボタンを追加。
  • ドックで URL に対応。

v1.0.0.1000

2026-08-08
  • 全機能ページを多言語対応にし、簡体中国語と英語をサポートしました。
  • データ生成モジュールを追加：UUID / GUID、ULID、ランダム文字列、テストデータ。
  • PDF 一括処理モジュールを追加：結合、分割、透かし、圧縮、暗号化と復号。
  • ImageMagick と FFmpeg を基盤とする画像・動画の一括処理モジュールを追加しました。
  • コマンドモジュールを 379 個に拡充し、AI とよく使う Web サイトの分類項目を追加しました。
  • NirCmd.exe を自社開発の yyzCmd.exe に置き換え、システムコマンドを純粋な Win32 実装に変更しました。
  • 長いスクリーンショットのスクロール結合に対応。クリップボードの画像をデスクトップにピン留めできるようになりました。
  • 分割パッケージ方式の更新に変更し、更新確認時は変更のあった部分のみをダウンロードします。
