IDM / Motrix が向く場面

ダウンロードが目的の全部なら専用ツールが有利です。IDM のブラウザ統合と Web 動画取得は最も成熟（年間課金）し、Motrix は本当によくできる無料・OSS・クロスプラットフォームのダウンローダー（トレント/マグネット対応）。ダウンロードだけならどちらかを、特に無料・OSS なら Motrix をどうぞ。

yyzTools が向く場面

アプリを増やしたくないなら、yyzTools の aria2 ダウンローダーはランチャー・全ディスク検索・プレビュー・一括リネームと同じ無料 Alt+Space ボックスに最初から入っていて、商用も無料です。狙いは「アプリを一つ減らす」ことで、ブラウザ級の動画スニファーではありません。

よくある質問

yyzTools は IDM ほど速いですか？

どちらもファイルを分割してマルチスレッドで高速化し、レジュームにも対応します。IDM は実績で勝り、何より yyzTools のダウンローダーに無いブラウザ自動捕捉と Web 動画取得を持ちます。yyzTools の魅力は別の軸 — 堅実で、商用も含め無料なダウンローダーが他のツールと同じ箱に入っていることです。

すでに Motrix を使っていますが、なぜ yyzTools？

Motrix は優れた無料・OSS・クロスプラットフォームのダウンローダーです。それだけなら残す方が賢明（macOS/Linux も動く — yyzTools は Windows のみ）。ランチャー・ファイル検索・OCR・プレビュー・一括リネームを担う Alt+Space アプリにダウンロードも畳み込みたい時に yyzTools が効きます。

ダウンローダーは本当に商用無料ですか？

はい。yyzTools の全機能と同じ無料ビルドで、個人も商用も無料です — IDM が年間課金になる点と分かれます。
