よくあるご質問

本当に永久無料ですか。今後有料になりませんか。

本当に無料です。有料アンロックや会員制度は設けず、中核機能を有料項目として切り出すこともありません。yyzTools は、また一つサブスクリプションを増やすものではなく、長くデスクトップに置いていただけるツールでありたいと考えています。

自分のデータはアップロードされますか。

いいえ。クリップボード履歴、ファイル検索、アプリ統計、OCR などはすべて本体内で処理・保存されます。翻訳のようなオンライン機能をご自身で利用されたときにのみ、入力された内容が選択したサービスの提供元へ送信されます。またソフトウェアは定期的に更新を確認しますが、その通信で送られるのはバージョン番号だけです。

アカウント登録は必要ですか。

不要です。登録を求めることはなく、身元に関する情報を自発的に収集することもありません。

対応する OS を教えてください。

Windows 10 と Windows 11 の 64 ビット版です。Microsoft Edge WebView2 ランタイムが必要で、Windows 11 には標準で搭載されています。Windows 10 で不足している場合はインストーラーが導入を案内します。

リソースを多く消費しますか。

常駐する主プロセスは非常に軽量です。壁紙、スクリーンショット、キー入力表示などは独立したプロセスになっており、使わなければ起動しません。ゲームを始めるときはワンクリックでゲームモードに切り替え、壁紙とエフェクトを一時停止できます。

自分で機能を追加するには、どうすればよいですか。

インストール先の Modules フォルダーに .zenmod（JSON）ファイルを置き、名称、アイコン、実行するコマンドを記述します。再起動すればコマンドパレットから検索できるようになり、コードのコンパイルは一切不要です。

デスクトップをひとつのツールボックスに任せる

無料でダウンロードできます。インストール後、Ctrl をダブルタップすればすぐに始められます。
