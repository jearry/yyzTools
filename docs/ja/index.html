よくあるご質問

本当に永久無料ですか。今後有料になりませんか。

本当に無料です。有料アンロックや会員制度は設けず、中核機能を有料項目として切り出すこともありません。yyzTools は、また一つサブスクリプションを増やすものではなく、長くデスクトップに置いていただけるツールでありたいと考えています。

自分のデータはアップロードされますか。

いいえ。クリップボード履歴、ファイル検索、アプリ統計、OCR などはすべて本体内で処理・保存されます。翻訳のようなオンライン機能をご自身で利用されたときにのみ、入力された内容が選択したサービスの提供元へ送信されます。またソフトウェアは定期的に更新を確認しますが、その通信で送られるのはバージョン番号だけです。

アカウント登録は必要ですか。

不要です。登録を求めることはなく、身元に関する情報を自発的に収集することもありません。

対応する OS を教えてください。

Windows 10 と Windows 11 の 64 ビット版です。Microsoft Edge WebView2 ランタイムが必要で、Windows 11 には標準で搭載されています。Windows 10 で不足している場合はインストーラーが導入を案内します。

リソースを多く消費しますか。

常駐する主プロセスは非常に軽量です。壁紙、スクリーンショット、キー入力表示などは独立したプロセスになっており、使わなければ起動しません。ゲームを始めるときはワンクリックでゲームモードに切り替え、壁紙とエフェクトを一時停止できます。

yyzTools と PowerToys の違いは何ですか。

PowerToys は Microsoft のモジュール型ユーティリティ集で、上級者向けに使う部品を自分で有効化していくものです。yyzTools は一体化スイートで、コマンドパレット、翻訳、OCR、クリップボード履歴、ファイル・画像・動画・PDF の一括処理が同じインストーラーで初期設定済みですぐ使えます。UI は 12 言語に対応しています。どちらも無料なので、両方入れておく人も多くいます。

Flow Launcher や Raycast と比べるとどうですか。

Flow Launcher は検索とプラグインに強い優秀なオープンソースランチャーです。Raycast は macOS 出身で、Windows 版はまだベータ、完全な体験には Pro サブスクリプションが必要です。yyzTools は「インストールしたら全部入り」：翻訳・OCR・クリップボード履歴・一括処理・ライブ壁紙をすべて内蔵し、プラグイン探しもサブスクリプションも不要です。

すでに PowerToys を使っていますが、yyzTools も入れられますか。

はい、問題なく共存できます。yyzTools の常駐プロセスは軽く、壁紙やスクリーンショットは必要なときだけ起動し、ホットキーもすべてカスタマイズできます。よくある組み合わせ：PowerToys はウィンドウ分割とキー割り当て、yyzTools は起動・翻訳・OCR・一括処理に。

uTools、Wox、ZTools と比べるとどうですか。

uTools はプラグインプラットフォームで、本体は無料ですが人気プラグインの多くは有料会員制です。Wox は検索に特化したオープンソースのランチャーです。ZTools はオープンソースの uTools 代替で、機能はプラグインマーケットから組み合わせます。yyzTools は 40 以上のモジュールをインストーラーに同梱し、会員制度も有料アンロックもなく、クリップボード・検索・OCR のデータはすべて端末内に留まります。
