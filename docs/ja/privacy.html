プライバシーポリシー

発効日：2026 年 9 月 15 日 · バージョン：v1.1

本ポリシーは、yyzTools（以下「本ソフトウェア」といいます）がお客様のデータをどのように取り扱うかを説明するものです。中核となる方針は一言で表せます。ローカル優先（local-first）——お使いのパソコン内で完結できることは、決して外部へ送りません。本ポリシーは利用規約第 3 条を詳しく説明したものであり、両者に不一致がある場合は本ポリシーが優先します。

1. 収集しない情報

本ソフトウェアはアカウント登録を必要とせず、氏名、電話番号、メールアドレスなどの個人識別情報を収集しません。また、いかなる形式のユーザープロファイリングや行動計測の送信も行いません。

当方にはお客様の利用データを保存するサーバーがありません。そもそも本ソフトウェアが利用データを当方へ送信しないためです。

2. ローカルで処理・保存されるデータ

以下のデータはすべてお客様のデバイス上で取得、処理、保存され、本体の設定ファイルとデータベースに保管されます。本ソフトウェアが自動的にアップロードすることはありません：

  • クリップボード履歴：コピーしたテキストと画像の記録。
  • アプリ使用統計：各アプリの前面表示時間とアクティブ化回数。
  • ファイル検索とプレビュー：本体のファイルインデックスと、開いたファイルのパス。
  • 文字認識（OCR）：認識はローカルの RapidOCR エンジンで完結し、画像が本体から出ることはありません。
  • 設定と各種の好み：ショートカットキー、ドックの項目、壁紙設定、表示言語など。
  • コマンドパレットの記録：検索した語句と、起動した項目。

3. ネットワーク接続が必要な機能

以下の場合にのみネットワーク通信が発生し、いずれもお客様の操作によって開始されます：

  • スーパー翻訳：送信されたテキストや画像は、設定で選択されたサービスに応じて、該当する第三者のオンライン翻訳サービスへ送信されます。これらのデータは当該第三者が自社のプライバシーポリシーに従って取り扱うため、当方の管理範囲外となります。
  • ファイルダウンロード：お客様が入力したリンクから、対象のサーバーへ直接接続します。
  • コマンドモジュールとナビゲーションページ：URL を開く際に、内蔵ブラウザーがそのサイトへ直接アクセスします。
  • ライブ壁紙：オンラインの Web ページを壁紙のソースとして利用する場合、そのページへアクセスします。

データを一切外部へ送信したくない場合は、上記のオンライン機能を使わないという選択ができます。その他の機能は完全にオフラインで利用できます。

4. 更新の確認

本ソフトウェアは、新しいバージョンがあるかを判断するために、公式ミラー（GitHub、jsDelivr など）へ定期的にバージョン一覧を要求します。この通信で送信されるのはバージョン番号などの必要な情報のみで、お客様の個人データや利用データは一切含みません。

設定で自動確認を無効にし、タスクトレイのメニューから手動で更新を確認するように変更できます。

5. データに対するお客様の管理権

  • すべてのローカルデータはお客様のユーザーフォルダー内にあり、いつでも直接、閲覧、バックアップ、書き出し、削除ができます。
  • クリップボード履歴は、コマンドパレットから 1 件ずつ削除することも、まとめて消去することもできます。
  • アンインストール時には、データフォルダーを併せて削除するかを選択できます。削除後は復元できません。

6. 第三者コンポーネント

本ソフトウェアには以下のオープンソースまたは無料のコンポーネントが含まれ、それぞれ本来のライセンス条項に従って配布されています：コードレベルで統合した Microsoft Edge WebView2（レンダリングランタイム）、Dear ImGui、nlohmann/json、SQLite、zlib、ならびにローカルプロセスとして呼び出されデータをアップロードしない FFmpeg、ImageMagick、Ghostscript、pdfcpu、RapidOCR（PaddleOCR ベース）、Aria2、7-Zip、OpenSSL などのツール。いずれもお使いの機器上でのローカル処理に用いられ、データのアップロードには関与しません。

7. 児童のプライバシー

本ソフトウェアは汎用のデスクトップツールであり、児童向けに設計されておらず、年齢に関する情報を自発的に収集することもありません。

8. ウェブサイトのアクセス統計

当サイト（yyztools.com）にアクセスすると、Microsoft Clarity を利用して匿名のアクセス統計とユーザビリティデータ（ページビュー、アクセス元、大まかな地域、クリックヒートマップ、匿名化されたセッション録画）を収集し、コンテンツの利用状況を把握してサイト体験の改善に役立てています。Clarity はセッションに匿名の識別子を割り当てるだけで、氏名やメールアドレスなどの個人を特定する情報を収集せず、入力内容は既定でマスクされます。データは Microsoft のプライバシーポリシーに基づいて処理され、当方はこれによって個人を識別することはできず、もしません。

9. ポリシーの変更とお問い合わせ

本ポリシーを改訂した場合は、新しい発効日を本ページに記載します。データの取り扱い方法に実質的な変更が生じる場合は、更新内容の説明でも併せてお知らせします。ご不明な点は、下記のメールアドレスまたは GitHub Issues よりお問い合わせください。
