uTools の代替をお探しですか？

uTools はプラグイン第一のランチャーです：超軽量コアに 3,000+ のプラグインマーケット、無料版にはインストール上限があり、解除は会員で。yyzTools は逆の賭けに出ます——ひとつのインストーラに 387 モジュールがすでに入っていて、入れた瞬間から全部使え、上限も会員もアカウントもありません。

上限なし、会員なし、組み立てなし

uTools の無料版はインストールできるプラグイン数を制限し、その解除こそ会員の価値です。yyzTools に対応する概念はありません：インストーラに 387 個の使えるモジュールがすでに入っていて、制限するものも解放するものもない——ランチャー、ファイル検索、OCR、翻訳、クリップボード履歴、バッチ処理、初日からすべて揃っています。

uTools が引き続き最適なとき

製品ではなく基盤が欲しいのなら——3,000+ のコミュニティプラグイン、Windows / macOS / Linux のクロスプラットフォーム、完成品が予見しなかったニッチな需要——uTools のエコシステムは、ひとつのインストーラに入るものよりはるかに大きい。プラグイン好きにとって今も自然な居場所です。

yyzTools がより合うとき

道具箱を手作業で組み立てたくないなら——マーケット巡りも、インストール上限も、それを解除する会員も、アカウント登録も不要なら——yyzTools は初日から 387 個の動くモジュールを渡します：ランチャー、全ディスク検索、OCR、翻訳、クリップボード履歴、バッチ処理ほか、商用も無料です。

よくある質問

yyzTools は uTools のようにプラグインに対応しますか？

拡張の単位は .zenmod コマンドモジュール——コマンドパレットにコマンドを登録する JSON ファイルで、背後にウェブページを置けます。387 個が同梱され、SDK ドキュメントとサンプルプロジェクトは無料でダウンロードできます。プラグインマーケットより意図的に軽く作ってあります：ランタイムも公開フローもありません。

どちらも既定は Alt+Space ですが、衝突しませんか？

します。既定のグローバルホットキーが両方 Alt+Space なので、併用の初回にどちらかで変更してください（yyzTools：トレイアイコン → 設定 → ショートカット）。以降は干渉しません。

uTools の無料版は何が制限されるのですか？

uTools の公式な位置づけは「基本機能は永久無料、付加サービスは有料」です：無料版にはプラグインのインストール数上限があり、無制限には会員が必要で、会員にはマルチデバイス同期なども含まれます。yyzTools にその概念はありません——全モジュールがインストーラに同梱されます。
