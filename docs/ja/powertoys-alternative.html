PowerToys の代替を探していますか？

PowerToys は優れたシステムユーティリティ集です。yyzTools は「ランチャー＋ツールボックス」の領域で重なりつつ、PowerToys が手が届かない部分まで踏み込みます。自前の全ディスク検索、本格翻訳、コピーした画像を OCR して文字まで検索できるクリップボードを備え、合計 387 の機能をキーボード先行の 1 アプリに詰め込みました。

yyzTools vs PowerToys

どちらもオールインワンですが、狙いが異なります。PowerToys は Windows 自体を強化する（ウィンドウ配置、キー再割り当て、システム調整）。yyzTools は毎日使うツール——検索、OCR、翻訳、クリップボード、一括処理、壁紙——をひとつの軽量インストールにまとめます。

クリップボードが画像を読む

文字を含む画像（スクリーンショットや画像ファイル）をコピーすると、yyzTools は裏で OCR を実行し、文字を画像と一緒に履歴へ保存します。後で画像の中にしかない単語で検索でき、認識したテキストだけを取り出してコピーもできます。Win+V は画像を残すだけで読まず、Text Extractor は一度読んだら終わり。どちらも検索できる文字の履歴にはなりません。

それでも PowerToys が適する場面

Windows 自体を操りたい——FancyZones のウィンドウ分割、Keyboard Manager のキー再割り当て、あるいは広く深いシステムツール群を、しかも全面オープンソースで Microsoft の支援付きで——というなら、PowerToys の方が専門的で強力です。使うモジュールだけ有効にできます。yyzTools は現時点でウィンドウ分割とキー再割り当てを提供していません。

yyzTools が適する場面

PowerToys Run＋ファイル検索＋クリップボード管理＋画面 OCR＋翻訳を、スタック導入ではなく 1 アプリにまとめたい。コピーした画像を検索できる文字にしたい。さらに画像/動画/PDF の一括処理、ライブ壁紙、ダウンロード管理も欲しい——そんなとき yyzTools は軽い 1 つのインストールで応え、キーボード先行、12 言語で使えます。

よくある質問

yyzTools は PowerToys を完全に置き換えられますか？

ランチャーとツールボックスの重複部分なら、ほぼ可能です。PowerToys には yyzTools がまだ持たないシステムツール（主に FancyZones と Keyboard Manager）があります。逆に yyzTools には PowerToys にない内蔵機能——本格翻訳、自社全ディスク検索、検索できる OCR クリップボード、動画・PDF のバッチ、ライブ壁紙——があります。実際に使う重複範囲で選んでください。

両方をインストールできますか？

はい、競合しません。ただしグローバルホットキー（どちらも既定で Alt+Space）に注意し、片方の起動キーを変えてください。

OCR クリップボードは何ができますか？

文字を含む画像をコピーすると、yyzTools は OCR を実行しテキストを履歴に保存します。その画像の中にだけ現れる単語で検索でき、抽出テキストだけコピーも可能です。Win+V は画像を残すだけで読まず、Text Extractor は履歴を残しません。

一度入れて、道具の山を置き換える

無料ダウンロード。Alt+Space を押し、文字のある画像をコピー。あとで画像の中にしかない単語でクリップボードを検索してみてください。
