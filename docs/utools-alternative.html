No cap, no membership, no assembling

uTools' free tier caps how many plugins you may install, and lifting the cap is precisely what the membership is for. yyzTools has no equivalent concept: the installer already carries 387 working modules, so there is nothing to cap and nothing to unlock — launcher, file search, OCR, translation, clipboard history and batch tools are all there on day one.

When uTools is still the right pick

If you want a platform more than a product — 3,000+ community plugins, cross-platform use across Windows, macOS and Linux, and niche needs no finished suite anticipated — uTools' ecosystem is far larger than anything one installer can ship. For plugin lovers it remains the natural home.

When yyzTools is the better fit

If you would rather not assemble your toolbox by hand — no browsing, no install cap, no membership to lift it, no account — yyzTools hands you 387 working modules on day one: launcher, full-disk search, OCR, translation, clipboard history, batch tools and more, free for business use too.

Common questions

Does yyzTools support plugins like uTools?

Its extension unit is the .zenmod command module — a JSON file that registers commands in the palette, with an optional web page behind them. 387 ship in the box, and an SDK with docs and a sample project is free to download. It is deliberately lighter than a plugin marketplace: no plugin runtime, no publishing pipeline.

Both launch on Alt+Space — do they clash?

Yes, the default global hotkey is Alt+Space on both, so change it on either side the first time you run them together (yyzTools: tray icon → Settings → Shortcuts). After that they coexist without conflict.

What exactly is limited in uTools' free tier?

uTools' official line is "core free forever, premium services paid": the free tier caps plugin installs, unlimited requires a membership that also bundles multi-device sync. yyzTools has no such concept — every module ships in the installer.
