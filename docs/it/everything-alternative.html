Cerchi un’alternativa a Everything?

yyzTools include un proprio motore di ricerca su tutto il disco, costruito nello stesso modo di Everything — letture dirette di NTFS $MFT per l’indice, monitoraggio del journal USN per gli aggiornamenti in tempo reale, sintassi di query compatibile. Ciò che lo distingue: lo stesso programma di installazione porta con sé anche un launcher, la traduzione, l’OCR, gli strumenti in blocco e oltre 40 moduli.

yyzTools vs Everything

I due seguono la stessa strada tecnica; la differenza è nel posizionamento. Everything è uno strumento autonomo dedicato alla ricerca dei file per nome, mentre yyzTools integra la ricerca dei file in una cassetta degli attrezzi per la produttività.

Quando Everything resta la scelta giusta

Se tutto ciò che serve è la ricerca definitiva dei file per nome — query con espressioni regolari, un server HTTP per condividere i risultati, l’integrazione tramite SDK o l’indicizzazione di unità non NTFS e rimovibili — Everything resta uno specialista maturo e affidabile. Il motore di yyzTools indicizza attualmente solo volumi NTFS fissi e non supporta regex:; non ha la pretesa di sostituire Everything in ogni nicchia.

Quando yyzTools è la scelta migliore

Se preferisci sostituire con una sola app una combinazione di due strumenti — per esempio PowerToys Run per l’avvio più Everything per i file — yyzTools lo fa con un’unica installazione: una sola casella Alt+Space cerca insieme applicazioni, file, processi, finestre, segnalibri e appunti, con azioni di anteprima, apertura della cartella e Cestino sui risultati, e alle spalle oltre 40 moduli come traduzione, OCR, cronologia degli appunti ed elaborazione in blocco.

Domande frequenti

La ricerca file di yyzTools è un involucro intorno a Everything?

No. Dalla v1.0.5 la ricerca file gira su un motore completamente sviluppato internamente (letture dirette di NTFS $MFT + aggiornamenti del journal USN). La dipendenza da Everything è stata rimossa dal programma di installazione e l’uso di memoria dell’indice è sceso da centinaia di MB a pochi MB.

La sintassi di query è compatibile con Everything?

La sintassi comune è compatibile: path:, ext:, size:, datemodified:, i caratteri jolly e le combinazioni AND / OR / NOT funzionano tutti. Le espressioni regolari (regex:) non sono ancora supportate: è il principale divario di sintassi rispetto a Everything.

Posso tenere Everything installato insieme a yyzTools?

Sì, non vanno in conflitto. Detto questo, se la ricerca file di yyzTools copre le tue esigenze, tenerne solo uno fa risparmiare risorse.
