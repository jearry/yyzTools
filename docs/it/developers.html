Crea moduli per yyzTools

Un modulo è una normale pagina HTML/JS più un file .zenmod: niente framework, niente fase di build. Scegli da dove partire.

Guida introduttiva

Crea da zero una web app che gira dentro yyzTools: struttura della pagina, host della finestra, i18n, API native asincrone e persistenza della configurazione. Senza build.

Riferimento API

Riferimento completo delle API native di yyzTools: finestre, applicazioni, processi, file, media, OCR, cifratura, appunti, segnalibri, comandi e aggiornamenti.

Scarica il progetto di esempio

Un modulo completo e già funzionante. Copia le cartelle Web e Modules nella cartella di yyzTools.exe — si uniscono a quelle già presenti — e riavvia: il pannello dei comandi lo troverà. Include entrambi i documenti in inglese.
