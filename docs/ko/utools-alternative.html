uTools 대안을 찾고 계신가요?

uTools는 플러그인 중심 런처입니다: 초경량 코어에 3,000+ 플러그인 마켓, 무료 버전에는 설치 한도가 있고 해제는 멤버십으로 합니다. yyzTools는 반대의 길을 갑니다——설치 파일 하나에 387개 모듈이 이미 들어 있어, 설치하는 순간 전부 쓸 수 있고 한도도 멤버십도 계정도 없습니다.

yyzTools vs uTools

출발점은 같습니다——키보드 중심으로 무엇이든 여는 상자——지만 걸고 있는 것은 반대입니다. uTools는 플러그인 플랫폼을, yyzTools는 완성된 도구 상자를 내놓습니다.

한도도, 멤버십도, 조립도 없습니다

uTools 무료 버전은 설치할 수 있는 플러그인 수를 제한하고, 그 해제가 곧 멤버십의 가치입니다. yyzTools에는 해당 개념이 없습니다: 설치 파일에 387개의 쓸 수 있는 모듈이 이미 들어 있어 제한할 것도, 해제할 것도 없습니다——런처, 파일 검색, OCR, 번역, 클립보드 기록, 일괄 처리가 첫날부터 모두 자리합니다.

uTools가 여전히 나은 선택일 때

제품이 아니라 플랫폼을 원한다면——3,000+ 커뮤니티 플러그인, Windows / macOS / Linux 삼면 지원, 완성품이 예견 못 한 틈새 필요——uTools의 생태계는 설치 파일 하나에 담긴 것보다 훨씬 큽니다. 플러그인 애호가에게 여전히 자연스러운 곳입니다.

yyzTools가 더 맞을 때

도구 상자를 손수 조립하고 싶지 않다면——마켓 둘러보기도, 설치 한도도, 그것을 푸는 멤버십도, 계정 가입도 없다면——yyzTools는 첫날부터 387개의 동작하는 모듈을 건넵니다: 런처, 전체 디스크 검색, OCR, 번역, 클립보드 기록, 일괄 처리 등, 상업용도 무료입니다.

자주 묻는 질문

yyzTools는 uTools처럼 플러그인을 지원하나요?

확장 단위는 .zenmod 명령 모듈입니다——명령 팔레트에 명령을 등록하는 JSON 파일이고, 뒤에 웹페이지를 둘 수 있습니다. 387개가 기본 동봉되고 SDK 문서와 샘플 프로젝트는 무료로 내려받을 수 있습니다. 플러그인 마켓보다 의도적으로 가볍습니다: 런타임도 게시 절차도 없습니다.

둘 다 기본이 Alt+Space인데 충돌하지 않나요?

합니다. 기본 전역 단축키가 양쪽 모두 Alt+Space라 함께 쓰는 첫 번째 순간 어느 한쪽에서 바꾸세요(yyzTools: 트레이 아이콘 → 설정 → 단축키). 이후에는 간섭하지 않습니다.

uTools 무료 버전은 정확히 뭐가 제한되나요?

uTools의 공식 입장은 「기본 기능은 영구 무료, 부가 서비스는 유료」입니다: 무료 버전에는 플러그인 설치 수 한도가 있고, 무제한은 멤버십이 필요하며 멤버십에는 다중 기기 동기화 등도 포함됩니다. yyzTools에는 그런 개념이 없습니다——모든 모듈이 설치 파일에 들어 있습니다.

마켓을 건너뛰고, 도구는 그대로

무료 다운로드. Alt+Space를 누르면 387개 모듈이 이미 뒤에——검색, OCR, 번역, 클립보드, 일괄 처리.
