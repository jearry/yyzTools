yyzTools 모듈 만들기

모듈은 일반 HTML/JS 페이지와 .zenmod 파일 하나뿐입니다. 프레임워크도 빌드 단계도 필요 없습니다. 시작점을 선택하세요.

빠른 시작

yyzTools 안에서 실행되는 웹 앱을 처음부터 만들기: 페이지 구성, 창 호스트, 다국어, 비동기 Native API, 설정 저장. 빌드 불필요.

API 레퍼런스

yyzTools Native API 전체 레퍼런스: 창 제어, 앱 관리, 프로세스, 파일 작업, 미디어 처리, OCR, 암호화, 클립보드, 북마크, 명령 실행, 업데이트.

샘플 프로젝트 다운로드

그대로 실행되는 완성형 모듈입니다. 동봉된 Web, Modules 두 폴더를 yyzTools.exe가 있는 폴더에 복사해 기존 폴더와 합친 뒤 다시 실행하면 커맨드 팔레트에서 바로 찾을 수 있습니다. 두 문서의 영어본도 포함됩니다.
