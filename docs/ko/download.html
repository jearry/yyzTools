업데이트 안내

yyzTools는 분할 패키지 업데이트 방식을 사용합니다. 메인 프로그램, 프런트엔드 페이지, 명령 모듈, FFmpeg, OCR 모델 등이 각각 독립적으로 패키징되어 업데이트를 확인할 때 실제로 변경된 부분만 내려받으므로, 매번 전체를 다시 설치할 필요가 없습니다.

다운로드 및 설치 자주 묻는 질문

Q01 yyzTools는 완전히 무료인가요?

네. 모든 기능이 영구 무료입니다. 유료 잠금 해제도, 멤버십도, 평가판 카운트다운도 없습니다.

Q02 데이터를 수집하나요?

아니요. yyzTools는 계정이 필요 없고 클립보드 기록, 파일 검색, OCR은 모두 사용자 PC에서 처리됩니다. 번역 같은 온라인 기능을 직접 사용할 때에만 입력 내용이 선택한 서드파티 서비스로 전송됩니다.

Q03 인터넷 연결이 필요한가요?

다운로드, 업데이트 확인, 번역 등 온라인 기능에만 네트워크가 필요합니다. 커맨드 팔레트, 파일 검색, OCR, 클립보드 기록, 일괄 처리 등은 완전히 오프라인으로 동작합니다.

Q04 시스템 요구 사항은 무엇인가요?

64비트 Windows 10(1809 이상) 또는 Windows 11, 약 600 MB의 디스크 공간, Microsoft Edge WebView2 런타임이 필요합니다. Windows 11에는 기본 포함되어 있고, Windows 10에서 없으면 설치 프로그램이 안내합니다.

Q05 설치 파일을 실행하면 "Windows에서 PC를 보호했습니다"라는 알림이 뜹니다. 어떻게 해야 하나요?

코드 서명이 없는 프로그램에 대해 표시되는 Microsoft Defender SmartScreen의 일반적인 경고로, 처음 실행 시 나타날 수 있습니다. "추가 정보" → "그래도 실행"을 클릭하면 설치를 계속할 수 있습니다. 페이지에 표시된 SHA-256 체크섬으로 파일 무결성을 확인할 수도 있습니다.

Q06 설치 파일에 다른 소프트웨어 번들이나 브라우저 설정 변경이 있나요?

없습니다. 설치 파일에는 yyzTools 본체와 실행에 필요한 내장 구성 요소(FFmpeg, OCR 모델 등 로컬 기능용 의존 요소)만 포함됩니다. 서드파티 소프트웨어 번들, 브라우저 홈페이지 강제 변경, 자동 시작 외의 상주 프로세스가 전혀 없습니다. 이 페이지의 SHA-256 체크섬으로 파일 무결성을 확인할 수 있습니다.

Q07 yyzTools를 완전히 제거하려면 어떻게 하나요?

시스템 "설정 → 앱" 또는 설치 폴더의 제거 프로그램을 실행하면 됩니다. 제거 시 사용자 데이터(설정, 클립보드 기록, 사용 통계 등은 모두 사용자 프로필에 저장되며 레지스트리 깊숙이 흩어지지 않음)를 함께 삭제할지 선택할 수 있습니다. 기본적으로 사용자 디렉터리에 설치되므로 제거 후 서비스나 자동 시작 항목이 남지 않습니다.
