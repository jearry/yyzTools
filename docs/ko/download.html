yyzTools 다운로드

현재 버전 v1.0.4.1400 · Windows 10 / 11 · 64비트 · 평생 무료

공식 다운로드

GitHub Releases의 원본 다운로드 주소입니다. 속도는 네트워크 환경에 따라 달라집니다.

yyzTools-setup-1.0.4.1400.exe
설치 파일 다운로드 GitHub Releases 페이지에서 직접 파일을 선택할 수도 있습니다

휴대용 버전

설치가 필요 없습니다. 쓰기 가능한 아무 폴더에 압축을 풀고 yyzTools.exe를 실행하면 모든 데이터가 해당 폴더에 저장되며 온라인 업데이트도 지원됩니다.

yyzTools-v1.0.4.1400-portable.7z
휴대용 버전 다운로드

시스템 요구 사항

운영체제
Windows 10 1809 이상 / Windows 11(64비트)
런타임
Microsoft Edge WebView2(Windows 11 기본 포함, Windows 10에서 없으면 설치 프로그램이 안내)
디스크 공간
약 600 MB(FFmpeg, ImageMagick, OCR 모델 등 내장 구성 요소 포함)
권한
기본적으로 사용자 폴더에 설치되며 관리자 권한이 필요하지 않습니다

설치 순서

  1. 위의 설치 파일을 다운로드해 실행합니다.
  2. 안내에 따라 인터페이스 언어를 선택하고, 나머지는 기본값으로 두면 됩니다.
  3. 설치가 끝나면 Alt+Space로 커맨드 팔레트를 열고 사용을 시작합니다.
  4. 트레이 아이콘에서 설정을 열고 배경화면과 특수 효과를 전환하거나 업데이트를 확인할 수 있습니다.

업데이트 안내

yyzTools는 분할 패키지 업데이트 방식을 사용합니다. 메인 프로그램, 프런트엔드 페이지, 명령 모듈, FFmpeg, OCR 모델 등이 각각 독립적으로 패키징되어 업데이트를 확인할 때 실제로 변경된 부분만 내려받으므로, 매번 전체를 다시 설치할 필요가 없습니다.

다운로드 및 설치 자주 묻는 질문

yyzTools는 완전히 무료인가요?

네. 모든 기능이 영구 무료입니다. 유료 잠금 해제도, 멤버십도, 평가판 카운트다운도 없습니다.

데이터를 수집하나요?

아니요. yyzTools는 계정이 필요 없고 클립보드 기록, 파일 검색, OCR은 모두 사용자 PC에서 처리됩니다. 번역 같은 온라인 기능을 직접 사용할 때에만 입력 내용이 선택한 서드파티 서비스로 전송됩니다.

인터넷 연결이 필요한가요?

다운로드, 업데이트 확인, 번역 등 온라인 기능에만 네트워크가 필요합니다. 커맨드 팔레트, 파일 검색, OCR, 클립보드 기록, 일괄 처리 등은 완전히 오프라인으로 동작합니다.

시스템 요구 사항은 무엇인가요?

64비트 Windows 10(1809 이상) 또는 Windows 11, 약 600 MB의 디스크 공간, Microsoft Edge WebView2 런타임이 필요합니다. Windows 11에는 기본 포함되어 있고, Windows 10에서 없으면 설치 프로그램이 안내합니다.
