Typora 대안을 찾고 있나요?

Typora는 "보이는 그대로" 쓰는 Markdown 작성을 최고 수준으로 다듬었지만 그 대가는 $14.99 일시불입니다. yyzTools는 같은 무료 설치 프로그램 안에 milkdown 기반 WYSIWYG Markdown 편집기를 내장했습니다. 제목, 표, 작업 목록, 각주, KaTeX 수식, Mermaid 다이어그램, 붙여넣으면 저장되는 이미지, 자동 저장——옆에는 OCR, 번역, 파일 검색까지, 총 388개 모듈 중 하나입니다.

무료로 얻는 WYSIWYG

Typora의 가격 페이지에는 $14.99라고 적혀 있습니다. yyzTools의 Markdown 편집기는 무료 설치 프로그램의 한 부분입니다. milkdown의 WYSIWYG, GFM 전체, KaTeX 수식과 Mermaid 다이어그램, 붙여넣은 즉시 문서 폴더에 저장되는 이미지, 기본 5초 간격 자동 저장——가입도 로그인도 없고 상업용도 무료입니다.

여전히 Typora가 좋은 때

Typora는 한 가지 기술을 오랫동안 다듬어 왔습니다. 여러 형식 내보내기, 테마 스토어와 사용자 CSS, 개요 사이드바와 파일 트리, 전체 검색과 맞춤법 검사, Windows / macOS / Linux에서 일관된 경험——일시불 1회, 라이선스 1개로 3대 기기. 장문을 자주 쓰거나 내보내서 전달해야 하거나 Mac/Linux에서 쓰는 사람에게 Typora는 여전히 기준입니다.

yyzTools가 더 적합한 때

메모, 문서, 블로그 초안을 가끔 쓴다면——WYSIWYG, 수식, 다이어그램, 이미지 자동 저장과 자동 저장이 필요하고, 한 가지 일 때문에 유료 앱을 늘리고 싶지 않다면——편집기는 이미 yyzTools 안에 있습니다. 옆에는 OCR, 번역, 파일 검색, 클립보드 기록——총 388개 모듈, 개인·상업용 모두 무료입니다.

자주 묻는 질문

yyzTools가 Typora를 대체할 수 있나요?

핵심 글쓰기에서는 가능합니다. WYSIWYG, GFM, KaTeX 수식, Mermaid, 이미지 자동 저장, 자동 저장을 모두 갖췄습니다. 다만 Typora의 내보내기 형식, 테마 생태계, 개요와 파일 트리, 맞춤법 검사, macOS/Linux 지원에 해당하는 기능은 없습니다. 장문 작성자나 내보내기로 전달해야 하는 분은 Typora를 남겨두는 걸 권합니다——일시불이라 오래 쓸 수 있습니다.

이미지는 어디에 저장되나요?

붙여넣거나 복사하거나 드래그한 이미지는 문서가 있는 assets/ 하위 폴더에 자동 저장되고 상대 경로로 참조됩니다. 문서 폴더째로 이동하거나 압축하거나 Git에 넣어도 이미지는 유지됩니다. 아직 저장하지 않은 문서에 이미지를 넣으면 먼저 저장하라는 안내가 나옵니다.

수식과 Mermaid 다이어그램을 지원하나요?

지원합니다. 인라인 수식은 $..$, 블록 수식은 $$..$$(KaTeX로 렌더링), Mermaid 코드 블록은 클릭 한 번으로 SVG 미리 보기가 됩니다. 둘 다 필요할 때만 로드되어 첫 화면을 느리게 하지 않습니다.

PDF나 Word로 내보낼 수 있나요?

PDF와 HTML 내보내기를 모두 지원합니다——내보내기 메뉴에 두 항목이 있고 WYSIWYG입니다(PDF는 시스템 인쇄 엔진으로 생성). Word / EPUB 등은 내장되어 있지 않아, 그런 형식이 필요하다면 Typora가 더 편합니다.

글쓰기의 절반을 무료로

무료 다운로드. Alt+Space에서 Markdown 편집기를 열면 수식, 다이어그램, 이미지, 자동 저장이 모두 준비되어 있습니다——옆에는 OCR, 번역, 검색도.
