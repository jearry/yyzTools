v1.0.5.1500

최신 버전 2026-09-02
  • 파일 검색 엔진을 자체 개발로 전환하여 Everything 의존성을 제거하고, 메모리 사용량을 수백 MB에서 수 MB로 줄였습니다.
  • 빠른 OCR 번역 기능 추가.
  • 「PDF 일괄 처리」 병합 도구에서 삽입 위치를 지정할 수 있습니다.
  • 「동영상 일괄 처리」에 커버 도구 추가.
  • 「파일 미리보기」의 동영상 늘어남 현상 수정.
  • 「알림 도우미」의 「다이내믹 배경화면에 남은 시간 표시」에서 「매년」 유형 항목은 남은 시간이 90일 미만일 때만 표시되도록 변경.
  • 다이내믹 배경화면의 알림 카운트다운에 「오늘은 알림 끄기」 버튼 추가.

  • 설치 파일에서 테스트 모듈 삭제.

  • 키 입력 표시가 마우스를 따라다니도록 변경.

이 버전 다운로드

v1.0.0.1000

2026-08-08
  • 모든 기능 페이지에 다국어를 적용해 10개 언어(중국어 간체·번체, 영어, 일본어, 한국어, 프랑스어, 독일어, 스페인어, 러시아어, 아랍어)를 지원합니다.
  • 데이터 생성 모듈 추가: UUID / GUID, ULID, 무작위 문자열과 테스트 데이터.
  • PDF 일괄 처리 모듈 추가: 병합, 분할, 워터마크, 압축, 암호화 및 복호화.
  • ImageMagick과 FFmpeg 기반의 이미지 및 비디오 일괄 처리 모듈을 추가했습니다.
  • 명령 모듈을 379개로 확장하고 AI와 자주 쓰는 웹사이트 분류 항목을 추가했습니다.
  • 자체 개발한 yyzCmd.exe로 NirCmd.exe를 대체하고, 시스템 명령을 순수 Win32 구현으로 변경했습니다.
  • 긴 화면 캡처에서 스크롤 이어붙이기를 지원하며, 클립보드 이미지를 바탕화면에 고정할 수 있습니다.
  • 분할 패키지 업데이트 방식으로 변경해, 업데이트 확인 시 변경된 부분만 내려받습니다.
