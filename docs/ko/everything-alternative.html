Everything 대체제를 찾고 계신가요?

yyzTools에는 Everything과 같은 방식의 자체 개발 전체 디스크 검색 엔진이 내장되어 있습니다 — NTFS $MFT를 직접 읽어 인덱스를 만들고, USN Journal을 감시해 실시간 갱신하며, 쿼리 구문도 호환됩니다. 다른 점은 런처, 번역, OCR, 일괄 처리 등 40여 가지 도구까지 같은 설치 파일에 담았다는 것입니다.

yyzTools vs Everything

두 도구는 같은 기술 방식을 쓰지만 제품의 위치가 다릅니다. Everything은 파일 이름 검색에 특화된 단독 도구이고, yyzTools는 파일 검색을 통합 생산성 툴박스 안에 넣었습니다.

Everything이 여전히 좋은 선택인 경우

파일 이름 검색의 극한만 필요하다면 — 정규식 쿼리, HTTP 서버 공유, SDK를 통한 2차 통합, 혹은 비 NTFS·이동식 디스크 인덱싱 — Everything은 여전히 성숙하고 믿을 수 있는 전문 도구입니다. yyzTools의 엔진은 현재 고정 NTFS 디스크만 인덱싱하고 regex:도 지원하지 않으므로, 모든 세분화된 상황에서 대체하려 하지 않습니다.

yyzTools가 더 나은 선택인 경우

「런처 + 파일 검색」조합 — 예컨대 실행은 PowerToys Run, 파일은 Everything이 담당하던 두 도구 조합 — 을 하나의 도구로 바꾸고 싶다면 yyzTools 한 번이면 충분합니다. Alt+Space 한 입력창에서 앱, 파일, 프로세스, 창, 북마크, 클립보드를 함께 검색하고, 결과를 바로 미리보기·위치 열기·삭제할 수 있으며, 뒤에는 번역·OCR·클립보드 기록·일괄 처리 등 40여 개 모듈이 있습니다.

자주 묻는 질문

yyzTools의 파일 검색은 Everything을 감싼 것인가요?

아니요. 1.0.5부터 파일 검색은 완전 자체 개발 엔진（NTFS $MFT 직접 읽기 + USN Journal 실시간 갱신）으로 바뀌었고, Everything 의존성은 설치 파일에서 제거되었습니다. 인덱스 메모리 사용량은 수백 MB에서 몇 MB로 줄었습니다.

쿼리 구문은 Everything과 호환되나요?

자주 쓰는 구문은 호환됩니다. path:, ext:, size:, datemodified:, 와일드카드, AND / OR / NOT 조합을 그대로 쓸 수 있습니다. regex: 정규식만 미지원이며, 이것이 Everything과의 주요 구문 차이입니다.

Everything과 함께 설치할 수 있나요?

네, 서로 충돌하지 않습니다. 다만 yyzTools의 파일 검색으로 충분하다면 하나만 남겨두는 쪽이 자원을 아낍니다.
