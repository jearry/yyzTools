무료 다운로드

5분 만에 yyzTools 시작하기

설치 후 기능 페이지를 하나씩 열어볼 필요 없습니다. 아래 단계만 따라가면 실제로 쓰게 되는 방식 그대로 yyzTools를 익힐 수 있습니다.

01

명령 팔레트 호출

30초

Alt+Space를 누르면 화면 중앙에 검색 상자가 나타납니다. 이것이 yyzTools의 중심입니다: 앱, 파일, 프로세스, 창, 북마크, 클립보드 기록을 이 상자 하나에서 모두 검색하고, 입력하는 대로 결과가 뜨며 Enter로 엽니다.

Alt+Space팔레트 표시 / 숨기기

Shift+Enter로 선택한 항목을 관리자 권한으로 실행할 수 있습니다.

02

접두사 몇 가지 기억하기

2분

입력창 맨 앞에 접두사와 공백을 입력하면 검색 영역이 전환됩니다: f는 전체 파일, p는 프로세스, w는 창, b는 브라우저 북마크, c는 클립보드 기록, >는 명령 실행, =는 계산기입니다. 기능 이름이 아니라 알파벳만 기억하면 됩니다.

f␣전체 파일 p␣프로세스 w␣창 b␣북마크 c␣클립보드 기록 =␣계산기
03

자주 쓰는 항목을 독에 끌어놓기

1분

마우스를 화면 상단으로 옮기면 독이 슬라이드로 나타납니다. 자주 쓰는 앱·파일·폴더를 그대로 끌어다 놓으면 추가되고, 밖으로 끌면 삭제됩니다. 즐겨 쓰는 항목을 시작 메뉴에서 찾아다닐 필요가 없어집니다.

독을 마우스 오른쪽 버튼으로 클릭하면 그룹을 만들 수 있고, URL도 바로 끌어놓을 수 있습니다.

04

단축키 취향대로 바꾸기

1분

트레이 아이콘 마우스 오른쪽 버튼 → 설정 → 단축키. 팔레트, 스크린샷, OCR, 번역, 계산기를 편한 조합으로 바꿀 수 있고, 팔레트 안의 하위 모듈에도 개별 단축키를 지정할 수 있습니다.

트레이 메뉴에서 배경화면·데스크톱 효과 전환과 업데이트 확인도 가능합니다.

05

필요할 때 필요한 것만 열기

30초

번역, OCR, 일괄 처리 기능을 일부러 찾아다닐 필요가 없습니다. 팔레트에 이름을 입력하면 열립니다. 이름이 기억나지 않으면 기능 목록을 둘러보세요 — 40여 개 모듈이 모두 설치되어 있어 언제든 꺼내 쓸 수 있습니다.
