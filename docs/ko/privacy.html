무료 다운로드

개인정보 처리방침

시행일: 2026년 8월 8일　·　버전: v1.0

본 방침은 yyzTools(이하 “본 소프트웨어”)가 사용자의 데이터를 어떻게 처리하는지 설명합니다. 핵심 원칙은 한마디로 로컬 우선(local-first)입니다. 사용자 PC에서 끝낼 수 있는 일은 절대 다른 곳으로 보내지 않습니다. 본 방침은 이용약관 제3조를 구체적으로 풀어 쓴 것이며, 두 문서가 일치하지 않을 경우 본 방침을 우선 적용합니다.

1. 수집하지 않는 정보

본 소프트웨어는 계정 등록을 요구하지 않으며, 이름 · 전화번호 · 이메일 등 신원 식별 정보를 수집하지 않습니다. 어떤 형태의 사용자 프로파일링이나 행동 추적 전송도 하지 않습니다.

사용자의 이용 데이터를 저장하는 서버가 우리에게는 없습니다. 본 소프트웨어가 애초에 이용 데이터를 우리에게 전송하지 않기 때문입니다.

2. 로컬에서 처리하고 저장하는 데이터

다음 데이터는 모두 사용자의 기기에서 수집 · 처리 · 저장되며 로컬 설정 파일과 데이터베이스에 보관됩니다. 본 소프트웨어가 임의로 업로드하지 않습니다:

  • 클립보드 기록: 사용자가 복사한 텍스트와 이미지 기록.
  • 앱 사용 통계: 각 앱의 포그라운드 시간과 활성화 횟수.
  • 파일 검색 및 미리보기: 로컬 파일 인덱스와 사용자가 열어 본 파일 경로.
  • 문자 인식(OCR): 인식은 로컬 RapidOCR 엔진에서 수행되며 이미지는 PC를 벗어나지 않습니다.
  • 설정과 환경설정: 단축키, 독 항목, 배경화면 설정, 인터페이스 언어 등.
  • 커맨드 팔레트 기록: 사용자의 검색어와 실행한 항목.

3. 네트워크가 필요한 기능

다음 경우에만 네트워크 요청이 발생하며, 모두 사용자의 조작에 의해 시작됩니다:

  • 슈퍼 번역: 사용자가 제출한 텍스트나 이미지는 설정에서 선택한 서비스에 따라 해당 제3자 온라인 번역 서비스로 전송됩니다. 이 데이터는 해당 제3자가 자체 개인정보 처리방침에 따라 처리하며 우리의 통제 범위를 벗어납니다.
  • 파일 다운로드: 사용자가 입력한 링크로 대상 서버에 직접 연결합니다.
  • 명령 모듈과 내비게이션 페이지: 주소를 열 때 내장 브라우저가 해당 사이트에 직접 접속합니다.
  • 다이내믹 배경화면: 온라인 웹페이지를 배경화면 소스로 사용하면 해당 페이지에 접속합니다.

어떤 데이터도 외부로 나가지 않기를 원한다면 위의 네트워크 기능을 사용하지 않으면 되고, 나머지 기능은 완전히 오프라인으로 사용할 수 있습니다.

4. 업데이트 확인

본 소프트웨어는 새 버전이 있는지 판단하기 위해 주기적으로 공식 미러(GitHub, jsDelivr 등)에 버전 목록을 요청합니다. 이 요청은 버전 번호 등 필요한 정보만 전송하며 사용자의 개인 데이터나 이용 데이터를 포함하지 않습니다.

설정에서 자동 확인을 끄고 트레이 메뉴를 통해 수동으로 업데이트를 확인할 수도 있습니다.

5. 데이터에 대한 사용자의 권한

  • 모든 로컬 데이터는 사용자 폴더 안에 있으므로 언제든지 직접 확인 · 백업 · 내보내기 · 삭제할 수 있습니다.
  • 클립보드 기록은 커맨드 팔레트에서 개별 항목을 삭제하거나 한 번에 비울 수 있습니다.
  • 제거할 때 데이터 폴더를 함께 삭제하도록 선택할 수 있으며, 삭제 후에는 복구할 수 없습니다.

6. 제3자 구성 요소

본 소프트웨어는 다음 오픈소스 또는 무료 구성 요소를 내장하며, 각각 원래의 라이선스 조항에 따라 배포됩니다: Microsoft Edge WebView2, FFmpeg, ImageMagick, Ghostscript, pdfcpu, RapidOCR, Everything, Aria2, 7-Zip, OpenSSL 등. 모두 로컬 프로세스로 호출되며 데이터 업로드와는 무관합니다.

7. 아동의 개인정보

본 소프트웨어는 범용 데스크톱 도구로서 아동을 대상으로 설계되지 않았으며, 연령과 관련된 정보를 임의로 수집하지 않습니다.

8. 웹사이트 접속 통계

본 웹사이트(yyztools.com) 방문 시 Cloudflare Web Analytics를 사용하여 페이지뷰, 유입 출처, 대략적 지역 및 기기 유형 등의 익명 집계 방문 통계를 수집합니다. 이는 콘텐츠의 인기를 파악하고 사이트를 개선하기 위한 것입니다. 이 서비스는 쿠키를 사용하지 않으며 개인 식별 정보를 수집하지 않습니다. 관련 데이터는 Cloudflare의 개인정보 처리방침에 따라 집계되어 처리됩니다.

9. 방침 변경과 문의

본 방침이 개정되면 이 페이지에 새로운 시행일을 표시합니다. 데이터 처리 방식에 실질적인 변화가 있는 경우에는 업데이트 안내에도 함께 알립니다. 문의 사항은 아래의 이메일이나 GitHub Issues를 통해 연락해 주세요.
