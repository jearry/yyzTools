무료 다운로드

기능 목록

사용 상황에 따라 6개 분야로 나누었습니다. 모든 기능이 하나의 설치 파일에 들어 있으며, 별도로 구매할 항목은 없습니다.

yyzTools(전체 명칭 Yes Your Zen Tools)는 무료 · 로컬 우선의 Windows 데스크톱 생산성 도구 모음입니다. 커맨드 팔레트, 독, 클립보드 기록, 슈퍼 번역, OCR, 파일 미리보기, 일괄 이름 변경, 이미지 · 비디오 · PDF 일괄 처리, 다이내믹 배경화면, 데스크톱 특수 효과 등 40여 개 모듈을 내장했습니다. 설치 파일 하나, 12개 언어, 계정 불필요, 평생 무료입니다.

커맨드 팔레트 실행과 효율 텍스트와 언어 파일과 미디어 계산과 확장 개인화 비교

커맨드 팔레트

Alt+Space로 여는 통합 입구, 검색창 하나가 PC 전체를 관통합니다.

앱 검색 default

Win32 / UWP 앱, 시스템 명령, 시스템 설정을 검색해 실행하며, 관리자 권한 실행과 파일 위치 열기를 지원합니다.

파일 검색 f␣

자체 개발 인덱싱 엔진 기반의 초 단위 전체 디스크 검색으로 메모리 사용량이 매우 적고, 바로 열기 · 미리보기 · 위치 열기 · 휴지통으로 삭제할 수 있습니다.

프로세스 관리 p␣

프로세스를 검색해 실행 / 일시 중지, 종료, 재시작할 수 있어 작업 관리자를 따로 열 필요가 없습니다.

창 관리 w␣

창을 검색해 표시 / 숨기기, 항상 위 설정 / 해제, 닫기를 할 수 있습니다.

북마크 검색 b␣

브라우저 북마크를 검색해 일반 모드 또는 시크릿 모드로 엽니다.

클립보드 기록 c␣

텍스트와 이미지 기록을 되짚어 보고, 선택하면 바로 다시 입력됩니다.

명령줄 >␣

명령을 바로 실행하며 관리자 권한 실행을 지원합니다.

즉시 계산 =␣

입력하는 동안 결과가 나오고 수식과 결과가 그래픽으로 표시되며, Enter로 복사합니다.

실행과 효율

반복 동작을 단축키 한 번으로 압축합니다.

독

자주 쓰는 앱과 주소를 담은 플로팅 실행 바로, 그룹으로 관리하며 손쉽게 접근합니다.

클립보드 기록

텍스트와 이미지를 백그라운드에서 기록하고, 이미지를 바탕화면 위에 고정할 수 있습니다.

앱 사용 통계

각 앱의 사용 시간과 활성화 횟수를 기록하고, 차트로 시간이 어디로 갔는지 한눈에 보여 줍니다.

화면 캡처

영역 캡처, 긴 캡처(스크롤 이어붙이기), 화면 고정을 별도 프로세스로 처리해 서로 부담을 주지 않습니다.

화면 녹화

화면과 소리 녹화, 카메라 영역 자유 선택을 지원합니다. 카메라가 커서를 자동으로 추적해 줌하고, 클릭·키 입력 힌트를 표시하며, 한 번의 클릭으로 완성본을 내보냅니다.

알림 도우미

1회 / 매일 / 매주 / 매월 알림을 설정하면 시간이 되었을 때 바탕화면 알림이 표시됩니다.

만세력

양력과 음력 대조, 절기와 공휴일, 간지 연도와 택일 정보를 제공합니다.

키 입력 표시

RawInput 기반으로 키보드와 마우스 입력을 실시간 표시해, 화면 녹화나 시연에서 시청자가 또렷하게 볼 수 있습니다.

마우스 찾기

현재 커서 위치를 한 번에 강조해, 여러 모니터 환경에서 더 이상 마우스를 찾아 헤매지 않습니다.

텍스트와 언어

텍스트 처리 흐름에서 자주 쓰는 공정을 한 번에 갖췄습니다.

슈퍼 번역

여러 엔진으로 단어 선택 번역과 문단 번역을 지원하며, 서비스와 대상 언어를 직접 고를 수 있습니다.

문자 인식 OCR

캡처하면 바로 인식하고, 로컬 RapidOCR 엔진이 오프라인으로 동작하며 한글과 영문 혼용도 정확합니다. 빠른 OCR 번역도 지원합니다.

정규식

실시간 일치 강조, 그룹 확인, 자주 쓰는 표현식 빠른 조회를 제공합니다.

인코딩 · 디코딩

Base64 / URL / HTML / Unicode / 진법 등 흔히 쓰이는 인코딩을 서로 변환합니다.

해시 계산

MD5 / SHA 계열 다이제스트로 텍스트와 파일 검증을 지원합니다.

암호화 · 복호화

OpenSSL 기반의 대칭 · 비대칭 암복호화와 키 생성을 제공합니다.

데이터 변환

JSON / YAML / XML / TOML / CSV 구조화 데이터의 상호 변환과 서식 정리를 지원합니다.

데이터 생성

UUID / GUID, ULID, 무작위 문자열과 테스트 데이터를 일괄 생성합니다.

파일과 미디어

일괄 처리는 도구에 맡기고, 사용자는 파일만 고르면 됩니다.

파일 미리보기

Office 설치 없이 Word / Excel / PPT / PDF / 이미지 / 비디오 / 코드 / 압축 파일 등의 형식을 바로 미리봅니다.

일괄 이름 변경

번호, 치환, 정규식, 대소문자, EXIF 시간 등의 규칙을 조합하며, 변경 전에 미리보기를 제공합니다.

이미지 일괄 처리

ImageMagick 기반의 크기 조정, 자르기, 형식 변환, 워터마크, 압축.

비디오 일괄 처리

FFmpeg 기반의 트랜스코딩, 구간 추출, 프레임 추출, 압축, 오디오 추출.

PDF 일괄 처리

pdfcpu와 Ghostscript 기반의 병합, 분할, 워터마크 추가, 압축, 암복호화.

파일 다운로드

Aria2 기반의 멀티스레드 다운로드로, 이어받기와 대기열 관리를 지원합니다.

계산과 확장

개방형 명령 모듈 체계 — JSON 하나만 추가하면 명령이 하나 늘어납니다.

계산 노트

여러 줄 연속 계산을 지원하고 변수, 단위 환산, 함수를 사용할 수 있으며 수식을 조판된 형태로 표시합니다.

QR 코드

텍스트와 주소로 QR 코드를 생성하고, 캡처 화면이나 이미지에서 인식할 수도 있습니다.

명령 모듈

379개의 .zenmod 명령 모듈을 내장해 AI, 앱, 게임, 시스템, 웹사이트 다섯 분류를 아우르며, 커맨드 팔레트에서 바로 호출합니다.

내장 브라우저

테두리 없는 경량 브라우저로, 명령 모듈이 주소를 열 때 사용해 기본 브라우저를 건드리지 않습니다.

사용자 확장

Modules 폴더에 .zenmod JSON을 넣으면 명령이 하나 추가되며 컴파일이 필요 없습니다.

개인화

바탕화면은 하루 중 가장 오래 보는 화면이니, 조금 더 보기 좋을 만합니다.

다이내믹 배경화면

Windows Composition API로 웹페이지와 영상을 바탕화면 아이콘 레이어 아래에 붙여 조작을 가리지 않습니다.

바탕화면 특수 효과

눈송이 내리기 같은 분위기 효과를 제공하며, 마우스가 통과해 클릭을 방해하지 않습니다.

게임 모드

배경화면과 특수 효과를 한 번에 일시 중지해 자원을 모두 게임에 양보합니다.

내비게이션 페이지

그룹을 직접 구성할 수 있는 탭 내비게이션으로, 브라우저의 새 탭 페이지를 대체합니다.

지구 방위전

내장 미니 게임으로 3분간 잠시 쉬어 갑니다.

각 제품의 공개 자료 기준이며 2026년 8월 기준입니다. 「플러그인」은 해당 기능이 내장이 아니라 서드파티 플러그인으로 제공됨을 뜻합니다. 「⚠️」는 부분 지원 또는 특정 플랫폼 한정을 뜻합니다.

모든 도구마다 강점이 있습니다. PowerToys는 시스템 수준 조정에 강하고, uTools와 Raycast는 확장형 플러그인 플랫폼이며, Flow Launcher와 Wox는 검색 중심 런처, Launchy는 가벼운 고전, Everything과 Listary는 파일 검색 전문가입니다. yyzTools는 자주 쓰는 기능을 처음부터 하나의 네이티브 앱에 통합했습니다 — 플러그인을 찾아다닐 필요도, 웹 런타임 부담도 없습니다. 자신의 작업 방식에 맞는 것을 선택하세요.
