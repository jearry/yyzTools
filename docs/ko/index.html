평생 무료

모든 기능을 개방합니다. 유료 잠금 해제도, 멤버십 등급도 없으며 핵심 기능을 제한해 우회적으로 과금하지도 않습니다.

로컬 우선

클립보드, 파일 검색, 사용 통계, OCR 등의 데이터는 모두 사용자 PC에서 처리하고 저장하며, 임의로 업로드하지 않습니다.

한 번의 설치

387개 기능 모듈을 설치 직후 바로 사용할 수 있어, 하나씩 검색하고 비교하고 다운로드하고 써 보고 지우는 과정이 필요 없습니다.

자주 묻는 질문

정말 평생 무료인가요? 나중에 유료로 바뀌지 않나요?

정말 무료입니다. 유료 잠금 해제도, 멤버십 등급도 없고 핵심 기능을 잘라내 유료 항목으로 만들지도 않습니다. yyzTools가 또 하나의 구독료가 아니라, 오래도록 데스크톱에 두고 싶은 도구가 되기를 바랍니다.

제 데이터가 업로드되나요?

아닙니다. 클립보드 기록, 파일 검색, 앱 사용 통계, OCR 등은 모두 사용자 PC에서 처리하고 저장합니다. 번역처럼 네트워크가 필요한 기능을 직접 사용할 때에만, 입력한 내용이 사용자가 선택한 서비스로 전송됩니다. 또한 소프트웨어는 주기적으로 업데이트를 확인하는데, 그 요청은 버전 번호만 전송합니다.

계정을 만들어야 하나요?

필요하지 않습니다. 가입을 요구하지 않으며, 사용자의 신원 정보를 임의로 수집하지도 않습니다.

어떤 운영체제를 지원하나요?

Windows 10과 Windows 11의 64비트 버전입니다. Microsoft Edge WebView2 런타임이 필요하며, Windows 11에는 기본 포함되어 있고 Windows 10에서 없는 경우 설치 프로그램이 설치를 안내합니다.

자원을 많이 차지하나요?

상주하는 메인 프로세스는 매우 가볍고, 배경화면 · 화면 캡처 · 키 입력 표시 등은 별도 프로세스로 분리되어 사용하지 않으면 실행되지 않습니다. 게임을 할 때는 게임 모드를 한 번 켜서 배경화면과 특수 효과를 일시 중지할 수 있습니다.

yyzTools와 PowerToys의 차이는 무엇인가요?

PowerToys는 Microsoft의 모듈형 유틸리티 모음으로, 고급 사용자가 필요한 구성 요소를 직접 활성화하는 방식입니다. yyzTools는 통합 스위트로, 커맨드 팔레트·번역·OCR·클립보드 기록·파일/이미지/비디오/PDF 일괄 처리가 하나의 설치 파일에 기본 구성되어 바로 사용할 수 있으며 인터페이스는 12개 언어를 지원합니다. 둘 다 무료라서 함께 사용하는 사용자도 많습니다.

Flow Launcher나 Raycast와 비교하면 어떤가요?

Flow Launcher는 검색과 플러그인이 강점인 훌륭한 오픈소스 런처이고, Raycast는 macOS 출신으로 Windows 버전은 아직 베타이며 완전한 경험은 Pro 구독이 필요합니다. yyzTools의 차이는 "설치하면 전부 있다"입니다: 번역, OCR, 클립보드 기록, 일괄 처리, 라이브 배경화면이 모두 내장되어 플러그인을 찾을 필요도, 구독할 필요도 없습니다.

Everything이나 Listary와 비교하면 어떤가요?

Everything은 파일 이름 검색에 특화된 훌륭한 도구이고, Listary는 런처와 탐색기 확장까지 갖추고 있습니다. yyzTools의 파일 검색은 1.0.5부터 자체 개발 엔진으로 바뀌었습니다. NTFS MFT 직접 읽기와 USN 실시간 갱신이라는 같은 방식으로, path: / ext: / size: 등 호환 구문을 지원하며 전체 디스크 인덱스를 약 5~30MB 메모리에 상주시킵니다. 차이는 Alt+Space 한 입력창에서 파일을 앱·프로세스·창·북마크·클립보드와 함께 검색하고, 바로 미리보기·위치 열기·삭제까지 할 수 있다는 점입니다. 파일 이름 검색 속도만 원한다면 Everything은 여전히 좋은 선택입니다.

이미 PowerToys를 쓰고 있는데 yyzTools도 설치할 수 있나요?

네, 충돌 없이 함께 쓸 수 있습니다. yyzTools 상주 프로세스는 가볍고 배경화면·스크린샷 등은 필요할 때만 실행되며, 단축키도 모두 바꿀 수 있습니다. 흔한 조합은 PowerToys로 창 분할과 키 재매핑을, yyzTools로 실행·번역·OCR·일괄 처리를 맡기는 것입니다.

uTools·Wox·ZTools와 비교하면 어떤가요?

uTools는 플러그인 플랫폼으로 본체는 무료지만 인기 플러그인 다수는 유료 멤버십이 필요합니다. Wox는 검색에 특화된 오픈소스 런처입니다. ZTools는 오픈소스 uTools 대안으로, 기능을 플러그인 마켓으로 조립해 씁니다. yyzTools는 387 개 모듈을 설치 파일에 함께 담아 멤버십도 유료 잠금 해제도 없고, 클립보드·검색·OCR 데이터는 모두 사용자 PC에 남습니다.
