평생 무료

모든 기능을 개방합니다. 유료 잠금 해제도, 멤버십 등급도 없으며 핵심 기능을 제한해 우회적으로 과금하지도 않습니다.

로컬 우선

클립보드, 파일 검색, 사용 통계, OCR 등의 데이터는 모두 사용자 PC에서 처리하고 저장하며, 임의로 업로드하지 않습니다.

한 번의 설치

40여 개 기능 모듈을 설치 직후 바로 사용할 수 있어, 하나씩 검색하고 비교하고 다운로드하고 써 보고 지우는 과정이 필요 없습니다.

379개 명령 모듈

AI, 앱, 게임, 시스템, 웹사이트 다섯 가지 분류의 명령을 바로 사용할 수 있고, JSON 파일 하나만 추가하면 직접 확장할 수 있습니다.

Ctrl을 두 번 누르면, 무엇이든 찾을 수 있습니다

CmdPlate는 yyzTools의 중심입니다. 앱, 파일, 프로세스, 창, 북마크, 클립보드가 모두 같은 입력창 안에 있습니다. 접두사만 붙이면 검색 대상이 바뀌므로 도구 이름을 외울 필요가 없습니다.

자주 묻는 질문

정말 평생 무료인가요? 나중에 유료로 바뀌지 않나요?

정말 무료입니다. 유료 잠금 해제도, 멤버십 등급도 없고 핵심 기능을 잘라내 유료 항목으로 만들지도 않습니다. yyzTools가 또 하나의 구독료가 아니라, 오래도록 데스크톱에 두고 싶은 도구가 되기를 바랍니다.

제 데이터가 업로드되나요?

아닙니다. 클립보드 기록, 파일 검색, 앱 사용 통계, OCR 등은 모두 사용자 PC에서 처리하고 저장합니다. 번역처럼 네트워크가 필요한 기능을 직접 사용할 때에만, 입력한 내용이 사용자가 선택한 서비스로 전송됩니다. 또한 소프트웨어는 주기적으로 업데이트를 확인하는데, 그 요청은 버전 번호만 전송합니다.

계정을 만들어야 하나요?

필요하지 않습니다. 가입을 요구하지 않으며, 사용자의 신원 정보를 임의로 수집하지도 않습니다.

어떤 운영체제를 지원하나요?

Windows 10과 Windows 11의 64비트 버전입니다. Microsoft Edge WebView2 런타임이 필요하며, Windows 11에는 기본 포함되어 있고 Windows 10에서 없는 경우 설치 프로그램이 설치를 안내합니다.

자원을 많이 차지하나요?

상주하는 메인 프로세스는 매우 가볍고, 배경화면 · 화면 캡처 · 키 입력 표시 등은 별도 프로세스로 분리되어 사용하지 않으면 실행되지 않습니다. 게임을 할 때는 게임 모드를 한 번 켜서 배경화면과 특수 효과를 일시 중지할 수 있습니다.

기능을 직접 추가하려면 어떻게 하나요?

설치 폴더의 Modules 폴더에 .zenmod JSON 파일을 하나 넣고 이름, 아이콘, 실행할 명령을 적어 두면 됩니다. 다시 시작한 뒤 커맨드 팔레트에서 검색할 수 있으며, 코드를 컴파일할 필요는 없습니다.

데스크톱을 도구 상자 하나에 맡겨 보세요
