Features

Grouped into six categories by the job at hand. Everything here is in the same installer, with no add-ons to buy.

yyzTools (short for "Yes Your Zen Tools") is a free, local-first Windows productivity toolkit with 40+ integrated modules: command palette, dock, clipboard history, translation, OCR, file preview, batch rename and batch image / video / PDF processing, live wallpaper, and desktop effects. One installer, 12 languages, no account, no paid tiers.

CmdPlate Speed & efficiency Text & language Files & media Compute & extend Personalisation Compare

CmdPlate

One search box for your whole PC, summoned by pressing Alt+Space.

App search default

Find and launch Win32 / UWP apps, system commands and settings. Run as administrator or reveal in folder.

File search f␣

Instant full-disk search powered by Everything. Open, preview, reveal, or send to Recycle Bin.

Process manager p␣

Search processes and run / suspend, terminate, or restart them without opening Task Manager.

Window manager w␣

Search windows and show / hide, pin on top, or close them.

Bookmark search b␣

Search browser bookmarks and open them normally or in private mode.

Clipboard history c␣

Browse past text and images, pick one to paste it straight back.

Command line >␣

Run commands directly, with an option to elevate.

Instant calculator =␣

Results as you type, with typeset formulas. Press Enter to copy.

Speed & efficiency

Collapse repetitive actions into a single shortcut.

Dock

A floating launcher for frequently used apps and URLs, organised into groups.

Clipboard history

Records text and images in the background. Pin an image to float above the desktop.

App usage

Tracks time spent and launch counts per app, charted so you can see where the hours go.

Screen capture

Region capture, scrolling capture, and pin-to-screen — each in its own process.

Screen recorder

Record the screen with audio and a custom camera region. The camera follows the cursor with auto zoom, click and keypress overlays, and one-click export.

Reminders

One-off, daily, weekly, and monthly reminders with desktop notifications.

Calendar

Gregorian and lunar dates side by side, with solar terms, holidays, and sexagenary cycle info.

Input hints

Live keyboard and mouse overlay via RawInput — ideal for screencasts and demos.

Mouse finder

Highlight the cursor instantly. No more hunting across multiple monitors.

Text & language

The whole text-processing pipeline, installed once.

Super translate

Multi-engine translation for selections or full passages, with your choice of service and target language.

OCR

Capture and recognise in one step. Runs offline on the local RapidOCR engine, accurate on mixed scripts.

Regex tester

Live match highlighting, capture-group inspection, and a cheat sheet of common patterns.

Encode / decode

Convert between Base64, URL, HTML, Unicode, and numeric bases.

Hash calculator

MD5 and SHA-family digests for both text and file verification.

Encryption

Symmetric and asymmetric encryption plus key generation, backed by OpenSSL.

Data conversion

Convert and format between JSON, YAML, XML, TOML, and CSV.

Data generator

Bulk-generate UUID / GUID, ULID, random strings, and test data.

Files & media

Let the tool handle the batch. You just pick the files.

File preview

Preview Word, Excel, PPT, PDF, images, video, code, and archives without installing Office.

Batch rename

Combine numbering, replacement, regex, case, and EXIF-date rules — with a preview before you commit.

Batch image tool

Resize, crop, convert, watermark, and compress via ImageMagick.

Batch video tool

Transcode, trim, extract frames, compress, and pull audio via FFmpeg.

Batch PDF tool

Merge, split, watermark, compress, encrypt, and decrypt via pdfcpu and Ghostscript.

Downloader

Multi-threaded downloads with resume and queue management, powered by Aria2.

Compute & extend

An open command-module system — drop in a JSON file, get a new command.

Calculator pad

Multi-line continuous calculation with variables, unit conversion, and functions, rendered as typeset formulas.

QR codes

Generate QR codes from text or URLs, and read them back from screenshots or image files.

Command modules

379 bundled .zenmod modules across AI, apps, games, system, and web — all reachable from CmdPlate.

Built-in browser

A lightweight frameless browser used when modules open URLs, so your main browser stays untouched.

Custom extensions

Add a .zenmod JSON file to the Modules folder and the command appears. No compilation needed.

Personalisation

The desktop is the screen you stare at most. It may as well look good.

Live wallpaper

Renders web pages and video beneath the desktop icon layer via the Windows Composition API — never in the way.

Desktop effects

Ambient effects such as falling snow, click-through so they never intercept the mouse.

Game mode

Pause wallpaper and effects in one click and hand every cycle back to the game.

Navigation page

A customisable grouped tab dock to replace your browser new-tab page.

Earth Defender

A small built-in game for a three-minute break.
