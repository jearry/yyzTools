Privileges

Installation

  1. Download the installer above and run it.
  2. Pick your interface language when prompted; the defaults are fine for everything else.
  3. Once installed, double-tap Ctrl to open CmdPlate and get started.
  4. The tray icon gives you settings, wallpaper and effect toggles, and update checks.

About updates

yyzTools updates per package: the main framework, front-end pages, command modules, FFmpeg, OCR models, and so on are packaged separately, so an update downloads only what actually changed instead of reinstalling everything.
